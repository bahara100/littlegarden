# 2단계 생활 시뮬레이션 검증

검증일: 2026-10-15 · Windows / Node.js 24.14.1

## 자동 검사

- `npm run check`: 현재 클라이언트 타입 검사 통과.
- `npm test`: 생활 테스트 6개 통과.
- `npm run build`: 정적 빌드 성공. 약 593KB JS / gzip 152KB. 기존 500KB 청크 경고는 남아 있으나 빌드는 성공한다.
- CI 검사 및 Pages 배포 전에 현재 생활 테스트를 실행하도록 설정했다.

테스트 범위:

1. 벤치 우회, 맵 밖·장애물·NaN 목적지 거부. 안전한 두 점 사이가 원형 나무를 관통하는 경우도 우회.
2. 벤치 두 좌석에 대한 선점 예약과 세 번째 친구의 요청 거부. 실패한 요청은 기존 명령을 유지.
3. 탑승 도중 취소 시 순간 이동 없이 하차, 탑승 완료 후 하차, 하차 완료 전까지 예약 유지.
4. 수동 이동으로 기존 예약 반환, 목적지 도착 후 자율 행동 복귀.
5. 10분 분량의 자율 생활에서 모든 친구의 벤치/그네 이용, 경계·장애물 회피, 예약자와 사용자 상태 일치.
6. 서로 교차하는 친구의 이동 완료, 반복적인 행동 취소 후 예약 누수 없음.

10분 검증은 결정적인 난수를 주입해 빠르게 계산한 시뮬레이션 시간이다. 실제 브라우저 성능의 10분 장시간 검증과 구분한다.

## 브라우저 검사

- 개발 서버와 최종 정적 빌드(Vite preview)에서 실행 확인.
- 세 친구의 초기 자동 기구 이용을 DOM 상태로 확인: 토리/모모 벤치, 루루 그네.
- 3D 화면에서 앉기와 다리 자세, 그네 좌석/캐릭터의 동시 움직임 확인.
- 친구 선택, 하차, 빈 바닥 클릭 이동 지시와 안내, 행동 중/자율 상태 전환 확인.
- 하차 완료를 기다린 뒤 패널의 벤치 버튼으로 재이용 지시, 탑승 상태와 안내 확인.
- 친구 목록, 좌석 수, 예약/이용 상태가 실시간 갱신됨을 확인.
- 최종 정적 빌드의 오류·경고 로그 0건(확인 시점 기준).
- PC 1440×1100, 좁은 600×850 레이아웃 확인.

브라우저 검수 중 기구를 캐릭터가 가리면 클릭이 어려워, 남은 자리 수가 표시되는 직접 이용 버튼을 추가했다. 개발 중 HTML과 스크립트가 순차 갱신되는 순간의 오류와 최종 정적 페이지를 구분해 최종 빌드에서 검증했다.

## 남은 범위

- 실제 기기 장시간 성능, 저사양 GPU/모바일 터치 사용성.
- 향후 GLB 최종 아트에 대한 손 위치·의상·모션 검수. 현재는 임시 관절 도형이다.
- 배치 변경에 따른 동적 경로 갱신과 저장: 3단계 이후 구현.
- 원격 GitHub Pages 배포는 미수행.
