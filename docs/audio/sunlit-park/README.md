# 햇살이 쉬어가는 공원

사용자 요청: 기존 곡을 삭제하고, 편안하고 밝은 공원에서 아이들이 뛰어놀고 가족들이 화목하게 쉬는 분위기의 새 배경음 제작.

- 새 멜로디와 화성으로 작곡. 기존 정원 곡의 멜로디를 사용하지 않았다.
- C장조, 4/4박자, 100 BPM, 40마디(악보 약 96초 + 악기 잔향).
- 피아노의 밝은 주제 → 플루트의 주제/대조부 → 피아노 복귀와 짧은 마무리.
- 나일론 기타 분산화음, 어쿠스틱 베이스, 작은 마라카스와 브러시 계열 타격음.
- 강약/짧은 쉼/미세한 타이밍 차이를 사용. 실제 아이들 목소리나 환경음은 넣지 않았다.
- FluidSynth 2.6.1 + 설치된 GeneralUser GS로 로컬 렌더링. 사운드폰트 자체는 저장소에 넣지 않는다.

편집 원본: `sunlit-park.mid`, `score.json`, `sunlit-park.wav`.
게임 파일: `apps/client/public/music/sunlit-park.mp3`(44.1 kHz 스테레오, 128 kbps, -16 LUFS 목표).
재현: pretty_midi를 설치한 Python 3.13으로 `tools/audio/compose-sunlit-park.py` 실행.

잔향이 있는 완결형 곡이며 샘플 단위 무간격 루프는 아니다. 이후 추가한 **너와 나란히, 공원 산책**과 목록 순서대로 재생한다.

검증: MP3 실제 길이 약 95.5초, FFmpeg 전체 디코딩 성공, TypeScript/Vite 빌드 성공.
최초 등록 당시에는 `sunlit-park.mp3`만 포함했고, 이후 `sweet-park-walk.mp3`를 함께 추가했다.
이전 두 곡은 게임 음원/목록에서 제거했다. 이전 편집 원본과 제작 스크립트의 영구 삭제는 자동 승인 검토에서 차단되어 개발 자료로 남아 있다.
