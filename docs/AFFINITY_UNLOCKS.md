# 친밀도 해금 쓰는 법

친밀도(♥)가 오르면 친구가 **대사**, **감정 표현**, **행동**을 새로 할 수 있게 됩니다.
해금 내용은 [`apps/client/src/unlocks.ts`](../apps/client/src/unlocks.ts)의 `UNLOCKS`에 한 줄씩 적습니다. 처음에는 비어 있습니다.
내용을 정해서 알려 주시면 Claude나 코덱스가 이 형식으로 넣습니다.

대사와 감정 기호는 모두 캐릭터 머리 위의 **흰 구름 모양 말풍선** 안에 표시됩니다.
대사는 길이에 맞춰 줄바꿈하고, 감정은 큰 아이콘으로 표시합니다. 같은 순간에 둘 다 있으면 대사가 먼저 표시됩니다.
말풍선은 이동·앉기·그네·확대에 맞춰 따라가며, 내용이 없거나 꾸미기 중이면 숨깁니다.
표시 코드는 `characterBubbles.ts`와 `garden-ui.css`이며 Phaser·Canvas가 공유합니다.

## 친밀도와 단계

- 쓰다듬기로 친구마다 하루에 한 번 ♥ 1이 오릅니다(최대 99).
- 단계(`affinity.ts`의 `AFFINITY_LEVELS`):

| ♥ | 단계 |
| --- | --- |
| 0 | 처음 만난 사이 |
| 3 | 아는 사이 |
| 7 | 친구 |
| 15 | 단짝 |
| 30 | 소중한 친구 |

해금은 단계가 아니라 ♥ 숫자(`at`)로 정합니다. 단계 숫자에 맞추면 "친구가 되면 ~" 같은 느낌이 납니다.

## 공통 항목

| 항목 | 뜻 |
| --- | --- |
| `at` | 필요한 ♥ (0~99) |
| `friend` | 이 친구만: `'character'`(홍련), `'peach'`(모모), `'lilac'`(루루). 빼면 모든 친구 |
| `chance` | 그 순간이 올 때마다 일어날 확률(0보다 크고 1 이하). 빼면 기본값: 쉬다가 가끔(idle) 0.1, 행동 0.15, 나머지 1 |

## 1. 대사 (`kind: 'line'`)

머리 위 말풍선에 뜨고, 화면 아래 안내 줄에도 `루루: "…"`로 나옵니다.

```ts
{ kind: 'line', at: 3, when: 'pet', text: '또 왔구나!' },
{ kind: 'line', at: 7, friend: 'lilac', when: 'greet', text: '모모야, 같이 놀자!' },
```

- `text`: 20글자까지. 말풍선은 2.4초 + 글자당 0.12초 동안 보입니다.
- 한 순간에 맞는 대사가 여러 개면 그중 하나를 무작위로 고릅니다.

## 2. 감정 표현 (`kind: 'emote'`)

머리 위에 기호나 짧은 말을 잠깐 띄웁니다(그림이 따로 없어서 글자로 표시해요).

```ts
{ kind: 'emote', at: 7, when: 'seat', emote: '♪' },
{ kind: 'emote', at: 15, friend: 'peach', when: 'pet', emote: '✿', seconds: 3 },
```

- `emote`: 6글자까지(예: ♡ ♪ ✿ ! ? … zZ). `seconds`: 보이는 시간, 기본 2초.
- `♡`와 `♪`는 말풍선 안에 **도트 아이콘**(하트·음표)으로 그려집니다. 다른 기호는 글자로 보입니다. 새 도트 아이콘은 `tools/art/make-emote-icons.py`에 16×16 그림을 더하고 `characterBubbles.ts`의 `EMOTE_ICONS`에 기호를 연결합니다.
- 대사와 감정은 따로 고르므로 한 순간에 둘 다 나올 수 있습니다. 대사가 떠 있는 동안에는 대사가 먼저 보입니다.

## 언제 나오나 (`when`)

| when | 순간 |
| --- | --- |
| `pet` | 쓰다듬었을 때 |
| `levelUp` | 쓰다듬어서 단계가 올랐을 때(이 대사가 있으면 `pet` 대사 대신 나옴) |
| `greet` | 다른 친구와 마주쳐 인사할 때 |
| `seat` | 벤치·그네에 앉았을 때 |
| `idle` | 자유롭게 놀다가 다음 할 일을 고를 때 가끔 |

## 3. 행동 (`kind: 'action'`)

자유롭게 놀다가 다음 할 일을 고를 때, 해금된 행동을 `chance` 확률로 스스로 합니다(부탁한 일을 하는 중에는 하지 않아요).

```ts
{ kind: 'action', at: 7, action: 'wave' },
{ kind: 'action', at: 15, friend: 'peach', action: 'visitFriend', chance: .2 },
```

지금 있는 행동(`friendActions.ts`):

| action | 내용 |
| --- | --- |
| `wave` | 멈춰 서서 잠깐 손을 흔들어요 (♡) |
| `cheer` | 그 자리에서 잠깐 기뻐해요 (♡ → ♪) |
| `visitFriend` | 자유롭게 노는 가장 가까운 친구 옆 칸으로 걸어가요. 도착하면 인사하기도 해요 |

새 행동이 필요하면 원하는 동작을 말해 주세요. `friendActions.ts`에 이름을 더하고 `simulation.ts`의 `perform()`에 동작을 만듭니다. 전용 그림이 필요한 동작(점프, 춤 등)은 도트 작업이 먼저 필요합니다.

## 확인

- 친구를 고르면 오른쪽 정보에 `해금: 대사 2 · 감정 1 (다음: ♥ 15 행동)`처럼 지금까지 열린 것과 다음 해금이 나옵니다.
- `npm test`가 목록을 검사합니다: 없는 친구·순간·행동 이름, ♥ 범위, 20글자 넘는 대사를 잡아냅니다.
