# 홍련 기본 코스튬 치비 초안

검증일: 2026-10-15

## 참조와 제작 방식

사용자가 지정한 [나무위키 홍련 페이지](https://namu.wiki/w/홍련(승리의%20여신:%20니케))는 도구에서 본문을 열지 못했다. 아래 기본 코스튬 이미지를 직접 열어 확인한 뒤 직접 3D 형상을 제작했다.

- [니케 공식 홍련 소개](https://x.com/NIKKE_en/status/1583261821498073093) / [소개 이미지](https://pbs.twimg.com/media/FfjgO-uXEAAdlk7.jpg)
- [기본 코스튬 전신 이미지](https://cdn.prydwen.gg/images/nikke/characters/scarlet_full.webp)

원작 3D 모델·텍스처 추출 없이 Three.js 메시로 만든 팬 모델 초안이다. 이미지 자체를 게임 에셋으로 포함하지 않았다. 넓은 삿갓, 금색 장식, 매듭과 술, 은빛 보라색 긴 머리, 금빛 눈, 흰색/보라색 의상, 붉은 허리 장식, 장검을 작은 비율에 맞춰 단순화했다. 장검은 기구 이용을 위해 짧게 줄인 칼집 형태로 허리에 장착했다.

## 변경

- 첫 캐릭터 ID character를 유지하고 표시 이름/외형을 홍련으로 교체. 기존 저장 배치와 호환.
- 모모·루루 및 기존 놀이터 기구는 유지.
- 공통 머리/몸통/팔/다리 그룹으로 대기·걷기·인사·벤치·그네 동작 연결.
- 그네 팔 각도를 줄의 가로 위치 ±0.52에 맞춤.
- 친구 가까이 보기: 500% 확대 및 정면 쪽에서 부드럽게 따라보기. 친구 변경 시 대상 전환.
- ⌖ 버튼으로 전체 시점 복귀, 우클릭 드래그 시 따라보기 해제, 편집 진입 시 전체 시점 복귀.

## 검사

- npm.cmd test: 18/18 통과. 모델 크기와 유한 정점, 공통 리그 그룹, 그네 손 위치 검사 추가.
- npm.cmd run check, npm.cmd run build 통과. 기존 번들 크기 경고 유지.
- 배포 빌드 브라우저에서 홍련 선택/정보/확대, 얼굴 가시성, 인사, 벤치 착석, 그네 탑승/흔들림 확인.
- 기존 배치 저장 복원 상태에서 실행됨을 확인. 꾸미기 진입 시 확대 종료 및 모델 숨김/복귀 확인.

## 남은 아트 범위

사용자 피드백으로 품질 목표를 블루아카이브 카페 SD 수준으로 명확히 변경했다. [목표 외형 및 제작 기준](art/SCARLET_ART_TARGET.md)에 모델링용 컨셉을 기록했다. 이후 반영한 곡선 머리카락·얼굴 데칼·비율 보정도 여전히 기능용 모델 개선이며, 정밀 SD 아트 완료로 간주하지 않는다.

현재는 형상과 색상 확인용 초안이다. 세부 문양·손가락·정교한 머리카락, 옷감 변형/충돌, 뼈대 스키닝, 원작 전용 동작, 기구 아트 개선과 모바일 실기기 성능 검증은 남아 있다. 넓은 모자/옷자락은 보행 충돌 대신 발 기준 경로를 사용한다.
