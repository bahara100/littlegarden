# 캐릭터 머리 위 말풍선

사용자 결정: 대사 또는 감정 아이콘을 담는 하얀색의 몽글몽글한 말풍선.

- 둥근 구름 윤곽, 연한 테두리, 뾰족한 꼬리 대신 작은 둥근 방울.
- 기존 대사·감정 타이머 및 인사/쓰다듬기/좌석 반응을 그대로 표시. 새 해금 내용은 넣지 않았다.
- `characterBubbles.ts`가 Phaser와 Canvas의 화면 좌표를 받아 DOM 말풍선을 공통으로 표시한다.
- 글자와 아이콘은 지도 확대와 독립적인 크기. 대사는 최대 190px 안에서 줄바꿈.
- 머리 위치에 따라 이동하고 좌우 경계에서는 말풍선만 안쪽으로 조정. 꼬리는 원래 캐릭터 방향을 가리킨다.
- 내용 없음·화면 밖·꾸미기 중 숨김. 렌더러 종료 시 DOM 정리. 포인터 입력은 통과.
- 캐릭터 그림·걷기·좌석·친밀도/저장 규칙은 변경하지 않았다.

검증: 생활 단위 검사 51개 통과. Phaser/Canvas에서 감정 표시·확대 중 크기 유지·꾸미기 숨김 화면 검사 추가.
최종 구름 모양 적용 후 빌드 및 말풍선/모바일 화면 검사 3개 통과. 실제 게임에서도 흰 구름 윤곽과 머리 위 위치를 확인했다.
