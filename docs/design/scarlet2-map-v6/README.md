# 홍련2 맵 적용

사용자가 최종 걷기 V6를 확인하고 맵에 적용하라고 했다. 현재 홍련 아바타(`character`)의 표시를 정지V2·최종걷기V6로 연결한다. 아바타 ID와 저장/친밀도/배치, 원래 홍련의 승인 원본 및 `scarletApproved.ts`는 보존한다. 모모·루루의 게임V2도 그대로다.

- 원화: `scarlet2-base-v2/idle-se,ne.png`, `scarlet2-walk-v6/walk-se,ne.png`.
- 배포용: `apps/client/public/sprites/scarlet2/approved-v6/`, `scarlet2.ts`.
- 128px·4컷·6FPS, SW/NW는 전체 반전. 정지 발끝 행114 아래를 접지115로 둔다. 원래96px몸체+여백이므로 모모·루루와 같은 원본픽셀당 크기로 표시한다.
- Phaser와Canvas의 소스/크기/기준점/속도를 공통 데이터로 사용한다. Canvas의 예전96px 고정 잘라내기를128px 데이터값으로 고쳤다. 실제 이동거리로 프레임을 진행하고 멈추거나 동작줄이기에서는 정지V2다.
- 최초 맵 연결은 정지와 걷기였다. 이어서 기존 의자형 앉기V2도 연결했다(`../scarlet2-chair-map-v2/`). 돗자리는 별도 바닥 앉기 자세가 필요해 기존 동작을 유지한다.
- `sync-scarlet2-runtime.py`로 정지/걷기/앉기 여섯 PNG를 바이트 동일하게 동기화한다. V6 포장도 이후 이 동기화를 실행한다. 리뷰용 .pxo/ZIP은 게임 배포 폴더에 복사하지 않는다.
- 타입검사·전체95개단위테스트·배포빌드 통과. `check-map.mjs`는 두 렌더러의 실제 네 방향 이동, 전 프레임, 128px 자르기, 정지 전환, 미러, 오류 없음과 배포 파일 보존을 확인한다. Phaser의 로드된 텍스처 픽셀도 실제 PNG와 비교했다.

기술검사와 실제 맵에서의 사용자 시각 검수는 별개다. 돗자리 바닥 앉기 및 시소 전용 작화는 별도 후속 작업이다.
