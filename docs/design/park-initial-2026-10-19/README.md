# 작은 공원 초기 배치

기존에 만든 기구를 모두 활용한 24×24 작은 공원의 시작 배치. `apps/client/src/parkLayout.ts`의 `PARK_INITIAL_LAYOUT`이며, `initialLayout(region)`으로 지역별 시작 배치를 고른다.

- 호수 산책 공간: 5×6 물고기 호수, 앞 벤치, 물가 산책길과 나무·화단.
- 분수 쉼터: 분수대 둘레의 작은 길, 옆 벤치, 꽃과 바깥 산책길.
- 놀이 공간: 그네와 시소, 중앙 길 옆 음수대. 시소를 가리는 앞쪽 나무는 덜어냈다.
- 피크닉 공간: 테이블 양쪽의 접근 길, 기존 돗자리와 주변 나무.
- 시냇물: 직선 조각 5개를 연결하고 중앙 산책길이 작은 나무다리를 건너 이어진다.
- 먼 쪽 두 변에는 울타리를 두고, 보는 쪽은 열어 기구가 잘 보이도록 했다.

193개 배치(그중 길 146칸). 꾸미기 제한 300개 이내이며, 겹침과 중앙 통로, 모든 좌석 접근점, 호수 구경 자리, 다리 양쪽 통행을 검사했다.

새 공원과 작은 공원의 **초기 배치로**에 적용한다. 기존 사용자 저장은 자동 교체하지 않는다. 기존 초기화 확인창을 거쳐 해당 지역의 배치·보관함만 바꾸며 친구 친밀도와 다른 지역은 유지한다. 온천의 시작 배치는 이전 `DEFAULT_LAYOUT`을 유지한다.

검증: 단위 검사 79개, 타입 검사, Phaser·Canvas 실제 화면, 저장된 공원 유지/초기화 취소/확정 후 재접속과 친밀도 보존 확인. 화면은 `*-whole.png`, `*-detail.png`, `*-editor.png`.
