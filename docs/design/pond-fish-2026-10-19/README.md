# 5×6 호수와 물속 물고기

- 기존 도트 호수를 가로·세로 한 칸씩 넓힌 5×6 크기로 적용했다. 회전 시 6×5.
- 금색·주황색·은청색 물고기 세 마리가 서로 다른 경로로 헤엄치며 꼬리를 흔든다. 물색 마스크로 돌·연잎·꽃 아래에 가려진다.
- Phaser는 공통 256×160 물고기 텍스처만 8 FPS로 갱신한다. 정적인 바닥은 매 프레임 다시 만들지 않는다. Canvas도 같은 도트와 경로를 쓴다.
- 꾸미기와 동작 줄이기는 물고기를 정지시킨다. 물고기는 장식이며 캐릭터의 길 찾기나 저장 데이터에 개별 생물 상태를 추가하지 않는다.
- 저장 v4 변환은 공간이 있는 예전 호수만 확대한다. 충돌이 생기는 기존 호수는 4×5로 보존하고 꾸미기 이동 시 확대 미리보기를 제공한다. 배치·친구·지역·친밀도·하루 시각을 보존한다.
- 검증: 단위 검사 77개, 타입 검사, 두 렌더러 회전·저장·구경 검사 통과. 물고기 전 경로의 픽셀 마스크, 정지 설정, 경로 반복과 이동 연속성도 검사했다.
- `phaser.png` / `canvas.png`: 실제 게임 화면. `*-rotated.png`: 회전 미리보기. `fish-frames.png`: 공통 원화+물고기의 128개 샘플, `fish-preview.gif`: 4 FPS·32초 미리보기(게임은 8 FPS).
