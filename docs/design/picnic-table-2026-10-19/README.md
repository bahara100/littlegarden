# 피크닉 테이블 좌석 연결

양쪽 벤치에 두 자리씩 총 네 자리를 지정했다. 각자 다른 칸 가운데에서 접근하며 예약, 승하차, 자유 행동, 배치 적용 때의 자리 해제는 기존 좌석 흐름을 사용한다. 이용 중 표시는 `테이블에서 쉬는 중`, 머무는 시간은 18~24초(밤은 더 길게)다.

테이블을 누르거나 친구를 고른 뒤 `테이블 이용`으로 부탁할 수 있다. 실제 그림의 원본/반전 방향에 맞춰 좌석·접근점·바라보는 방향을 함께 맞췄다. 상판을 원본에서 분리해 뒤쪽 벤치 친구의 하체 앞, 앞쪽 벤치 친구의 뒤에 그린다. 원본 그림·배치 크기는 바꾸지 않는다.

앞 앉기와 현재의 임시 뒤 자세를 재사용한다. 사용자가 뒤 앉기 베이스 제작을 나중으로 미뤘으므로, 이번에는 전용 뒤 앉기 또는 홍련의 새 앉기 그림을 제작하지 않았다. 뒷모습을 완성된 앉기 베이스로 간주하지 않는다.

검증: 4회전의 네 좌석/접근/방향, 서로 다른 자리 예약과 양쪽 착석, 내려오기/배치 교체 후 예약 해제, 여러 테이블 독립성. Phaser·Canvas 각각 원본/반전 테이블의 실제 화면 검수.
