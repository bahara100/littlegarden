# 분수대 구경

사용자 요청: 분수대를 구경할 때 분수대 도트 아이콘(⛲)이 나오게.

- 분수대를 누르거나(그림·칸 어디든), 분수대를 고른 뒤 `구경 부탁하기`를 누르면 고른 친구가 분수대 바로 옆 빈칸으로 걸어가 분수대 쪽을 보고 선다.
- 자유롭게 놀 때도 분수대가 있으면 20% 확률로 스스로 구경하러 간다(호수 25%와 같은 방식, 분수대가 없으면 확률을 굴리지 않는다).
- 구경하는 6~11초 동안 머리 위 말풍선에 ⛲ 아이콘이 5초마다 2.5초 보인다. 상태 표시는 `분수 보러 가는 중` → `분수 구경하는 중`.
- 호수 구경의 대사(루루 “물고기다! 언니 이것 봐!”)는 호수에서만 나온다.
- 코드: `simulation.ts` `watchFountain`·`fountainSpots`·`FOUNTAIN`, 단위 테스트 `tests/life/fountain.test.ts`, 화면 테스트 `tests/e2e/fountain-watch.spec.ts`(이 폴더 그림은 `UPDATE_PROOF=1`로 만든 것).
