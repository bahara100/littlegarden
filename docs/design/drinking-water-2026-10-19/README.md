# 음수대 물 흐름

기존 `drinking-fountain.png`는 수정하지 않고, 원본에 그려진 물줄기를 따라 푸른 물빛과 밝은 반짝임이 내려가도록 했다. 물이 떨어지는 수반 안에는 작은 타원형 물결이 퍼진다.

- `apps/client/src/drinkingWater.ts`: 128×128 원본에서 16컷을 한 번 생성해 보관하고 12FPS로 반복한다.
- 원본 물줄기 중심선을 따라 밝고 차가운 픽셀만 선택한다. 수도꼭지와 아래 돌 본체, 투명 실루엣은 그대로다. 수반 안의 작은 영역에는 물결 색을 입힌다.
- Phaser/Canvas 모두 연결했다. 반전 배치는 전체 그림과 함께 반전하고, 배치 모드와 동작 줄이기 설정에서는 0번 컷으로 고정한다.
- 배치 크기·좌표·충돌·캐릭터 동작은 바꾸지 않았다.

`flow-preview.gif`는 물줄기 부분을 4배 확대한 반복 미리보기, `water-frames.png`는 실제 16컷이다. `phaser.png`/`canvas.png`는 게임 화면, `*-editor.png`는 반전 배치 미리보기다. `source-*`는 수정 전 원본 확인 자료다.

검증: 빌드 및 `tests/e2e/drinking-water.spec.ts`의 두 렌더러 통과. 16개의 서로 다른 컷, 반복 경계, 정지 설정, 물 영역 밖 RGB와 모든 알파 보존을 검사했다. 분수 구경 아이콘 검사까지 총 4개 E2E 통과.
