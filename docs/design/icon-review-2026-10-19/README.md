# 감정·계절 아이콘 전체 점검

사용자 요청으로 감정 8개와 계절 4개, 총 12개의 실제 PNG를 16·32·48px 및 확대 이미지로 확인했다. 전부 16×16, 알파 0/255이며 정수 배율로 표시한다. 작은 크기에서 뭉개지는 부분을 수정했고 기존 말풍선/계절 선택 연결은 유지한다.

- 분수: 앞선 V2에서 크림색 수반과 하늘색 물줄기, 기둥을 분리했다. 이전 그림은 `../fountain-icon-v2/before.png`에 있다.
- 낚시: 지나치게 두꺼운 막대 대신 가는 낚싯대, 한 픽셀 낚싯줄, 작은 빨강/흰 찌와 물결로 정리했다.
- 물고기: 몸통 가장자리에 섞이던 눈을 흰 눈 테두리 안으로 옮겼다.
- 여름: 중심을 정확히 맞춰 여덟 광선을 균형 있게 배치했다.
- 가을: 줄기의 과도한 외곽선을 줄여 잎과 줄기 형태를 구분했다.
- 겨울: 픽셀 중심에 걸리지 않아 사라졌던 두 번째 눈을 복원했다.
- 하트·음표·손인사·느낌표·대화 점·봄꽃은 검토 후 원본을 유지했다.

`before/`와 `before-overview.png`는 **분수 V2 작업 뒤, 전체 점검 시작 시점**의 기록이다. 따라서 `verification.json`에서는 추가 수정된 5개가 changed로 표시된다. 최초 분수 수정까지 합하면 이번 작업의 변경 아이콘은 6개다.

- `after-overview.png`: 확대 전체 그림. 별표는 전체 점검 단계에서 추가 수정한 아이콘이다.
- `actual-sizes.png`: 게임에서 사용하는 1·2·3배 크기.
- `verification.json`: 파일별 규격·불투명 색 수·알파·변경 여부·SHA256.

원본 격자/팔레트는 `tools/art/make-emote-icons.py`. 재생성: `py tools/art/make-emote-icons.py`.
빌드 통과 및 `fountain-watch.spec.ts`의 두 렌더러에서 실제 분수 구경 말풍선 표시를 확인했다. 기술 검사는 사용자 작화 승인과 다르다.
