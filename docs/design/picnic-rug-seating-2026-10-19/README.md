# 피크닉 돗자리 두 자리 연결

사용자가 기존 피크닉 돗자리에도 앉을 수 있게 해 달라고 요청했다.

- 돗자리 위에 서로 마주보는 두 위치와 바깥의 별도 접근 칸을 둔다. 한 명당 한 자리, 이동 중에도 예약을 유지한다.
- 돗자리 직접 클릭 또는 캐릭터 패널의 ‘돗자리 앉기’로 이용한다. 상태는 ‘돗자리에서 쉬는 중’, 하차 버튼은 ‘일어나기’다.
- 모모·루루의 앞/뒤 앉기 그림을 활용하고 골반을 바닥 높이로 낮춘다. 홍련은 기존 가구와 같은 승인 대기 그림을 유지한다.
- 돗자리 이용자는 본인 위치를 기준으로 주변 기구·나무·친구와 앞뒤 정렬한다. 고정 돗자리 그림과 2×2 크기, 배치 저장 데이터는 변경하지 않는다.
- `worldFrom()`에 고정 두 좌석이 포함된다. 배치한 가구가 없어도 돗자리는 남는다. 기존 가구 검사는 해당 종류의 좌석을 대상으로 유지한다.

단위 검사 89개, 타입 검사·빌드 통과. Phaser와 Canvas에서 실제 돗자리 클릭, 두 명 착석, 만석일 때 버튼 비활성, 일어나기와 빈자리 복구를 확인했다. 두 화면은 `phaser-seated.png`, `canvas-seated.png`다.
