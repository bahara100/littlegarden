# 잔디와 길 디테일

첫 단순한 풀잎/점무늬 작업에 사용자가 기구에 비해 여전히 기초 수준이라고 지적했다. 최종은 `docs/art/pixel/ground-materials-v1/`의 생성 원화를 사용한다. 명암 있는 풀잎·클로버·작은 꽃과 흙·자갈·눌린 길 질감을 두 렌더러의 공통 코드로 연결한다. 이어진 길은 하나로 보이고 꾸미기 모드에서만 격자를 겹친다. 배치와 길 찾기에는 영향이 없다.

무늬는 월드 좌표와 고정 난수로 결정한다. 길을 지우거나 배치 순서를 바꿔도 주변 무늬가 섞이지 않는다. 길 내부의 접합선은 그리지 않으며 교차로·모서리도 외곽만 테두리로 처리한다. 지역·계절 팔레트를 계속 사용하고, 축소 화면에서는 작은 장식을 단순하게 표현한다.

기존 뒤 앉기는 임시 대기 파생 그림이며, 사용자가 제대로 된 뒤 앉기 베이스 제작을 나중으로 미뤘다. 이번 변경에는 캐릭터 작업이 포함되지 않는다.

검증: 길 연결 외곽/교차로/분리된 길과 순서 독립성, Phaser·Canvas 생활/확대/꾸미기 화면, 배치 보존.
