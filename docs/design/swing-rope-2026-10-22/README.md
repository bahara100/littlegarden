# 그네 줄의 가림 순서와 앉은 위치

사용자가 첨부한 두 화면을 기준으로, 캐릭터가 좌석 오른쪽으로 치우치고 가까운 줄이 머리카락 뒤에 가려지는 부분을 수정했다.

`swingArt.ts`가 기존444px 분할 원본에서 가까운 줄을 추출한다. 나무 좌석은 앞 줄에서 제외한다. 먼 프레임→먼 줄/좌석(+.3)→캐릭터(+.35)→가까운 줄(+.38)→가까운 A프레임(+.4)으로 그린다. 위 가로봉은 기존처럼 흔들림 방향에 따라 가린다. 앞 줄도 기존 source 직접 샘플링 방식으로 같은33포즈를 만들어 좌석과 동기화한다.

앉은 위치는 회전0/3에서 화면 왼쪽 .16타일, 반전 방향인1/2에서 오른쪽 .16타일로 보정한다. 앉기/일어서기 진행도에 따라 적용·복원한다. Canvas에도 같은 정지/흔들림 그림과 좌석 궤적을 연결해 캐릭터만 별도로 수직 움직이던 방식을 대체했다. 좌석높이와 캐릭터 그림, 원본 그네 PNG, 예약과 저장 배치는 바꾸지 않았다.

`check-swing.mjs`는 실제 앱의 두 렌더러에서4회전×3포즈24경우와 다른 세 캐릭터6경우를 확인한다. 앞 줄이 실제 캐릭터 뒤/앞 순서에 맞고 좌석과 같은 프레임인지, 끝에서 잘리지 않는지, 캐릭터가 좌석을 따르는지 검사했다. 움직이는 상태에서 동작 줄이기 적용, 일어나기 예약 해제와 그네 제거 시 뷰 정리도 확인했다. 결과는 `verification.json`, 실제 화면은 `phaser-*.png`/`canvas-*.png`다.

기존 `tests/e2e/swing-pixels.spec.ts`의 두 테스트(원본 정지 그림/직접샘플링, 실제 걸어와 탑승) 통과. 타입검사와 배포 빌드도 통과했다. 기술 검사는 사용자 작화/위치 승인을 뜻하지 않는다.
