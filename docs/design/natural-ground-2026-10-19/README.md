# 평소에는 자연스러운 바닥, 꾸미기에서만 그리드

사용자 요청: 생활 모드에서는 타일 그리드가 보이지 않고 자연스럽게 이어지는 바닥,
놀이터 꾸미기에서만 칸을 표시.

- 생활 모드: 바닥 전체를 한 번에 같은 기본색으로 채워 체크무늬/타일 경계 제거.
- `groundTexture.ts`가 칸과 무관한 위치에 잔디/꽃잎 점을 드문드문 배치한다. 지역·계절 색은 유지한다.
- 길 타일도 생활 모드에서는 같은 색으로 이어지고, 꾸미기에서는 칸별 테두리가 나타난다.
- Phaser·Canvas 모두 `editor.active`로만 그리드를 결정한다.
- 화면 설정의 그리드 스위치를 삭제하고 자동 표시 안내로 바꿨다.
- 이전 저장의 `settings.grid` 값은 형식 호환을 위해 읽을 수 있지만 화면 표시에 영향을 주지 않는다.
- 실제 저장된 기구 배치·길 찾기·타일 스냅 규칙은 변경하지 않았다.

검증: 빌드 성공, 보기 설정 및 두 렌더러의 기구 배치/저장 화면 검사 3개 통과.
실제 브라우저에서 생활 모드/꾸미기 모드 양쪽을 확인하고 취소로 복귀했다.
`life-mode.png`, `edit-mode.png`에 확인 화면을 저장했다.
