# 돌 테두리 접근 제한과 기구 앞뒤 가림 점검

사용자가 호수를 감상하는 홍련이 돌 위에 서 보인다고 지적하고 시냇물과 다른 기구도 위치에 따른 겹침·가림을 점검해 달라고 요청했다.

## 수정

- 호수 감상 위치를 배치 칸 바깥 0.5칸에서 1.5칸으로 물렸다. 호수 돌 테두리는 0.5칸, 시냇물의 돌·풀 테두리는 0.25칸을 걷기 장애물에 더해 물뿐 아니라 둑 위도 걷지 않는다. 배치 칸·그림·저장 좌표는 그대로다.
- 호수·시냇물의 높이 있는 테두리를 원본 도트에서 분리해, 캐릭터·나무·울타리·기구와 같은 앞뒤 정렬에 참여시킨다. 바닥의 물과 연잎·물고기는 기존 바닥 순서를 유지한다.
- 물 위 나무다리는 배치 배열 순서와 관계없이 둑보다 위에 그린다. 다리 위를 걷는 친구는 데크와 먼 난간 뒤로 숨지 않으며 앞쪽 난간에만 가려진다.
- 전체 공원의 연결 시냇물에서 정렬 관계가 순환할 때도 물 테두리 → 다리 순서는 유지한다. 이전에는 순환 해소 과정에서 중앙 시냇물의 돌이 다리 데크를 덮었다.
- 기존 다리 발 높이 0.32칸은 원화보다 낮아 몸이 데크 밑으로 들어갔다. 중앙 1.05칸의 아치와 양 끝 0.75칸의 짧은 접근 경사를 적용했다. 두 렌더러가 같은 발 높이와 그리기 순서를 사용한다.
- 호수를 옮기거나 지웠을 때 예전 감상 자리와 시선 목표도 함께 해제한다.

## 검증

- 호수·시냇물 및 세워진 기구/장식 12종, 네 방향의 앞/뒤 순서. 나무와 울타리, 벤치·그네·시소·테이블·음수대·분수대·다리·화단 포함.
- 둑 접근 금지, 네 방향 감상 자리, 다른 기구의 좌석 접근, 다리 통행, 저장 배치/백업 보존 단위 검사.
- Phaser와 Canvas에서 호수 뒤쪽 감상, 시냇물 옆 이동, 실제 다리 통과 화면. `*-far-shore.png`, `*-stream-bank.png`, `*-bridge-entry.png`, `*-bridge-exit.png`.
- `raised-layers.png`: 왼쪽 원본 / 오른쪽 앞뒤 가림용 도트. 새 색·도형으로 그리지 않고 원본 픽셀을 복사하며, 복사된 색이 원본과 같은지도 확인했다.
- 기존 그네의 앞 프레임/탑승자와 피크닉 상판/먼 좌석의 전용 순서는 유지한다. 캐릭터 원화·걷기·좌석 자세를 변경하지 않았다.
- 최종 단위 검사 86개와 TypeScript 검사 통과. 두 렌더러의 호수 뒤 감상·다리 통과 네 장면 및 전체 공원 두 장면의 브라우저 검사 통과. 전체 공원의 데크를 덮던 돌 테두리 수정 후 두 렌더러 전체 화면도 다시 확인했다.

원본 PNG는 수정하지 않는다. `raisedWaterArt.ts`, `drawOrder.ts`, `waterBounds`, `POND_WATCH_GAP`이 공통 기준이다.
