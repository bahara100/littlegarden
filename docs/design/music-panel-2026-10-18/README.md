# 음악 패널 디자인

요청: 지도 오른쪽 위 노래 제목 칸과 목록 버튼을 배경과 어울리게 수정.

- 분리된 흰 상자를 연한 세이지색의 통합 패널로 변경.
- 크림색 원형 음표 아이콘, 제목 영역만 페이드/가로 흐름 처리.
- 음악 목록 SVG 아이콘. 열림 상태는 짙은 녹색으로 표시.
- 목록도 같은 녹색/크림색 계열로 맞추고 선택 항목을 강조.
- 후속 요청으로 왼쪽 지역·계절 선택도 같은 패널로 통일. 지역 번호 배지와 계절 아이콘을 구분하고 열림 상태를 녹색으로 표시.
- 좁은 화면에서는 두 줄 패널 사이 간격을 확보해 겹치지 않게 조정.
- 기존 제목 흐름, 곡 선택·음량·음소거·재생과 키보드 접근 유지.
- 수정 위치: `apps/client/src/garden-ui.css`, `apps/client/index.html`.

검증: TypeScript/Vite 빌드 성공, 실제 브라우저에서 지역·계절·음악 메뉴 열림 및 좁은 화면 배치 확인.
기존 Playwright 모바일 화면 맞춤 검사도 통과(1 passed). 샌드박스의 로컬 서버 연결 제한으로 최초 실행은 대기했으며, 로컬 연결이 가능한 권한으로 재실행해 검사를 완료했다.
