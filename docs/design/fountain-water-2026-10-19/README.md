# 분수대 물 흐름

- 기존 분수대 PNG의 푸른 물 영역만 24프레임·12 FPS로 움직인다. 위쪽 물줄기의 하이라이트가 아래로 흐르고, 아래 수조에는 낙수 지점에서 타원형 잔물결이 퍼진다.
- 돌, 기둥, 테두리, 기존 흰 포말과 투명도는 원본 픽셀 그대로 유지한다. 이미지 이동/확대/변형이나 새 바닥 그림자는 없다.
- `fountainWater.ts`에서 한 번 만든 프레임을 Phaser와 Canvas가 공유한다. 여러 분수대도 같은 프레임 자원을 재사용한다.
- 꾸미기와 동작 줄이기 설정에서는 정지한다. 저장 데이터와 배치 범위는 변경하지 않는다.
- 검증: TypeScript 검사 및 두 렌더러 브라우저 검사 통과. 24개 고유 프레임, 반복 주기, 정지 프레임, 물 이외 영역/알파 보존을 확인했다.
- `phaser.png`, `canvas.png`: 실제 게임. `*-editor.png`: 꾸미기·회전 확인. `water-frames.png`, `water-preview.gif`: 실제 공통 프레임의 확대 미리보기.
