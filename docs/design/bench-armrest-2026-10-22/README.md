# 벤치 앞 팔걸이와 앉기 위치

캐릭터 전체가 벤치 위에 그려져 앞 팔걸이가 가려지는 문제를 수정했다. `benchArt.ts`가 기존 벤치 두 방향의 앞 철제 팔걸이/앞다리 픽셀만 추출한다. 나무판과 고리 안쪽은 앞 레이어에서 제외한다. Phaser와 Canvas 모두 벤치 뒤→캐릭터(+.35)→앞 철제 부분(+.4) 순서로 표시한다. 일반 보행자는 기존 장면 순위대로 그려져 벤치 앞에 있으면 앞 팔걸이보다 앞에 나온다.

앉을 때 화면상으로 회전0/3은 왼쪽 .16타일, 반전한 회전1/2는 오른쪽 .16타일 보정한다. boarding/leaving 진행도에 비례하고 일어서면0으로 돌아간다. 기존 좌석 예약/높이/경로/저장 배치와 벤치/캐릭터 원본 그림은 바꾸지 않았다. 모모·루루·홍련2·스노우화이트에 공통 적용한다.

- `before-snow.png` / `after-snow.png`: 같은 회전0·오른쪽 좌석의 실제 게임 전후.
- `bench-cell-0.png`, `bench-cell-1.png`: 수정 전 실제 렌더 텍스처.
- `bench-front-0.png`, `bench-front-1.png`: 원래 픽셀의 앞 팔걸이 추출 결과.
- `phaser-turn-*.png`, `canvas-turn-*.png`: 두 렌더러 네 회전.
- `*-character.png`, `*-peach.png`, `*-lilac.png`: 다른 세 캐릭터도 확인.
- `verify-bench.mjs`: 실제 양 렌더러에서 네 회전×양좌석16경우, 다른캐릭터6경우의22검사와 소스픽셀보존/나무제외/일어서기예약해제/벤치제거 시레이어제거/브라우저오류 검증. `verification.json`에 결과.

타입검사와 배포 빌드 통과. 기술 검사는 사용자 외형/배치 승인을 뜻하지 않는다.
