# 피크닉 테이블 그리드 각도 보정

원본 그림의 긴 변 기울기는 약 38/62로, 바닥 아이소메트릭 그리드(1/2)보다 가팔랐다. 원본 목재 도트와 PNG를 보존하고 `picnicTable.ts`의 공통 역방향 픽셀 샘플링으로 그리드에 맞췄다.

- 긴 변 (62,38) → (62,31), 짧은 변 (−28,14) → (−28,14).
- x좌표와 폭은 그대로이며 바닥 중심 접지 기준점을 고정한다. 새 색이나 블러 없이 한 번만 nearest-neighbour로 샘플링한다.
- 테이블 전체와 먼 쪽 친구를 가리는 상판 복사본을 같은 좌표 변환으로 만든다. 홀수 방향은 최종 보정 그림 전체를 반전한다.
- Phaser·Canvas 모두 같은 보정 함수를 쓴다. 기존 저장 좌표·4×3 배치 칸·좌석·접근점·앉기 높이는 그대로다.
- 타입 검사, 변 기울기/접지점 검사, 좌석 접근·승하차 검사 및 두 렌더러 두 방향 화면 확인을 통과했다.
- `*-seated.png`: 승차 확인. `*-grid.png`: 꾸미기 화면. `source-inspection.png`: 변경하지 않은 원본 확대.
