# 그네 움직임 도트 정리

`playground-swing-v1.png` 원본은 그대로 사용한다. 이전에는 줄·좌판을 먼저 128px로 축소하고 다시 비틀어 픽셀 윤곽을 두 번 샘플링했다. 이제 움직이는 프레임은 원본 444px 레이어에서 변형과 축소를 한 번에 처리한다. 줄 주변에서 따로 떨어져 움직이던 1~4px 잔여 조각은 제거한다. 프레임별 경계도 잘라 이웃 프레임으로 번지지 않게 한다.

정지 프레임은 기존 축소 그림을 그대로 복사한다. 그네 위치, 크기, 좌석 높이, 각도, 주기와 탑승자 이동 계산은 바꾸지 않았다. 시소는 여전히 정지 장식이며 두 명 탑승 기능은 별도 작업이다.

검증: 양 방향 33개 프레임의 정지 픽셀 일치와 프레임 경계 잘림 없음, 실제 게임 모모 그네 탑승. `comparison.png`는 이전/수정 후 양 끝과 가운데를 비교하며 `in-game.png`는 게임에서의 탑승 화면이다. 정적 검사는 작화에 대한 사용자 승인을 대신하지 않는다.
