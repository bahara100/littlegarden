# 피크닉 테이블 앉기 접점 보정

사용자가 올린 화면에서 스노우화이트가 벤치 끝에 서 있는 것처럼 보였다. 공통 발 기준 원점을 테이블의 바닥 좌표에 놓으면서 실제 엉덩이 접점이 벤치 면에서 벗어난 것이 원인이었다.

`picnicTable.ts`에서 실제 그리드 정렬 후의128px 벤치 면을 near(11,80)→(62,108), far(64,55)→(120,86)으로 기록하고 각 선의1/4·3/4 지점에 두 좌석을 맞췄다. 스노우화이트·홍련2·모모/루루의 실제 앉기 그림에서 앞/뒤 엉덩이 접점을 따로 사용한다. 두 렌더러가 같은 보정을 쓰며 회전 시 테이블과 함께 반전하고 boarding/leaving 진행도에 따라 보간한다. 기존 좌석높이·예약/길찾기·저장 좌표와 그림은 그대로다.

반대편 이용자는 기존 상판 레이어 뒤에 놓고, 가까운 벤치의 원래 목재 도트를 앞 레이어로 추출해 다리가 벤치 판 위에 그려지는 부분을 가렸다. 다른 보행자와의 순서는 기존 장면 rank를 따른다. 새 PNG 작화나 캐릭터 자세 변경은 없다.

`before-*.png`와 `after-*.png`가 동일한 스노우화이트 네 자리의 실제 전후다. `check-seats.mjs`와 `verification.json`은 두 렌더러×4회전×4좌석32경우의 실제 엉덩이/벤치 접점과 가림 순서, 다른 캐릭터의 앞뒤6경우씩12경우 총44검사를 기록한다. Canvas 정수 픽셀 반올림 오차 내/Phaser 정확 좌표 일치를 확인했다. 네 명 동시 이용, 일어서기 예약 해제와 테이블 제거 시 앞 레이어 정리도 확인했다. 개별/동시 탑승 그림은 `phaser-*.png`와 `canvas-*.png`다.

기존 피크닉 단위테스트4개로 네 자리 접근성과 바라보는 방향·서로 다른 예약·일어서기를 확인했다. 타입검사와 배포 빌드를 실행했고 실제 접근/앉기/일어나기/편집 E2E도 점검했다. 기술 검사는 사용자 배치/외형 승인을 의미하지 않는다.
