# 홍련2 의자형 앉기 V2 맵 연결

사용자의 이어서 진행 요청에 따라 미연결된 기존 앉기V2를 좌석에 연결했다. 새로운 작화나 원본 수정은 없다. 정지V2·걷기V6, 모모·루루의 게임V2, 저장/배치/예약 로직은 유지한다.

- 벤치·그네·피크닉 테이블·시소는 기존 의자형 앉기V2를 사용한다. 시소 전용 다리/손 자세를 새로 만들었다는 뜻은 아니다.
- SE/NE 원본 PNG를 그대로 배포 폴더의 `sit-se/ne.png`로 복사한다. SW/NW는 전신 반전.
- 공통 몸체96px에 더한 여백(16,24)을 고려해 앉기 원점을 `(96×.97+24)/128`로 둔다. 친구들과 같은 좌석 높이값을 쓰되, 앉고 일어서는 진행률 .45 전후에 자세를 전환하고 서면115/128로 복귀한다.
- 바닥형 자세가 필요한 돗자리는 기존 동작을 유지한다. 이번 의자형 그림을 바닥에 억지로 놓지 않는다.
- `scarlet2.ts`에서 지원 좌석과 전환 조건을 공유해 Phaser/Canvas를 일치시킨다. 동작 줄이기에서도 앉은 그림은 유지한다.
- 배포용 외형 검수 페이지에 ‘의자에 앉기’ 선택을 추가했다. `sync-scarlet2-runtime.py`는 정지/걷기/앉기 6PNG를 원본과 동일하게 동기화한다.

검증: 전체96단위테스트·타입검사·배포빌드 통과. `check-seats.mjs`는 두 렌더러에서22가지 실제 기구 이용·일어서기, 네 방향, 원점 복귀, 돗자리 제외를 확인한다. 기구 종류를 바꾸는 검수는 실제 편집기와 같이 각 기구마다 고유ID를 사용한다. 기존 맵 걷기 검수도 네 방향의 네 컷/정지 전환/텍스처 일치를 확인했다. 저장된 PNG는 실제 좌석 화면의 검수 기록이며 작화 승인을 대신하지 않는다.
