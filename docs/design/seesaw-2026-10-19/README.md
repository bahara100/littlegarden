# 두 친구가 타는 시소

- 각 시소에 두 개의 독립 좌석과 칸 가운데 접근점을 지정했다. 원본/반전 그림과 4회전 배치에 맞춘다.
- 한 명은 25초 동안 기다린다. 두 명이 모두 앉으면 14초 동안 함께 탄다. 예약 또는 이동 중인 친구는 탑승 인원에 포함하지 않는다.
- 판자는 3.2초 주기로 오르내리며 두 캐릭터의 높이와 말풍선도 같은 프레임에 따라 움직인다. 한 명이 내리면 중립으로 부드럽게 돌아온다.
- 자유 행동 중인 친구는 빈 반대편 자리로 합류할 수 있다. 화면의 `시소 이용` 버튼이나 시소 클릭으로 직접 부탁할 수도 있다.
- 원래 시소 PNG는 보존했다. 런타임에서 받침을 분리하고 판자 밑의 가려진 나뭇결을 원본 픽셀로 연결해 33개 기울기 프레임을 만든다. 16px 여백으로 양 끝이 잘리지 않게 했다.
- Phaser와 Canvas가 같은 프레임·좌석 이동 계산을 쓴다. 동작 줄이기 설정에서는 정지 그림으로 보여준다.

모모·루루의 앞 좌석은 기존 앉기 그림, 반대 좌석은 기존 뒤 대기의 머리·의상·신발을 활용한 뒷모습 앉기를 사용한다. 양 끝에서 서로를 바라보게 하며 반전 방향에서도 함께 바뀐다. 홍련은 기존 기구와 같이 대기 그림으로 탄다. 전용 시소 손잡이 잡기 자세를 새로 그린 것은 아니다.

검증: 단독 대기, 두 명 탑승과 반대 높이, 세 번째 예약 거절, 내려오기와 재합류, 대기 시간 종료, 배치 교체 시 예약 해제, 네 회전의 접근 경로. 브라우저에서 두 렌더러와 두 그림 방향을 확인하고 각각 반대 기울기 화면을 저장했다.
