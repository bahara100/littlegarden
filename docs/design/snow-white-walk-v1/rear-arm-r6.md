# 뒤 걷기 3번 팔 위치 R6

사용자가 뒤3번 접지에서 팔 위치를 지적했다. 앞에서 재사용한 굽힌 장갑이 어깨 바깥쪽으로 길게 나와 보이는 위치를 조정했다.

NE3의 굽힌 팔/손 실제 픽셀을 x−2/y+2 이동하고, 원래 어깨 루트(y72..73)는 유지했다. 손/장갑 크기와 실제 명암 픽셀을 보존했으며 회전이나 축소는 없다. NW3는 전신 반전이다. 변경 전 R5는 `before-rear-arm-r6/`에 보관한다.

변경 범위는 NE3 x71..84/y74..84 안이다. 그 밖의 몸/머리/다리는 같고, NE/NW1·2·4와 앞쪽 SE/SW 전체(R5 목과 R4 머리 포함)의 SHA가 같다. 기존 빌더 `repair_rear_arm()`에서 재현하고 Pixelorama의 NE 몸통 레이어를 갱신했다. `.pxo` 내보내기와 최종 PNG 일치, 기존129파일 보존, 영역 밖 보존, 원래 장갑 픽셀 일치, 전체 연결·색·반전 검사를 수행했다.

검수 페이지에 실제3번의 전후 확대를 추가하고 `dir=ne&frame=3`으로 바로 선택할 수 있게 했다. 데스크톱/모바일32경우 실제 PNG/베이스동기/확대/재생/다운로드 검사와 NE3 초기선택을 확인했다. 기술 검사는 자연스러운 작화에 대한 사용자 승인을 의미하지 않는다. 게임은 미연결이다.
