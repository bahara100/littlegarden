# 뒤3번 팔 위쪽 돌출 정리 R7

사용자가 R6 뒤3번의 팔 위쪽에 삐져나온 도트만 정리해 달라고 했다. 이전 어깨 루트의 바깥끝을 남긴 x77..81/y72..73의10점만 삭제했다. 안쪽 어깨 연결과 내린 팔/손 전체는 유지했다. NW3는 전신 반전이다.

`before-arm-edge-r7/`에 R6를 보관했다. 빌더 `repair_rear_arm()` n==2의 끝에서 같은10점을 삭제한다. Pixelorama NE 몸통 레이어의3번만 갱신했고 최종 PNG와 편집기 출력이 같다. 포장은 R6대비 지정10점 밖 동일, 손/장갑 원래 픽셀, 다른 컷/머리/다리/앞쪽 전체 SHA, 기존129원본, 연결/반전/색을 검사한다. 실제 전후 확대는 `rear-arm-edge-before-after.png`다. 검수 페이지는 `arm-edge-r7` 쿼리로 제공한다. 기술 검사는 사용자 작화 승인을 의미하지 않는다.
