# 앞 걷기 목·옷깃 연결 R5

R4 옆머리 복원 후 사용자가 머리와 목이 따로 움직인다고 지적했다. 머리와 몸의 공통 bob은 이미 같았다. 서로 다른 생성 원화의 목과 옷깃 위치가 컷별로 달랐고, 특히3번에서 목이 오른쪽으로 이동하고 가슴이 짧아져 보였다.

앞쪽 SE 네 컷의 몸통 레이어 x60..75, y68..80을 승인 정지의 이어진 목·옷깃·가슴 중앙으로 통일했다. 2·4번은 머리와 같은 y−1px 이동을 한다. 이 영역은 팔·손과 분리되어 기존 스윙을 유지한다. SW는 전체 반전이다. 새 생성이나 회전/축소는 없다.

- `docs/art/pixel/snow-white-walk-v1/before-neck-stabilize/`: R4 원본과 변경 전 SHA.
- `tools/art/prepare-snow-white-neck-r5.py`: 덮어쓰지 않는 변경 전 보관.
- `tools/art/build-snow-white-walk-v1.gd`: `stabilize_front_neck()`에서 재현.
- `tools/art/package-snow-white-walk-v1.py`: 변경 범위·정지 원화 일치·알파·팔/다리·머리/앞손 SHA·뒤 방향·원래129파일·편집기 합성 일치를 검사.
- `neck-core-five-way.png`: 윗줄 R4, 아랫줄 R5. 각 줄 왼쪽은 승인 정지, 그 뒤1~4번이다. bob을 제거해 목의 실제 작화 차이를 비교했다.
- 검수 페이지 위쪽 확대는 같은 컷을 동기 재생한다. 뒤 방향은 수정하지 않아 전후가 같다.

전신 미리보기와 확대 비교를 확인했고, 데스크톱/모바일 32경우의 실제 PNG·베이스 동기·전후 확대·재생·다운로드 검사를 수행했다. 기술 검사는 자연스러운 작화에 대한 사용자 승인을 뜻하지 않는다. 기존 정지·앉기·베이스·게임은 변경하지 않았다.
