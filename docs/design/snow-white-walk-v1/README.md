# 스노우화이트 걷기 V1 검수

정지/앉기와 SE V20/수동 NE V8 등129파일 SHA 보존. native128px·4컷·6FPS·2레이어 .pxo를 두 방향에 저장하고 편집기 출력이 실제16PNG와 같은지 확인했다. 전체알파0/255, 기존48색, 얼굴/고글·머리 동일(2/4번1px위로), 전신연결, 정확한좌우반전, 중복전신없음을 검사했다.

`check-review.mjs`는 데스크톱1440px/모바일390px에서4방향×4컷을 선택하고 전체32경우 Canvas가 실제PNG와 픽셀 동일한지, 베이스가 같은프레임인지, 확대보간이꺼져있는지, 가로넘침이없는지 검사한다. 재생/3FPS전환/다운로드도 확인했다. 이미지4장과 모바일캡처, `browser-check.json`에 기록했다. 이 검사는 작화/자연스러운움직임의 사용자 승인을 대신하지 않는다.

이동안내: `http://127.0.0.1:4185/snow-white-walk-v1/index.html`. 아직 게임에는 미연결이다. 상세 제작/제한은 `docs/art/pixel/snow-white-walk-v1/README.md`에 기록한다.
