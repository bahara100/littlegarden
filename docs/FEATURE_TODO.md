# 기능 손볼 목록

기능 쪽에서 아직 손볼 것들을 모아 둔 목록입니다(그림 작업은 제외). 끝낸 항목은 이 파일에서 지웁니다.
전체 개발 흐름 점검표는 [GAME_DEV_FLOW.md](GAME_DEV_FLOW.md)에 있습니다.

## 고치면 좋은 문제

### 지역·계절을 바꿔도 화면 글이 그대로
- 온천이나 겨울을 골라도 다음 글이 바뀌지 않습니다.
  - 오른쪽 패널의 "햇살 머무는 정원"과 설명
  - 머리말의 "LITTLE GARDEN"
  - 제목 아래 "햇살 좋은 오후, …"
- 고칠 곳: `index.html`의 `.garden-panel`, `.brand-sub`, `.page-heading`. 지역·계절마다 쓸 글을 `regions.ts`·`seasons.ts`에 넣습니다.

### 검수용 그림까지 배포에 들어감
- 지금: 게임 코드가 `sprites/garden/` 아래 파일 이름을 조립해서 쓰기 때문에, 배포 필터가 그 폴더 전체를 남깁니다. 그래서 게임이 쓰지 않는 검수용 `base-walk-v1`·`v3`·`v4`·`v5`도 함께 올라갑니다(약 0.5MB, 새 버전이 생길 때마다 늘어남).
- 고칠 곳: `friendBodyArt.ts`의 경로를 실제로 쓰는 버전 폴더(`sprites/garden/base-walk-v2/`)까지 코드에 적히게 하거나, `vite.config.ts`의 gameFilesOnly에 남길 목록을 더 정확히 줍니다.

## 기능을 더 살리는 것

### 새 공원 기구 이용 동작
- 지금: 공원 기구 6종을 배치할 수 있습니다. 시소는 두 자리 탑승과 오르내리기, 피크닉 테이블은 양쪽 벤치의 네 좌석, 나무다리는 물길 건너기를 연결했습니다.
- 할 일: 사용자가 요청하면 음수대에서 마시기, 분수 구경 등을 전용 동작/접근 위치와 함께 연결합니다.
- 물길은 직선 연결 조각입니다. 꺾이는 물길·갈림길의 배치 규칙은 해당 그림이 준비되면 추가합니다.

### 친밀도 해금 내용 채우기
- 지금: 대사·감정 표현·행동을 해금하는 틀은 있습니다. 해금 목록(`unlocks.ts`의 `UNLOCKS`)에는 모모·루루 대사 6개(♥0)만 있고, 홍련 대사·감정 표현·행동과 높은 단계(♥3·7·15·30) 내용은 아직 없습니다.
- 할 일: 사용자가 친구별 대사·감정·행동과 필요한 ♥를 정하면 [쓰는 법](AFFINITY_UNLOCKS.md) 형식으로 넣습니다. 새 행동이 필요하면 `friendActions.ts`와 `simulation.ts`의 `perform()`에 더합니다.

### 계절과 밤이 행동에는 영향 없음
- 지금: 계절은 바닥 색만 바뀌고, 밤에는 벤치를 더 찾는 것뿐입니다.
- 예:
  - 겨울에는 그네를 덜 타고 벤치에서 더 쉬기
  - 밤에 졸린 표시(그림 없이 기호로)
  - 눈·꽃잎이 날리는 효과

### 지역별 그림·기구
- 지금: 지역마다 배치는 따로 저장되지만, 온천 마을도 정원 기구·장식 그림을 씁니다.
- 할 일: 온천 그림이 준비되면 `regions.ts`의 `ready`를 켜고, 지역마다 쓸 수 있는 기구 목록과 기본 배치를 둡니다.

## 공개 전에

### 메뉴 키보드 조작
- 지금: 지역·계절·노래 목록은 Tab과 Esc만 됩니다.
- 할 일: 방향키 ↑↓로 항목 이동, Home/End를 넣습니다.

### 두 탭 동시 실행
- 지금: 같은 브라우저에서 탭 두 개로 열면 서로의 저장을 덮어씁니다.
- 방법: `storage` 이벤트로 다른 탭의 저장을 알아채고 안내하거나, 한 탭만 쓰게 합니다.
