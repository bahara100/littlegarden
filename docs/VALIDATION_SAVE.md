# 4단계 저장·복원 검증

검증일: 2026-10-15

## 구현 범위

- 적용한 배치와 보관함을 localStorage에 저장. 초안·생활 중 위치·좌석 예약·화면 설정은 제외.
- 앱 식별자 및 버전 1을 갖는 JSON 백업 다운로드/불러오기. 최대 200KB, 최대 160개.
- 불러오기/초기화는 개수를 보여주고 확인 후 실행. 편집 중 비활성화.
- 종류, 좌표, 방향, 크기, ID 중복과 캐릭터 ID 충돌, 겹침, 경계, 좌석 접근 경로 검증.
- 저장 실패 시 화면 안내, 현재 배치 유지 및 파일 백업 가능.
- 손상 저장은 원문을 유지하고 기본 놀이터 표시. 명시적인 새 배치 적용 전에는 덮어쓰지 않음.
- 복원된 placed-N 번호와 충돌하지 않는 새 ID 발급.

## 실제 브라우저 검수

사용자 개발 주소와 분리한 127.0.0.1:4173의 배포 빌드로 검수했다.

1. 나무 추가 → 배치 → 보관 → 변경사항 적용 시 저장 성공 문구 확인.
2. 새로고침 → 저장 복원 문구 및 78개 배치/1개 보관 확인.
3. 파일로 백업으로 JSON 다운로드 확인.
4. 초기화 확인 창 및 취소 동작 확인 후 초기 배치 적용.
5. 다운로드한 백업 선택 → 78개 배치/1개 보관 미리보기 → 확인 후 복원.
6. 다시 새로고침해 동일 개수와 복원 문구 확인. 브라우저 오류/경고 없음.
7. 백업이 아닌 JSON을 고르면 지원하지 않는 형식이라는 안내를 표시하고 현재 배치를 유지함을 확인.

## 사용 한계

브라우저·접속 주소별로 저장된다. 사이트 데이터 삭제, 시크릿 모드 종료 등에 대비해 JSON을 보관한다. 여러 탭에서는 마지막으로 적용한 배치가 저장되며 자동 동기화는 없다. 계정/서버 저장, 화면 설정, 오프라인 진행, 모바일 실기기 성능은 이번 범위에 포함하지 않는다.
