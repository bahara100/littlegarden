# 시제품 검증 기록

검증일: 2026-10-15 · Windows / Node.js 24.14.1

## 통과

- `npm run check`: 클라이언트와 서버 TypeScript 검사.
- `npm run build`: Vite 클라이언트 빌드 및 실행 가능한 서버 JavaScript 출력.
- `npm test`: 5개 테스트 통과.
- 실제 Colyseus 클라이언트 간 이동 상태 공유, 잘못된 이동 입력 무시, 거리 밖 탑승 거부.
- 같은 벤치 좌석의 동시 점유 방지, 탑승 중 이동 제한, 하차 후 반환.
- 다른 사용자에게 인사 모션 전달 및 이동으로 모션 취소.
- 그네 사용 중 입장한 사용자가 기존 탑승 상태 수신.
- 연결 종료 후 좌석 반환, 자동 세션 복귀, 사용자 퇴장, 방 분리.
- 16명 실제 연결과 짧은 동시 이동, 17번째 같은 방 입장 거부.
- `npm audit --omit=dev`: 알려진 취약점 0건.
- 실제 브라우저 두 탭에서 닉네임·방 코드 입장, 두 캐릭터 표시, 키보드 이동, 그네 탑승 확인.
- 브라우저 오류 로그 0건(확인 시점 기준).
- 좁은 미리보기에서 캔버스가 넘치던 문제 수정, PC 1440px 배치 확인.

## 아직 검증하지 않은 항목

- 16명 30분 장시간 부하와 인위적 네트워크 지연/손실.
- 실외 네트워크의 PC 두 대 연결, 실제 GitHub Pages와 원격 서버 배포.
- Docker 이미지 빌드/실행.
- 모바일 실기기 성능 및 터치 이동(터치 조작 미구현).
