# 3단계 꾸미기 검증

검증일: 2026-10-15 · Windows / Node.js 24.14.1

## 구현 범위

- 꾸미기 진입 시 생활 일시 정지. 친구 모델은 편집하는 동안 잠시 숨김.
- 벤치·그네·나무·화단·울타리·길 타일 목록과 실제 모델 미리보기.
- 0.5 단위 위치 맞춤, 마우스/위치 입력, 90도 회전, 이동, 보관, 다시 놓기.
- 초록/빨강 미리보기와 경계·겹침·접근/하차 및 통로 검사.
- 편집 초안과 적용된 배치를 분리. 개별 배치 취소와 전체 변경 취소.
- 적용 시 좌석/예약 해제, 안전한 위치로 재배치, 새 충돌·좌석·접근점·방향으로 생활 재개.
- 추가한 기구는 독립 인스턴스와 좌석 ID를 가짐. 기구를 모두 보관해도 산책 가능.
- 현재 페이지에서만 배치/보관함 유지. 영구 저장은 4단계.

## 자동 검사

- `npm.cmd run check`: 타입 검사 통과.
- `npm.cmd test`: 기존 생활 6개 + 배치 통합 7개 = 13개 통과.
- `npm.cmd run build`: 정적 빌드 성공. 기존 번들 크기 경고는 남음.

배치 테스트:

1. 기본 배치의 겹침 없음과 모든 좌석 접근 가능.
2. 유효하지 않은 미리보기가 적용된 배치를 덮어쓰지 않음. 전체 취소 원복.
3. 회전 시 점유 영역, 좌석/접근 위치, 방향이 같이 변함.
4. 보관 후 복원 시 동일 인스턴스를 유지하고 중복 생성하지 않음.
5. 겹침 및 중앙과 좌석 사이를 막는 울타리 배치 거부.
6. 이용 중 배치 적용 시 예약/탑승 상태 초기화, 회전한 벤치와 그네를 새 위치에서 재이용.
7. 복수 벤치의 독립 좌석 및 모든 기구 제거 후 산책.

기존의 10분 자율 생활 검증은 빠르게 계산한 시뮬레이션 시간이며 실제 기기 장시간 성능 검증과 구분한다.

## 브라우저 검사

- 개발 서버에서 새 나무 초록 미리보기, 숫자 위치 입력, 배치, 보관, 복원, 생활 적용 확인.
- 기존 벤치 클릭 선택 → 이동 → 90도 회전 → 배치 → 적용 후 실제 캐릭터의 앉기 확인.
- 최종 정적 빌드(Vite preview)에서 겹침 오류와 배치 버튼 비활성 확인.
- 새 장식을 놓아 배치 개수가 78에서 79가 된 뒤 전체 변경 취소, 재진입 시 78로 복원 확인.
- 최종 정적 빌드의 오류/경고 로그 0건(확인 시점 기준).
- PC 1440×1100 및 좁은 화면 600×850에서 화면 검수. 600px에서 가로 넘침 없이 꾸미기 패널이 세로로 표시됨을 확인했다.

브라우저 검수에서 초기 배치 그룹의 장면 연결 누락과 위치 입력 반영 문제를 발견해 수정했다. 반복되는 동일 안내 문구는 DOM을 다시 생성하지 않도록 정리했다.

## 제한과 후속 작업

- 저장·내보내기/가져오기·새로고침 복원은 아직 없음.
- 피크닉 소품, 안내판, 중앙 원형 바닥과 바탕 지면은 고정. 길 타일은 가구 아래에 겹쳐 놓을 수 있지만 타일끼리 겹침은 제한.
- 큰 나무의 수관이 아니라 바닥의 몸통/배치 영역을 기준으로 판단함.
- 실기기 장시간 성능·모바일 터치 UX·원격 Pages 배포는 미검증.
