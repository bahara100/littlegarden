# 도트 게임 개발 흐름과 이 프로젝트 점검표

작성일: 2026-10-17. 목적: 게임 개발이 보통 어떤 순서로 진행되는지 정리하고, 이 프로젝트에서 **이미 한 것 / 하다 만 것 / 빠진 것**을 한눈에 보기 위함.

표시: ✅ 됨 · 🟡 일부 · ❌ 없음

---

## 0. 한 줄 요약

**그림보다 "돌아가는 게임"이 먼저다.** 네모·동그라미 같은 임시 도형으로 규칙(걷기, 앉기, 배치, 저장)을 먼저 완성하고, 그 위에 그림을 갈아 끼운다. 그래야 그림을 몇 번 바꿔도 게임이 무너지지 않는다.

일반적인 순서:

1. 기획 — 무슨 게임인지, 시점, 캐릭터 크기, 기구 종류
2. 회색 상자(프로토타입) — 임시 도형으로 규칙부터 동작
3. 아트 규격 → 아트 제작
4. 그림을 게임에 연결
5. 다듬기 — 움직임, 겹침, 소리, UI
6. 테스트·검수
7. 배포
