# 3D 표현 검증 · 1단계

검증일: 2026-10-15 · Windows / Node.js 24.14.1

## 현재 범위

고정 직교 카메라, 마름모 지면, 임시 3D 치비 1명, 벤치와 그네 2종, 화면 이동·줌·선택·표현 설정. 자율 생활·기구 탑승·꾸미기·저장은 후속 단계다.

## 통과한 검사

- `npm run check`: 현재 Three.js 클라이언트 TypeScript 검사.
- `npm run build`: GitHub Pages에 올릴 정적 클라이언트 출력.
- 개발 페이지 HTTP 200, 별도 게임 서버 없이 접속.
- 빌드 결과를 Vite preview로 별도 실행해 정상 렌더링 확인.
- 프로덕션 페이지의 브라우저 오류/경고 로그 0건(최종 확인 시점).
- PC 1440×1050에서 지도와 정보 패널 배치 확인.
- 600×850에서 지도 전체 맞춤과 가로 넘침 없음 확인.
- 실제 캔버스 클릭으로 캐릭터·벤치·그네 정보 변경 확인.
- 선택 시 패널 내용 때문에 지도 크기가 바뀌지 않도록 패널 최소 높이 적용.
- 그네의 가는 프레임/줄을 쉽게 선택하도록 보이지 않는 클릭 영역 적용.
- 인사 버튼, 100% → 132% 확대, 그리드 켜기, 그림자 끄기 확인.
- 화면 이동 모드에서 실제 드래그로 이동, 초기화 후 100% 복귀 확인.
- `npm run check:legacy`, 기존 서버 빌드, `npm run test:legacy`: 보존된 멀티 코드의 5개 테스트 통과. 이는 3D 시뮬레이션 검사가 아니다.
- `npm audit --omit=dev`: 알려진 런타임 취약점 0건.

Three.js의 제거된 그림자 모드 경고를 확인해 지원되는 PCFShadowMap으로 변경했다. 개발 중 HTML과 스크립트가 순차 갱신될 때 발생했던 일시적인 초기화 오류는 최종 정적 페이지에서 재현되지 않았다.

## 아직 확인하지 않은 범위

- 모바일 실기기와 저사양 GPU에서의 성능, 장시간 실행.
- 프레임 레이트 목표의 정량 측정.
- WebGL 컨텍스트 손실/복구의 강제 재현(안내·재시도 처리 코드는 구현).
- 실제 GitHub 원격 저장소와 공개 Pages 배포.
- 자율 이동·기구 탑승·배치·저장: 아직 미구현.

현재 JS 번들은 약 582KB / gzip 148KB다. 빌드의 500KB 청크 크기 경고가 있으나 빌드는 성공한다. 실제 GLB 아트 적용 시 로딩 성능과 분할을 다시 검토한다.
