# 공통 몸체 SE 걷기 V8 후보 · 1번 왼다리 앞 (Pixelorama)

사용자 지시: “v3에서 1번 사진이 현재 오른쪽다리가 앞으로 나가고 왼쪽 다리가 뒤로 뻗고 있어. 왼쪽다리가 앞으로 나가고 오른쪽 다리가 뒤로 뻗어야 순서상으로 맞는 자세야.” 확인 답: “걷는 방향은 그대로 오른쪽 아래야. 앞발은 여전히 오른쪽 아래, 뒷발은 왼쪽 위에 있고, 앞으로 딛는 다리가 왼다리(화면 오른쪽 골반에서 나온 다리), 뒤로 뻗는 다리가 오른다리(화면 왼쪽 골반에서 나온 다리)가 되게 해.”

1번을 Pixelorama MCP로 다시 그렸다(garden-body-se-frame1-v8.pxo). 레이어(아래→위):
- body (V3 1번): 머리·몸·팔·반바지, 행 0~68 그대로.
- front shoe: V3 1번 자신의 앞 신발을 5px 오른쪽으로(오른쪽 아래, 발끝 오른쪽).
- front leg (left): 화면 오른쪽 다리 구멍에서 나와 앞 신발로 내려가는 왼다리.
- back shoe: V3 1번 자신의 뒤 신발(왼쪽 위), 예전 앞다리에 가렸던 옆면에 윤곽.
- back leg (right): 화면 왼쪽 다리 구멍에서 나와 왼쪽 아래 뒤 신발로 가는 오른다리. 가랑이에서 앞다리 위에 그린다.

다리 색은 1번의 피부·윤곽 색만 썼다. 2·3·4번은 V3와 픽셀 동일하다. frame1-pixelorama.png가 Pixelorama 출력이고, tools/art/build-garden-body-walk-se-v8.py가 이를 1번으로 시트·미리보기·GIF를 만든다.
