# 독립 앉기 시안 V1 · 별도 보관

머리와 몸 비율을 정지 V2에 맞추고 허벅지가 앞으로 나온 앉기 한 컷을 제작했다. 사용자가 **“이건 따로 저장해두고 모모, 루루가 앉았을때 자세로 베이스 몸체 만들어볼래?”**라고 요청해 이 시안을 별도로 보관한다. 모모·루루 참고 시안과 혼동하지 않는다.

- SE 원본: `sit-se.png`, `garden-body-sit-se-v1.pxo`.
- SW: 전신 좌우 반전 `sit-sw.png`, `garden-body-sit-sw-v1.pxo`.
- 96×96, 방향당 정지1컷, 기존 머리와 공유 팔레트. 의자·그림자 없음. 게임 미연결.
- 도구: 내장 image_gen 초안 → Pixelorama 기존 팔레트/머리 적용 → 전신/머리/몸 PNG 출력.
- 확인 페이지: `apps/client/public/body-sit-se-v1/index.html`.

현재 새 후보는 `garden-body-sit-friends-v1/`이다. 이 V1을 자동으로 승인/적용하지 않는다.
