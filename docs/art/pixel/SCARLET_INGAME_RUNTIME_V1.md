# 승인 SD 걷기 게임 연결 · 2026-10-17

사용자 요청 “응 연결해줘”에 따라 기본 Phaser 놀이터와 `?renderer=canvas` 호환 화면에 새 SD를 연결했다.

- 런타임 폴더: `apps/client/public/sprites/scarlet/ingame-approved-v1/`.
- SE 걷기는 `scarlet-ingame-walk-se-v1/walk.png`, NE는 `scarlet-ingame-walk-ne-v9/walk.png`의 바이트 그대로 복사했다. 대기는 `scarlet-ingame-sd-v1/idle-se.png`, `idle-ne.png`를 쓴다.
- SW는 SE, NW는 NE를 **잘라낸 컷마다 반전**한다. 비대칭 장비도 함께 반전하며 순서는 항상1→2→3→4다.
-96×96,4컷, 기준점(48,88), 기본6 FPS. 원본 픽셀은 수정하지 않았다. 과거 `?scarlet=...` 검수 모드와 자산은 보존한다.
- 공통 설정/재생기: `apps/client/src/scarletApproved.ts`. 크기는3.9칸, 한 컷당 이동 거리의 초기 보정값은 원본 가로4px에 해당하는0.1625칸, 속도0.975칸/초다. 실제 이동한 거리에 따라 컷을 넘기며, 정지하면 대기 그림으로 돌아간다. 방향 전환은 같은 걸음 순서를 유지한다. 이 보정은 모든 접지 픽셀의 완전한 고정을 보장하는 것은 아니다.
- 꾸미기 중에는 이동을 멈추며, 모션 줄이기 설정에서는 대기 그림을 유지한다.
- 홍련의 예전 앉기 그림은 긴 머리/다른 의상이라 새 SD와 섞지 않는다. 벤치/그네 접근·이용·내려오기는 유지하되 **새 SD 대기를 들어 올리는 임시 표시**다. 새 외형의 앉기 전용 모션은 아직 제작하지 않았다. 친구들의 앉기는 기존대로다.
- 게임의 “홍련 외형·동작 살펴보기”는 같은 런타임 시트를 읽는 `sprites/scarlet/ingame-approved-v1/review.html`로 연결한다.

검증: 타입 검사,생활/자산/재생 테스트32개,프로덕션 빌드 통과. SHA256으로 승인 걷기 원본과 런타임 파일의 동일성, 대기 원본의 바이트 동일성을 검사한다.30/60/120Hz에서 같은6 FPS 순환, 이동 없는 경우 프레임 고정, 정지 후 초기화, 다른 친구/과거 모드의 이동 속도 유지도 검사했다. 브라우저에서 Phaser/Canvas의 새 외형, 직접 바닥 클릭 이동, 앞·뒤 방향 표시, 기구 이용 후 외형 유지와 새 검수 링크를 확인했다.

로컬 확인: 게임 `http://127.0.0.1:4185/`, 별도 제작 검수 서버 `http://127.0.0.1:4184/`는 유지한다. 새 게임 서버는 `npm.cmd run dev --workspace apps/client -- --port 4185 --strictPort`로 실행했다.
