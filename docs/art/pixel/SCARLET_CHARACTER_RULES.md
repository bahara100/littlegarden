# 홍련 도트 외형 기준

사용자 교정 사항을 이후 방향·모션 제작에서도 유지한다.

- 긴 뒷머리는 풀어 내린 형태다.
- 아래 끝부분만 **등 뒤 중앙, 척추 중심선의 뒤쪽 한곳**에서 모아 묶는다.
- 양갈래·옆머리 묶음·옆으로 떨어지는 포니테일이 아니다.
- 매듭을 보여주려고 몸 옆으로 옮기지 않는다. 앞 대각선에서 매듭이 몸과 옷에 가려져도 된다.
- 양옆에 보이는 머리카락은 중앙 뒤쪽으로 이어지는 풀린 머리다. 두 개의 독립된 꼬리처럼 끝나면 안 된다.
- 삿갓의 끈과 술 장식은 머리 묶음과 별개다.
- 검은 캐릭터 왼쪽 허리에 한 자루만 찬다. 자루·작은 코등이·길고 가는 짙은 칼집·끝의 금색 마감이 같은 축으로 이어져야 한다. 뒤쪽에서도 칼집이 사라지거나 별도 손잡이처럼 끊겨 보이면 안 된다.
- 카메라는 위에서 내려다보는 마름모 맵의 대각선 시점이다.
- 기본 규격은 96×96, 고정 팔레트 최대 32색, 발 기준 (48,88), 좌상단 광원이다.
