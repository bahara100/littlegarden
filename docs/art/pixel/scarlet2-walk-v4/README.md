# 홍련2 걷기 V4 · 팔 스윙 복원 · 사용자 검수 전

검수: http://127.0.0.1:4185/scarlet2-walk-v4/index.html

사용자가 V3의 팔 움직임이 사라졌다고 지적했다. 양팔이 공통 상체 아래에 깔리고 회전 폭도 작아, 픽셀이 조금 변해도 실제로는 팔이 멈춘 것처럼 보였다. V3의 동작 검사 통과를 작화 승인으로 취급하지 않는다.

- 레이어 순서: 다리 → 먼 팔 → 공통 상체 → 가까운 팔. 가까운 팔 전체가 상체 앞에 표시된다.
- 승인 정지 팔의 어깨/팔꿈치/손을 행별 마스크로 분리하고, 위팔과 아래팔을 각각 회전해 네 자세를 만든다. 손은 축소하지 않는다. 원래 팔이 남아 중복되지 않게 상체의 정지 팔 잔여 부분을 제거하고 장비 뒤를 보완했다.
- 머리부터 허리까지 공통 원화는 네 컷에서 같은 방향을 유지하고 2·4번에만 함께 y−1px 움직인다. 기존 다리 네 자세와 부츠를 사용한다.
- 팔을 제거하면서 끊어진 칼집-허리 연결부를 원래 흰색/금색/외곽선 팔레트로 연결했다. 무기 디자인을 새로 생성하지 않았다.
- SE/NE 방향별128px·4프레임·6FPS·4레이어 .pxo. SW/NW는 각 전신 프레임의 전체 반전이다. 실제 검수 재생은 전신 PNG 교체이며 팔을 따로 변환하지 않는다.
- `build-scarlet2-walk-v4.gd`를 Pixelorama 새128px 프로젝트에서 dir=se/ne로 한 번 실행한다. 생성한 legs/far/core/near-sheet를 각각 레이어0/1/2/3에128px·4프레임으로 가져온 뒤 .pxo와 editor PNG를 내보내고 `py tools/art/package-scarlet2-walk-v4.py` 실행.
- V3/V4 동기 재생, 팔·어깨 확대, 1~4번 선택, 네 방향 동시 확인을 제공한다. 보존401파일 SHA, 공통 상체 동일성, 앞 팔 가림 순서, 편집기/PNG 합성, 팔 변화, 연결·색·반전 및 브라우저 검사를 기록한다.
- 새 AI생성 없음. 이전 그림·승인 베이스와 실제 게임은 보존한다. 새 팔 작화는 사용자 검수 전이다.
