# 공통 몸체 뒤쪽 앉기 V1 · 사용자 검수 전

사용자가 “베이스 몸체의 앉은 자세 뒷모습을 작업하자”라고 요청했다. 기존 모모·루루 참고 앞쪽 앉기의 짧고 가까운 다리·몸 가까이 모은 팔을, 뒤오른쪽 NE에서 보이는 등·목덜미·골반·접힌 다리로 새로 만들었다. NW는 전신 전체의 정확한 좌우 반전이다.

내장 image_gen으로 **전신 한 컷**을 생성했다. `source-sit-ai.png`가 생성 원본, `prompt.txt`가 실제 지시문이다. Pixelorama에서 머리 폭 48px, 머리 위 y5 기준으로 **전신을 함께 축소**하고, 기존 앞쪽 앉기에 실제 쓰인 18색 팔레트에 맞췄다. 머리·다리를 따로 붙이거나 팔다리를 도형으로 새로 그리지 않았다. 머리를 걷기 원본에서 복사했다고 주장하지 않는다.

최종 `sit-ne.png` / `sit-nw.png`는 96×96, 알파0/255, 방향별 정지1컷이다. 편집 원본 `garden-body-sit-ne-v1.pxo`는 NE 한 프레임·머리/몸 2레이어이며 완성 전신을 행52에서 손실 없이 나눴다. 반전된 머리·몸 PNG도 포함한다. 확대 PNG와 실제 PNG는 같은 도트다.

- 작화/내보내기: `tools/art/garden-body-sit-ne-v1.gd` (Pixelorama MCP)
- 포장/기술검사: `py tools/art/package-garden-body-sit-ne-v1.py`
- 검수 페이지: `/body-sit-ne-v1/index.html` (개발 서버)
- 기존 앞쪽 앉기, 승인 SE V20, 사용자 수동 수정 NE V8, 모모·루루 게임 V2는 변경하지 않았다.
- 게임·의상·앉고 일어서는 전환·실제 좌석 높이는 이번 시안에 연결하지 않았다.

앞/뒤 방향과 앉은 형태의 승인은 사용자 검수 사항이다. 레이어 합성·팔레트·투명도·반전·픽셀 연결 검사는 작화 승인을 뜻하지 않는다.
