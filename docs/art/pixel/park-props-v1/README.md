# 공원 기구·물길 6종

사용자 요청: 피크닉 테이블, 시소, 음수대, 분수대, 작은 나무다리, 시냇물 제작.

기존 `playground-props-v1.png`를 스타일 참고로 built-in **imagegen**으로 각각 생성했다.
따뜻한 목재·세이지색·크림색 돌·청록 물, 2:1 아이소메트릭 시점, 투명 배경.
정확한 생성 프롬프트 6개는 [prompts.json](prompts.json), 생성 원본은 `originals/`에 보존한다.

128×128 투명 PNG, 개별 최대 64색. 기존 기구와 같은 크롭/아래 가운데 정렬,
저알파 주변광 정리와 nearest-neighbour 축소를 사용했다. 이것을 수작업 도트로 다시 그렸다고 표현하지 않는다.
게임 자산: `apps/client/public/sprites/garden/park-props-v1/`.
재현: `python tools/art/package-park-props-v1.py`.
SHA256·원본 크롭·축소 크기는 `manifest.json`에 기록했다.

| 기구 | 배치 칸 | 이번 기능 |
| --- | --- | --- |
| 피크닉 테이블 | 4×3 | 회전·장식 배치 |
| 시소 | 4×1 | 회전·장식 배치 |
| 음수대 | 1×1 | 회전·장식 배치 |
| 분수대 | 3×3 | 회전·장식 배치 |
| 작은 나무다리 | 4×2 | 물 위 중첩 배치·길 찾기 통로 |
| 시냇물 | 4×2 | 바닥에 표시·동일 방향 직선 연결·물 진입 차단 |

모든 기구는 기존 꾸미기의 이동·회전·보관·되돌리기·저장·백업을 사용한다.
원본 대각선과 좌우 반전을 사용하므로 0/2번 회전, 1/3번 회전은 같은 작화다.
다리만 물 장애물을 잘라 통로를 만들며 다른 기구는 물과 겹칠 수 없다.
물속 진입을 막는 여유 폭은 기존 .34칸 발 반경을 그대로 사용한다.

이번은 정지 그림이다. 시소 타기·물 마시기·테이블 앉기 및 물줄기 애니메이션은 아직 없다.
물길의 꺾이는 모서리·갈림길·자연스러운 끝 마감은 별도 타일이 필요하며 이번은 직선 조각이다.
다리 난간 앞/뒤 분리 작화는 후속 보정 대상이다.
기본 배치는 자동으로 바꾸지 않으며 실제 저장된 공원도 유지했다.

검수 URL: `/park-props-v1/index.html`(6종과 방향 반전).
실제 게임은 `/` → 놀이터 꾸미기 → 기구 목록.
시험용 배치 화면: `game-phaser.png`, `game-canvas.png`.

검증: 생활/배치 단위 검사 **67개 통과**, Phaser·Canvas 각각 신규 기구 렌더링,
추가·회전·보관·되돌리기·적용·새로고침 복원 화면 검사 **2개 통과**. 빌드에 PNG 6개 포함 확인.
