# 홍련2 걷기 V2 · 머리/몸통 중심 보정 · 사용자 검수 전

검수: http://127.0.0.1:4185/scarlet2-walk-v2/index.html

V1의 프레임별 의상 중심과 허리 높이가 달라, 같은 위치의 승인 머리 아래에서 몸통이 따로 흔들렸다. 새 그림 생성 없이 기존 Pixelorama 도트를 정렬했다.

- 앞쪽 몸통 이동 x: −3 / +3 / −1 / +2px. 목 기준 x62.
- 뒤쪽 몸통 이동 x: +2 / +5 / +1 / +5px. 뒤 머리의 목덜미 기준 x66. 앞쪽과 같은 목 위치를 강제로 쓰지 않는다.
- 앞 허리 기준 y88, 뒤 허리 기준 y85. 2·4번은 머리/목/허리 모두 함께 y−1px. 목→허리와 허리→기존 발끝을 연속된 두 구간으로 맞췄다. 별도 하체 그림을 붙이지 않았다.
- 머리/갓은 V1과 픽셀 동일. 의상·부츠·칼집은 기존 도트를 최근접 좌표로 옮긴 것이며 새 색이나 새 디자인은 추가하지 않았다. 좌표 보정 중 행이 반복/생략되므로 몸통/하체의 모든 픽셀이 원본과 동일하다는 뜻은 아니다.
- 128px, 방향당4컷, 6 FPS, 2레이어 .pxo 두 개. SW/NW는 컷별 전체 반전.
- 재현: `build-scarlet2-walk-v2.gd`를 새4프레임/2레이어 프로젝트에서 dir=se/ne, frame=0..3, part=body/head로 실행하고 editor PNG를 내보낸 후 `py tools/art/package-scarlet2-walk-v2.py`를 실행한다.
- V1/승인 정지/앉기/수동 베이스 등249파일 SHA 보존, 편집기/PNG 일치, 알파·64색·연결·반전 및 브라우저 재생/모바일 검사를 기록했다.
- V2는 새 사용자 검수 후보다. 게임 연결과 기존 캐릭터는 변경하지 않았다. 기술 검사 통과는 동작/작화 승인과 다르다.
