사용자 지적: “V8 1번에서 고칠 게 있어. 다리 굵기랑 표현은 비슷하게 따라가야지.” V8 다리는 굵기가 일정한 가는 관 모양이라 다른 컷과 달랐다.

V9 1번은 V8과 같은 배치(걷는 방향 오른쪽 아래, 앞발 오른쪽 아래·뒷발 왼쪽 위, 앞으로 딛는 다리는 화면 오른쪽 골반에서 나온 왼다리, 뒤로 뻗는 다리는 화면 왼쪽 골반에서 나온 오른다리)이다. 다리는 3번 자신의 다리 그림을 옮겨 Pixelorama MCP로 조합했다(garden-body-se-frame1-v9.pxo).
- body (V3 1번, 행 0~68) 그대로.
- front leg (left): 3번 앞다리(굵은 허벅지·무릎 명암·신발)를 5px 오른쪽으로 옮겨 화면 오른쪽 다리 구멍에서 나오게 했다.
- back leg (right): 3번 뒷다리 정강이와 들린 신발을 제자리에 두고, 화면 왼쪽 다리 구멍 아래의 3번 허벅지 픽셀로 이었다. 가랑이에서 앞다리 위에 그린다.
