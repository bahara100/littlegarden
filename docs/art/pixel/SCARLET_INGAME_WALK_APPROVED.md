# 홍련 인게임 SD 걷기 최종 승인

2026-10-17 사용자가 “좋아. 여기까지 캐릭터 걷기 모션은 완성이야.”라고 확정했다. 이후 작업은 이 기록과 scarlet-ingame-walk-approved.json의 승인 자산을 기준으로 진행한다.

| 방향 | 확정 원본 | 처리 |
| --- | --- | --- |
| 앞오른쪽 SE ↘ | scarlet-ingame-walk-se-v1/walk.png | 그대로 재생 |
| 앞왼쪽 SW ↙ | 같은 SE 시트 | 컷별 좌우 반전 |
| 뒤오른쪽 NE ↗ | scarlet-ingame-walk-ne-v9/walk.png | 그대로 재생 |
| 뒤왼쪽 NW ↖ | 같은 NE 시트 | 컷별 좌우 반전 |

공통 규격은96×96 전신4프레임, 시트384×96, 기본6 FPS, 투명 배경, 공유24색 이하, 기준점(48,88)이다. 각 컷을1→2→3→4 순서로 자르고 재생한다. 시트 전체를 뒤집어 컷 순서까지 역전하지 않는다. 사용자 결정대로 반전 방향에서는 비대칭 의상/무기 위치도 함께 반전한다.

NE는3번 보폭/칼집 보정과4번 화면 왼쪽 접힘·화면 오른쪽 지지,2번을 참고한 접힌 발, 기존 칼집 복원 및 연결부 미세 보정까지 반영한V9다. 이전 후보/생성 원본을 현재 승인본으로 다시 사용하지 않는다.

승인 시트와 모든 개별 프레임의 SHA256은 scarlet-ingame-walk-approved.json에 기록했다. 별도 요청 없이 외형/의상/프레임 수/보폭/무기를 재생성하거나 이전 버전으로 되돌리지 않는다.

후속 사용자 요청에 따라 메인 Phaser/Canvas 게임에도 연결했다. 런타임 PNG는 승인 원본과 바이트 동일하며 연결 기록은 SCARLET_INGAME_RUNTIME_V1.md다. 게임 확인 주소는 http://127.0.0.1:4185/ 이며 별도 제작 검수 화면(4184)도 유지한다. 새 SD 앉기 전용 그림은 별도 후속 작업이다.
