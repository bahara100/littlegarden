# 뒤왼쪽(NW) 전신 걷기 4컷

2026-10-16. 기존 SE/SW/NE와 같은 96×96, 4프레임, 6 FPS 규격으로 추가한 사용자 검수본이다. 다른 세 방향의 그림은 변경하지 않았다.

## 결과
- 런타임: `apps/client/public/sprites/scarlet/fullframe-nw-v1/walk.png` (384×96).
- 실제 재생 컷 정지 미리보기: 같은 폴더의 `walk-preview-2x2.png` (768×768).
- 제작 기준: 같은 폴더의 `source-keys.png` (최종 순서의 원본 해상도).
- 검수 주소: `/scarlet-frames.html?direction=nw`.
- 놀이터: `/?scarlet=frames-four-v1`. 기존 NE 시험 주소에서도 NW 보행을 함께 불러온다.

## 제작
내장 image_gen 사용. 참고 이미지는 NE V5 최종 source-keys.png(외형과 화풍)와 기존 NW 기본 자세(방향)다. 단순 좌우 반전하지 않았다.

첫 생성 요청: 투명 배경의 2×2 전신 시트, 모두 화면 좌상으로 향하는 후면 대각선 시점, 왼다리 검은 교차 끈/오른다리 흰 스타킹 유지, 중앙 머리 끝 한 묶음, 왼쪽 허리 칼집, NW 시점의 좌하→우상 갓 뿔 축, 접지/통과/반대 접지/반대 통과 네 자세. 원본은 source-draft.png에 보존했다.

첫 생성본의 두 접지 자세가 비슷해 3번만 반대 보폭으로 수정 요청했다. 흰 오른다리는 진행 방향으로, 검은 왼다리는 뒤로 뻗으며 원래 골반 연결을 유지하도록 요청했다. source-contact-edit.png의 아래 왼쪽 셀만 채택하고 다른 셀은 최초 원본을 유지했다. 통과 자세의 실제 발에 맞춰 최초 셀 1·4·수정3·2를 최종 1·2·3·4로 정렬했다. 생성 도구에 자동 표시된 중간 결과는 최종 재생 순서와 다르므로 사용자에게 최종본으로 제시하지 않는다.

`tools/art/export-scarlet-nw-keys.ps1`로 합성·순서 정리·공통 축소·팔레트 변환·패킹한다. 독립적인 셀별 확대 축소나 런타임 관절 회전을 사용하지 않는다. 네 컷은 같은 축소율 0.1423611111, 32색, 발바닥 y=87, 기준 (48,88)이다. 서로 다른 프레임 해시와 알파 배경을 보존한다.

규격 검사와 미리보기 픽셀 대조를 수행한다. 이는 사용자에 의한 보행 자연스러움 최종 승인을 뜻하지 않는다. 검수 시 같은 다리의 골반→무릎→발, 칼집 연속성, 머리 묶음, 4→1 연결을 함께 확인한다.
