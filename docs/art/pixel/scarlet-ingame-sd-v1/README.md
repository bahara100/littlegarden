# 실제 인게임 SD 기준 첫 도트 시안

## 현재 확인 상태

사용자가 SE 첫 시안을 “좋아 퀄리티 좋게 나왔어”라고 확인했다. 이후 뒤쪽 진행 요청에 따라 NE 정지 한 컷을 추가했다. NE는 사용자 확인 전이다. 걷기 프레임과 현재 게임 자산 교체는 아직 하지 않았다.

### 추가한 뒤쪽 컷

- `source-ai-ne.png`: 승인한 SE 도트/밑그림과 실제 인게임 SD 뒷모습·옆모습 캡처를 내장 image_gen으로 참고하여 생성한 뒤오른쪽 픽셀 스타일 밑그림.
- `prompt-ne.txt`: 뒷머리의 둥근 덩어리와 짧은 목덜미 끝, 흰 허리 리본, 간단한 칼집, 앞쪽과 같은 짧은 몸 비율/디테일을 유지하도록 요청한 정확한 생성 프롬프트.
- `idle-ne.png`: 96×96, 공통 24색 팔레트 중 실제 22색 사용, 알파0/255, 최하단87행.
- `idle-ne-preview-6x.png`: NE 실제 PNG의 최근접6배 확대, 픽셀 차이0.
- `idle-pair-preview-6x.png`: 왼쪽 SE / 오른쪽 NE 실제 PNG만 최근접6배로 나란히 표시했다. 승인한 SE 파일의 SHA256이 `approved-se.sha256`과 일치함을 검사했다.
- `export-ne.json`: NE 규격/팔레트/소스 영역/축소율과 표시물 일치 검사 기록.

재현: `tools/art/export-scarlet-ingame-sd-v1.ps1 -Direction ne`, `tools/art/pack-scarlet-ingame-sd-pair.ps1`. 이 작업도 AI 밑그림을 정지 도트 규격으로 변환한 시안이며 Pixelorama 수작업 보정이나 보행 완성으로 보고하지 않는다.

사용자가 직전 AI 초안의 디테일이 많다고 지적한 뒤 인게임 SD 캡처 4장을 제공했다. 이전 상세 일러스트/피규어 기반의 긴 비율 대신 이 캡처의 큰 머리·작은 몸·짧은 다리와 간결한 장비를 기준으로 삼았다.

## 현재 결과

- `source-ai.png`: 캡처 4장을 참고해 내장 image_gen으로 생성한 픽셀 스타일 밑그림. 정확한 요청은 `prompt.txt`다.
- `idle-se.png`: 앞쪽 대각선 1컷, 96×96, 투명 PNG. 아직 외형을 확인할 첫 시안이며 보행 시트가 아니다.
- `idle-se-preview-6x.png`: 실제 96×96 결과를 최근접 6배로 확대한 576×576 미리보기. 원본과 픽셀 대조 차이 0.
- `palette.json`: 이 시안의 24색. 새 캡처의 흰색/회색·회보라색 머리·보라 장비·검정 띠·금색 장식을 위해 별도로 정했다.
- `export.json`: 소스의 사용 영역, 고정 축소율, 96×96 규격, 바닥 행(87), 색 수와 알파 검사 기록.

재현 도구: `tools/art/export-scarlet-ingame-sd-v1.ps1`. 생성한 밑그림을 투명도 기준으로 맞추고 최근접 표본과 고정 24색으로 변환했다. 이 단계는 Pixelorama에서 수작업 보정한 완성 도트라고 보고하지 않는다. Pixelorama 브리지는 현재 연결되지 않아 .pxo 파일은 만들지 않았다.

## 남긴 특징

둥근 짧은 뒷머리와 긴 앞쪽 옆머리, 납작하고 넓은 흰 갓, 금색 두 갈래 장식, 간단한 흰 밧줄/솜과 작은 패찰, 검정 어깨띠, 보라색 허리 장비, 짧은 비대칭 흰 다리/부츠, 허리에서 뒤로 이어지는 흰 칼집을 남겼다. 기존 창작 SD의 검은 X 스타킹·끝머리 묶음·커다란 빨간 띠를 쓰지 않았다.

현재 게임의 기존 자산은 교체하지 않았다. 다음은 이 한 컷의 비율과 단순화 수준을 확인한 뒤 Pixelorama에서 필요한 윤곽/색 덩어리를 보정하고, 뒤쪽 원본 및 걷기 4프레임으로 확장하는 단계다. SE/NE 두 원본을 그려 SW/NW를 전체 반전하는 최신 사용자 결정은 유지한다.
