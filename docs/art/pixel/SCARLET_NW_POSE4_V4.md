# NW V4: 4번 통과 자세

사용자는 V3에서 4번 때문에 보행이 부자연스럽다고 지적했고, 오른다리가 흰색이라는 기준을 재차 강조했다. 최신 검수본은 `fullframe-nw-v4/walk.png`이며 4프레임·6 FPS를 유지한다. 사용자 최종 승인 전이다.

4번만 수정했다. 흰 스타킹의 오른다리는 체중을 받으며, 검은 교차 끈의 왼다리는 무릎을 덜 굽혀 낮게 통과한다. 높이 든 발바닥이 크게 보이던 자세를 낮은 옆모습 발로 바꾸고 두 발을 몸 아래로 모았다. 의상은 골반에서 이어지는 다리에 고정하며, 발의 화면 좌우만 보고 의상을 교환하지 않는다.

1·2·3번 PNG는 V3와 바이트 동일하다. 4번 y0..49는 V3와 픽셀 동일하며 그 아래만 교체했다. 기존 공통 축소율/샘플링 위치를 유지한다.

내장 image_gen으로 기존 4번만 자른 `source-pose4-before.png`를 편집했다. 최종 요청은 다음과 같다: 오른쪽 골반에서 이어지는 흰 스타킹 오른다리를 지지 다리로 유지하고, 왼쪽 허리 칼집 아래의 검은 교차 끈 왼다리는 높이 찬 발을 낮은 통과 자세로 바꾸기. 검은 왼쪽 종아리의 교차 끈을 보이게 하고 흰 오른쪽 종아리는 흰색으로 유지하기. 모자·머리·상체·칼집·카메라·크기는 유지하며 한 컷과 투명 배경만 출력하기.

편집 원본 `source-pose4-edit.png`는 한 컷이다. 캔버스 전체를 원래 셀 크기로 정규화한 뒤 해당 셀의 하부만 기존 시트와 합쳤다. 재현 도구는 `tools/art/export-scarlet-nw-pose4-v4.ps1`다. 다음 수정의 기준은 합성된 `source-keys.png`이며, 사용자에게 보여줄 최종 네 컷은 실제 재생 시트에서 만든 `walk-preview-2x2.png`다.

자동 검증: 1·2·3번 PNG 해시 동일, 4번 상부 변경 0, 최대 32색, 실제 시트와 표시용 미리보기 픽셀 불일치 0. 자동 검사만으로 보행 자연스러움이나 사용자 승인을 단정하지 않는다.
