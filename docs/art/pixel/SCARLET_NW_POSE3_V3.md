# NW V3: 1번과 구분되는 반대 접지 자세

사용자는 V2의 1·3번이 같은 자세로 보여 움직임이 부자연스럽다고 지적했다. V2는 승인본이 아니다.

최신 재생본은 `fullframe-nw-v3/walk.png`, 최종 정지 미리보기는 같은 폴더의 `walk-preview-2x2.png`다. 방향당 4프레임, 기본 6 FPS는 유지한다.

1·2·4번 PNG는 V2에서 바이트 그대로 복사한다. 3번만 수정하며 y0..39는 V2와 픽셀 동일하다. 원래 공통 축소율과 샘플링 좌표를 유지한다. 실제 프레임 교체는 `tools/art/export-scarlet-nw-pose3-v3.ps1`로 재현한다.

내장 image_gen 편집의 최종 요청: V2 최종 순서 source-keys.png를 기준으로 아래 왼쪽 3번만 반대 접지 자세로 다시 그린다. 흰 오른다리가 진행 방향으로 나가 화면 왼쪽 위에 닿고, 검은 교차 끈 왼다리는 뒤로 뻗어 화면 오른쪽 아래에 닿는다. 골반에서 발까지 원래 의상을 유지한 채 투영상 다리가 교차할 수 있어야 한다. 보폭은 모자와 치마 폭 안의 작은 걸음으로 유지한다. 팔과 허리는 반대 보폭에 맞춰 조정하되 모자/머리 상부와 다른 세 컷은 유지한다. 칼집은 왼쪽 허리의 한 자루로 유지한다. 투명 배경, 같은 2×2 배치.

NW V2에서 화면 왼쪽에 검은 다리, 오른쪽에 흰 다리를 계속 묶어 두려던 제약은 잘못된 접근이었다. 고정해야 할 것은 화면의 좌우 영역이 아니라 **캐릭터 자신의 골반→허벅지→무릎→발의 의상 소유권**이다. 3번처럼 다리가 교차하는 투영에서는 검은 왼발이 화면 오른쪽, 흰 오른발이 화면 왼쪽에 올 수 있다. 화면 위치만으로 해부학적 좌우를 판정하지 않는다.

최종 생성 원본은 source-pose3-edit.png이며 3번 일부만 채택했다. 이후 참고는 합성된 source-keys.png다. 사용자에게 중간 생성 시트를 최종본으로 제시하지 않는다. 검사: 1·2·4 PNG 해시 일치, 3번 상부 픽셀 변경 0, 최대 32색, 최종 미리보기/재생 시트 픽셀 불일치 0. 이 기록은 사용자 최종 승인을 뜻하지 않는다.
