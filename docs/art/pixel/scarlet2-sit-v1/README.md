# 홍련2 · 앉기 4방향 V1

사용자가 정지 4방향을 좋게 확인하고 앉은 자세를 요청했다. 기존 홍련2 정지 그림·팔레트·편집 원본과 공통 베이스, 게임의 홍련·모모·루루는 유지한다. 이 결과는 별도 앉기 시안이며 아직 게임 기구에 연결하지 않았다.

## 제작

- 앞 베이스: `garden-body-sit-friends-v1/sit-se.png`, 뒤 베이스: `garden-body-sit-ne-v1/sit-ne.png`. 각각96×96에(16,24)여백을 붙인128×128 기준으로 작업했다.
- 정지의 실제 상단 머리/갓 레이어를 재사용했다. SE는 같은 좌표, NE는 앉기 목 중심에 맞춰 **x−3px, y변경 없음**으로 옮겼다. 크기·색·픽셀은 바꾸지 않았다. 레이어 구분선 아래의 일부 옆머리 끝은 상체 의상 영역에 포함되므로 전체 머리의 모든 픽셀이 정지와 동일하다는 의미는 아니다.
- 내장 ImageGen에 이 머리와 공통 앉기를 조합한 편집 대상 및 승인 정지 의상을 입력해 앞/뒤 의상을 별도로 만들었다. [앞쪽 프롬프트](prompt-se.txt), [뒤쪽 프롬프트](prompt-ne.txt), 실제 생성 원본은 `source-sit-ai-se.png` / `source-sit-ai-ne.png`다. 두 생성 원본을128px로 전체 축소하고 NE 의상은 y+1px로 맞췄다. 생성된 머리는 최종에 쓰지 않고 기존 머리 레이어로 복원했다.
- Pixelorama에서 기존48색 팔레트를 공용으로 써 앞·뒤 의상을 앉은 몸에 맞추고, 베이스의 짧은 다리·발에 흰 의상·부츠를 입혔다. 의상의 무릎 위/허리 장비는 베이스에 겹치며 행103 이후 최종 발 실루엣은 베이스와 정확히 같다. 앞쪽은 모은 손과 접힌 무릎, 뒤쪽은 등·허리 리본과 오른쪽으로 접힌 다리이며 칼집은 각각 허리 뒤로 이어진다.
- SE/NE 각각 한 프레임·3레이어 `.pxo`: 다리 / 의상·칼집 / 기존 머리·갓. SW/NW는 완성 전신의 정확한 좌우 반전이다.

## 결과와 검증

검수: `/scarlet2-sit-v1/index.html`. 정지 페이지에도 앉기 링크가 있다. 같은 배율의 베이스·정지·앉기 비교 및4방향 모아보기를 제공한다.

- `sit-se.png`, `sit-sw.png`, `sit-ne.png`, `sit-nw.png`: 실제128×128 투명 PNG.
- `sit-four.png`: 위 SE/SW·아래 NE/NW 순서의256×256 시트. `sit-four-preview.png`는 실제 시트의 최근접3배 확대다.
- `scarlet2-sitting-authoring.zip`: 네 방향 PNG·레이어·두 편집 원본·팔레트·두 프롬프트·기술 기록.
- `manifest.json`: 정지/원본 보존, 머리 레이어 재사용, 발 실루엣, 팔레트, 레이어 합성 검증 기록. `preserved-sources.json`은 시작 시점의 정지/베이스 해시다.
- `browser-review.png`, `browser-mobile.png`: 실제 검수 페이지 확인 자료.

재현: `tools/art/build-scarlet2-sit-v1.gd`를 새 Pixelorama128px 프로젝트에 방향별 다리/의상/머리 파트로 실행하고 `.pxo`와PNG를 내보낸 뒤 `py tools/art/package-scarlet2-sit-v1.py`를 실행한다.

검사 통과는 사용자 작화 승인과 다르다. 새 앉기는 검수 대상이며, 실제 좌석의 위치·앉는 높이·앞뒤 가림·앉고 일어나기 전환·걷기·게임 연결은 이후 단계다.
