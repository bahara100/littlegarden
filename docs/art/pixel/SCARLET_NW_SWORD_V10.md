# NW V10: 기존 칼을 기준으로 2번 누락 복원

사용자가 V9 다리에 “이제 좀 낫네”라고 한 뒤 허리춤 칼을 제대로 그려 넣도록 요청했다. 최초 생성에서 손잡이·칼집의 길이와 각도까지 새로 설계한 긴 칼이 나왔으나, 사용자가 “갑자기 칼을 아예 새로 만들면 어떡해. 기존꺼 참고 안해?”라고 지적했다. 이 긴 칼 생성본은 런타임에 적용하지 않았다. 해당 요청 기록은 rejected-redesign-prompt.txt이며 후속 기준으로 쓰지 않는다.

최종 작업은 기존 V9의 1·3·4번 칼 모양과 NE V5를 참고하여 **2번에서 빠진 같은 형태의 검은색/금색 칼 부분만 복원**했다. 전체 칼의 새 디자인을 만들거나 다른 컷을 다시 그리지 않았다. 내장 image_gen을 사용했으며 실제 요청은 fullframe-nw-v10/edit-prompt.txt다.

재현 도구 tools/art/export-scarlet-nw-sword-v10.ps1은 2번의 칼 주변 좁은 다각형 영역만 합성한다. 1·3·4번 PNG는 V9와 바이트 동일하다. 2번도 해당 영역 밖은 V9 그대로다. 다리의 흰 오른쪽/검은 왼쪽 의상과 가림 관계, 4프레임·6 FPS 규격은 유지한다.

후속 기준: fullframe-nw-v10/source-keys.png. 실제 재생: walk.png. 사용자 표시물: 실제 시트에서 만든 walk-preview-2x2.png 및 walk-preview.gif. PNG/GIF 픽셀 일치 검사는 표시 일관성 확인이며 사용자 최종 승인과 구분한다.
