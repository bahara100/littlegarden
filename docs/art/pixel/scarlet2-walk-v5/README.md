# 홍련2 걷기 V5 · 승인 베이스 팔 도트 적용 · 사용자 검수 전

검수: http://127.0.0.1:4185/scarlet2-walk-v5/index.html

사용자가 V4의 깨진 도트와 베이스 참고를 지적했다. V5의 팔은 회전으로 만들지 않는다. SE V20 / 사용자 수동 NE V8의 실제 네 컷에서 팔 피부 영역과 원래 외곽선 주변 픽셀을 추출하고, 그 픽셀 위치를 유지한 채 홍련의 피부·흰 보호구·보라색 밴드를 입힌다.

- 팔에는 회전·크기 변경·관절 보간·매끈하게 처리를 사용하지 않는다. 정수 이동만 사용한다: SE 양팔(−3,+2), NE 가까운 팔(+3,+5)/먼 팔(0,+5). 원본506파일을 SHA로 보존 검사한다.
- source-arm은 이동 전 실제 베이스 픽셀, reference-near/far는 이동 후 원래 베이스 색, near/far는 같은 위치에 의상색을 입힌 결과다. 추출 영역의 알파가 같고, 원래 손 크기를 유지한다. 전체 베이스 몸통과 홍련 몸통의 실루엣이 정확히 같다는 뜻은 아니다.
- 앞 방향 가까운 팔=오른팔, 뒤 방향 가까운 팔=왼팔로 보호구와 보라 밴드를 연결한다. SW/NW는 전체 전신 프레임 반전이다.
- 상체·다리·부츠·무기는 V4를 유지한다. 머리/옆머리 앞에 팔이 붙어 보이지 않도록 별도 머리 가림 레이어를 둔다.
- Pixelorama 방향별128px·4프레임·5레이어: 다리/먼팔/상체/가까운팔/머리 가림. 재생은 완성된 전신 PNG 네 컷, 6FPS다. 런타임 팔 회전은 없다.
- 화면은 V4/실제 승인 베이스/V5를 동기 재생한다. 전신과 네 컷은 원래128px의 정수2배로 표시하며 확대는 원래 PNG에서 직접 그린다. 모바일에서도 비정수 축소를 하지 않는다.
- 재현: `build-scarlet2-walk-v5.gd`를 새128px Pixelorama에서 dir=se/ne로 한 번 실행하고 legs/far/core/near/cap-sheet를 각각 레이어0..4에128px·4프레임으로 가져온다. .pxo와 editor PNG 내보내기 후 `py tools/art/package-scarlet2-walk-v5.py`.
- 검사: 원본 보존, 추출한 베이스 팔/의상 팔 알파 일치, 상체 동일성, 머리 보존, 가림 순서, 편집기/PNG 일치, 픽셀 연결/팔 동작/64색/반전, PC·모바일의 베이스 동기/정수 배율. 기술 검사는 작화 승인과 별개다.
- 새 AI생성 없음. 새 V5는 사용자 검수 후보다. 이전 그림과 실제 게임은 변경하지 않았다.
