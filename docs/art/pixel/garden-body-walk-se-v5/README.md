# 공통 몸체 SE 걷기 V5 · 1번 골반·다리를 오른쪽으로

사용자 지시: “자 이제 1번에서 다리 방향만 바꾸자. 골반과 다리가 좌측을 보고 있으니 우측으로 바꾸면 돼.”

V4 1번은 왼발이 앞(아래), 오른발이 뒤(위)였지만, 원래 1번의 골반과 다리를 거울처럼 뒤집어 만들어서 골반 주름과 다리가 왼쪽을 봤다. V5는 발 배치(왼발 앞·오른발 뒤)를 그대로 두고, 오른쪽을 보는 기존 그림만 모아 1번 아래쪽을 다시 맞췄다. 새로 그린 다리는 없다.

- 머리·몸·팔·골반(행 0~69): V3 1번 그대로(반전하지 않음). 반바지 주름이 오른쪽을 본다.
- 오른다리 윗부분(행 70~72, 오른쪽 다리 구멍 아래): V3 1번.
- 앞의 왼다리: 4번의 디딘 다리(행 70~88). 발끝이 오른쪽을 본다.
- 뒤의 오른다리: V2 3번의 뒤로 뻗은 다리(행 71~83)를 2px 왼쪽으로 옮겨 허벅지에 잇는다. 왼다리가 그 앞을 가린다.

2·3·4번 PNG는 V4(=V3)와 픽셀 동일하다. 검사: 8방향 연결, 이진 알파, 미리보기·GIF와 walk.png 일치.
