# 공통 몸체 SE 걷기 V17 · 현재본

사용자 지시(V16을 보고): “왼쪽 다리 도트 정리만 하고 마무리해도 될꺼같다.”

V17(Pixelorama MCP, garden-body-se-frame1-v17.pxo)은 V16 1번에서 왼다리 도트 4개만 정리했다.
- 왼다리 안쪽 외곽선이 행 73과 76에서 두 겹이던 것을 한 줄로.
- 종아리 바깥 가장자리 행 80~81의 회분홍 점 두 개를 종아리 그늘색으로.

1번 요약: 걷는 방향은 오른쪽 아래. 앞으로 딛는 다리는 화면 오른쪽 골반에서 나온 왼다리(3번 앞다리 그림 기반, 허벅지가 골반→무릎으로 \ 기울고 무릎이 앞, 종아리·신발이 조금 작음, 보폭 2px 줄임). 뒤로 뻗는 다리는 화면 왼쪽 골반에서 나온 오른다리(맨 위 레이어로 왼다리 안쪽을 가리고, 3번의 들린 뒷신발로 끝남). 두 허벅지 바깥 외곽선은 반바지 외곽선에서 이어진다. 2·3·4번은 V3와 픽셀 동일.

현재본으로 지정했다: 정지 베이스 페이지와 V1 주소의 걷기 링크가 V17을 가리킨다.
