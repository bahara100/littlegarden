# 모모·루루 V3 · 뒤 걷기 팔 교차

NE V3 베이스에서 팔이 네 컷 모두 고정임을 사용자가 지적했다. 공통 베이스는 NE/NW V4로 고치고 모모·루루의 뒤 걷기 소매와 손에도 같은 순환을 반영했다.

1번은 기존 의상의 양팔 작화를 반대로 옮겨 맞췄고, 2·4번은 공통 중간 팔 도트에 같은 의상색/명암·크림 커프·손을 입혔다. 3번은 기존 완성 전신 그대로다. 몸통과 팔의 경계만 정리하며 **기존 머리, y66 이후 치마 밑단·다리·발은 보존**했다. 2·4번의 소매는 앞서 실패한 의상 전체 색 치환 방식과 달리 기존에 완성된 몸통/치마를 유지하는 팔 보정이다.

앞 걷기 SE/SW와 모든 대기 PNG는 V2의 실제 파일을 그대로 복사했다. 사용자가 확인한 **뒤 대기 다리−5px·머리−5px 중심 보정도 그대로**다. 홍련과 기존 앉기, 가구 배치는 바꾸지 않는다.

96×96·4컷·6 FPS·최대64색, 전신 프레임 시트 재생. SW/NW는 컷별 반전. `.pxo`는8프레임·다리/의상/머리3레이어다. 원본 작화·의상색 기준은 `../garden-friends-base-walk-v2/`에 보존한다. 이번 수정에는 AI 생성이 없다.

재현: Pixelorama MCP에서 `tools/art/fix-garden-rear-arm-cycle-v4.gd` 실행 → `python tools/art/package-garden-rear-arm-cycle-v4.py`. 포장 검사에서 머리/치마/다리 보존, 실제 시트/반전 일치, 픽셀 연결을 확인한다. 실제 게임 및 Canvas 런타임은 `sprites/garden/base-walk-v3/`, 비교 URL은 기존 `/friends-base-walk-v1/index.html`이다. 팔 수정본은 사용자 검토 대상이다.
