# 홍련2 걷기 V6 · 팔 외곽선과 보호구 명암 · 사용자 검수 전

검수: http://127.0.0.1:4185/scarlet2-walk-v6/index.html

V5를 이어서 다듬었다. 실제 승인 SE V20 / 사용자 수동 NE V8의 팔 피부·손 픽셀은 그대로 유지한다. V5의 두 픽셀 주변 검색에 따라온 몸통·셔츠 외곽선 조각을 줄여, 직접 인접한 한 픽셀 주변 원화만 추출한다. 베이스 원본을 수정하지 않는다.

흰 보호구와 보라 밴드의 명암은 원본 피부의 녹색 채널 밝기로 구분한다. V5에서 사용한 빨간 채널은 대부분 피부색에서 거의 같아 흰 보호구의 명암이 사라졌다. 새 단계는 같은 64색 팔레트 안에서 밝은 면·중간 면·그늘을 나누며, 주변 소매 픽셀도 회색 단색 대신 의상 명암으로 맞춘다. 손과 팔을 회전하거나 크기를 바꾸지 않는다.

- V5의 머리·갓·몸통·다리·칼집·머리 가림 레이어는 픽셀 동일하다. 팔만 수정한다.
- 양팔의 어깨 이동값, 전신 상하 움직임, 다리 접지와 보폭은 V5 유지.
- SE/NE 원화 각 4컷·128px·6FPS·5레이어 Pixelorama. SW/NW는 완성 프레임 전체 반전.
- `source-arm-*`는 이번 한 픽셀 이웃까지의 실제 베이스 원화다. V5 추출보다 알파 영역은 작지만 실제 베이스의 모든 피부·손 픽셀은 같다.
- 검수 화면은 V5/승인 베이스/V6를 동기화하며 실제 출력 PNG를 정수 2배로 표시한다.
- 재현: `prepare-scarlet2-walk-v6.py` → 새 Pixelorama128px에 `build-scarlet2-walk-v6.gd` 실행(dir=se/ne) → 다리/먼팔/몸통/가까운팔/가림 시트5개를 각 레이어에4컷 가져오기 → .pxo 및 editor PNG 내보내기 → `package-scarlet2-walk-v6.py`.
- 검사는 기존650파일 SHA, 피부 픽셀/다른 레이어 보존, 팔·상체 합성/연결/64색/반전, 편집기 PNG 일치, 실제 브라우저 동기 재생/확대/모바일 표시를 확인한다. 기술 검사는 사용자 작화 승인을 뜻하지 않는다.
- 이전 홍련2·홍련·모모·루루·사용자 수동V8 및 실제 게임은 변경하지 않았다. 새 AI생성은 없다.

## 사용자 지정 빈 픽셀 보완

사용자가 첨부한 두 확대 이미지의 팔–몸통 사이와 기존 칼집 뿌리의 빈 부분만 추가로 채웠다. V6 페이지에 그대로 반영하며 원래 V6는 `before-shoulder-fill/`에 보관했다. 네 컷별 팔 9/5/3/8점, 칼집 20/17/13/20점을 채웠고, 원래 불투명 픽셀과 그 밖의 영역은 모두 동일하다. 움직이는 팔이 칼집을 가리는 픽셀은 변경하지 않는다. SE6번째 `팔·칼집 연결부 보완` 레이어로만 추가하며 NE5레이어와 전신은 유지한다. SW는 수정 SE의 정확한 반전이다.

`prepare-scarlet2-v6-shoulder-fill.py`는 백업과 좌표 `shoulder-fill.json`을 준비한다. SE의 새6번째 레이어에 `fill-scarlet2-walk-v6-shoulder.gd`를 frame=0..3으로 적용하고 저장·editor PNG 내보내기 후 기존 포장을 실행한다. 기존 V6 빌더도 JSON을 읽어 `joint-sheet-se.png`를 함께 출력하므로 다시 만들 때는 이 시트를6번째 레이어로 추가한다. 포장 시 추가 좌표 외에는 기존 V6와 픽셀 동일인지 검사한다.

사용자가 뒷모습도 같은 수정이 필요하다고 지적해 NE/NW에 추가 반영했다. NE 네 컷의 팔 연결부8/12/13/13점과 칼집 뿌리18/3/1/8점만 채운다. NE에도6번째 연결부 레이어를 두며 NW는 수정 NE의 정확한 반전이다. 이전 문단의 NE유지는 앞쪽 수정 당시의 이력이다. `rear-shoulder-fill.json`과 `prepare-scarlet2-v6-rear-fill.py`에 후면 좌표를 기록하고, 같은 네이티브 보완 스크립트에 dir=ne를 전달한다. 앞쪽 수정 프레임·SE.pxo의 SHA와 뒤쪽 기존 불투명 픽셀을 보존 검사한다.

## 칼집 테두리 정리 · 2026-10-22

사용자가 칼집의 테두리 누락과 도트 정리를 요청했다. SE/NE 모든 네 컷에서 기존 칼집 알파 안쪽에 한 픽셀의 짙은 자주색 외곽선을 그리고, 흰 윗면·연보라 중간 면·어두운 아랫면을 연속된 단계로 정리했다. 금색 끝장식·끝마개와 전체 실루엣/길이/알파는 그대로다. 앞 팔에 가려진 부분과 몸통이 없는 곳의 먼 팔은 덮어쓰지 않는다. 머리·팔·옷·다리 및 앞서 메운 어깨는 바뀌지 않는다.

원래6레이어 .pxo/프레임은 `before-scabbard-outline/`에 보존했다. `prepare-scarlet2-v6-scabbard-line.py`가 기존 칼집의 열별 범위 `scabbard-line.json`을 준비하며, Pixelorama의7번째 `칼집 외곽선·명암` 레이어에 `outline-scarlet2-walk-v6-scabbard.gd`를 dir=se/ne와 frame=0..3으로 적용한다. 저장/내보내기/포장 후 네 방향 PNG·시트·GIF·ZIP은 동기화된다. 기존 빌더와 연결부 보완 스크립트도 outline PNG를 마지막에 적용해 재실행으로 지우지 않는다. 이번 단계는 사용자 요청에 따라 칼집의 원래 불투명 픽셀 색도 바꾸며, 이전 빈 픽셀만 채우던 단계와 구분한다. 칼집 외 영역과 전체알파 보존을 검사한다.

### 정면 칼집 직선 보정

사용자가 정면 칼집이 휘어 보인다며 이 부분만 수정하라고 했다. SE의 x79..100에서 윗선은 `88 + round((x−79)×2/7)`, 아랫선은 윗선+6으로 맞춰 평행한 직선과 일정한 폭을 만든다. 기존 끝장식 x101이후와 길이, 팔 가림, 다른 캐릭터 영역은 유지한다. 이 수정은 기존 칼집 범위와 새 직선 범위의 합집합 안에서만 알파를 바꾼다. 이전 단계의 전체알파 유지 기록은 직선 보정 이전 이력이다. NE/NW 전신 및 NE.pxo는 SHA동일, SW는 수정 SE 전체 반전이다.

`before-front-scabbard-straight/`에 이전 SE7레이어/프레임/몸통/연결/외곽선을 보관한다. `prepare-scarlet2-v6-front-straight.py`와 `front-scabbard-straight.json`이 범위를 준비하며 Pixelorama의 `straighten-scarlet2-walk-v6-front.gd`를 frame=0..3, kind=core/joint/outline에 각 레이어2/5/6으로 적용한다. 저장·editor PNG 내보내기 후 V6준비/포장으로 동기화한다. 기존 빌더도 아래의 옛 칼집 조각을 지우고 직선 외곽선을 합성한다. 옛 SE연결/외곽선 도구는 이 결정 이후의 직선 원화를 덮어쓰지 않는다.

### 정지 V2 칼집 원화 적용

사용자가 정지 자세의 칼을 보고 정면 걷기를 수정하라고 했다. 이전의 고정 폭 직선은 정지 그림보다 두껍고 연결부가 커 보였다. 최신은 `front-scabbard-straight.json`의 mode=`approved-standing-pixels`다. x83..104의 칼집은 승인 `scarlet2-base-v2/idle-se.png`의 실제 색·알파·각도·실루엣·금색끝장식을 그대로 복사하고, 정지 손에 가렸던 x79..82 연결부만 더 가늘게 보완한다. 앞 팔이 겹치는 픽셀은 유지하고 2·4번은 전신과 같은 y−1 이동만 한다. 이전의 고정7px폭/직선 공식은 이력이며 최신 작화로 쓰지 않는다.

`before-front-scabbard-standing/`에 수정 전 .pxo/프레임/몸통/연결/외곽선을 보관했다. `prepare-scarlet2-v6-standing-scabbard.py`가 승인 원본에서 범위를 얻고, 같은 `straighten-scarlet2-walk-v6-front.gd`로 레이어2/5/6을 갱신한다. 포장은 노출된 x83이후 칼집 픽셀이 승인 원화와 실제로 같은지 네 컷 모두 검사하며, 뒤쪽 전신·NE.pxo SHA와 칼집 외 픽셀 보존도 확인한다. 이름에 남은 straight는 이전 도구명이며 현재 모드는 승인 원화 복사다.
