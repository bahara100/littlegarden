# 홍련2 걷기 V3 · 상체 원화 연결 수정 · 사용자 검수 전

검수: http://127.0.0.1:4185/scarlet2-walk-v3/index.html

V2는 정지 원화의 머리+목/어깨 일부 아래에 서로 다른 각도의 생성 몸통을 붙여, 좌표를 맞춰도 몸이 따로 도는 문제가 남았다. V3는 승인한 정지 V2 전신에서 머리·어깨·가슴·허리·칼집을 하나의 공통 상체로 사용한다. 상체 네 컷은 y0/−1/0/−1px 이동 외에 픽셀·각도·형태가 동일하다.

- 기존 걷기 V2의 다리 네 자세를 골반 의상 뒤에 겹쳐 연결한다. 원래 머리에서 몸통을 수평 절단해 따로 생성한 몸통을 붙이는 방식은 사용하지 않는다.
- 팔은 승인 정지 원화의 완전한 팔을 어깨에서 ±12°/±5° 회전해 제작했다. 피부색은 팔레트의 정확한6색으로 구분해 금색 무기 끝/장비 테두리가 함께 지워지지 않도록 한다.
- 회전/마스크는 제작 단계에만 사용한다. 검수 재생은 완성된 전신128×128 PNG 네 장을 6FPS로 교체하며, 머리·팔·다리 레이어를 별도로 움직이지 않는다.
- 목부터 허리까지의 연결을 비교할 수 있는 확대 화면과 V2/V3 동기 재생을 제공한다. SW/NW는 전체 프레임 좌우 반전이다.
- `core-{dir}-{n}.png`는 공통 상체, `limbs-{dir}-{n}.png`는 팔다리다. 각 방향 .pxo는4프레임·2레이어이며 PNG 합성과 일치한다.
- 재현: Pixelorama의 새128px/4프레임/2레이어 프로젝트에서 `build-scarlet2-walk-v3.gd`를 dir=se/ne, frame=0..3, part=limbs/core로 실행한다. editor PNG와 .pxo를 저장한 뒤 `py tools/art/package-scarlet2-walk-v3.py`.
- 검사: 상체 동일성, 팔/다리 동작 변화, 원본325파일 SHA 보존, 편집기PNG·레이어 일치, 64색·알파·연결·반전, 브라우저 실제PNG 일치/모바일 확인. 기술 검사는 자연스러움에 대한 사용자 승인과 다르다.
- 새 AI생성 없음. 기존 정지/앉기/베이스와 이전 걷기 V1·V2, 실제 게임은 보존한다. V3는 사용자 검수 후보다.
