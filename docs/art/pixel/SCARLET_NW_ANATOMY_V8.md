# NW V8: 골반에서 이어지는 다리와 반대 접지

사용자는 반복된 좌우 의상 오류를 지적했고, 무늬를 바꾸기 전에 각 다리의 연결부터 확인하는 방식으로 다시 작업하도록 요청했다.

## 고정 규칙

- 캐릭터 자신의 왼다리: 검은 X자 교차 리본. 자신의 오른다리: 흰 스타킹.
- 화면의 왼쪽/오른쪽 영역에 의상을 고정하지 않는다.
- 뒤왼쪽 보행의 진행축은 화면 좌상 ↔ 우하다. 같은 다리의 발은 이 축을 따라 전후로 이동한다.
- 1번은 V7을 보존한다. 2·3·4번은 연결된 골반–무릎–발목 경로를 바탕으로 자세를 수정한다.

## 제작 전 자세도

`fullframe-nw-v8/anatomy-guide.png`는 캐릭터 그림을 바꾸기 전에 만든 독립적인 관절 경로 도식이다. 빨강은 자신의 왼다리, 파랑은 자신의 오른다리다. 각 셀의 골반 시작점을 유지하며, 이미지의 상하좌우를 의상 소유권으로 사용하지 않는다. `anatomy-plan.json`에 좌표를 기록했다.

| 컷 | 왼다리 · 검은 리본 | 오른다리 · 흰색 |
|---|---|---|
| 1 | 앞으로 접지, 짧게 보임 | 뒤로 뻗음, 길게 보임 |
| 2 | 몸 아래에서 지지 | 뒤에서 앞으로 낮게 통과 |
| 3 | 골반에서 우하로 뒤로 뻗음 | 반대 골반에서 좌상으로 앞으로 접지 |
| 4 | 뒤에서 앞으로 낮게 통과 | 몸 아래에서 지지 |

특히 3번은 두 다리의 화면상 위치가 교차한다. 검은 왼다리가 흰 오른다리보다 앞쪽 깊이에 놓여 겹치는 곳을 가린다. 화면 왼쪽에 나타난 앞발에 검은 무늬를 다시 칠하면 같은 오류가 반복된다. V5~V7에서 3번의 다리를 각 화면 영역 안에 남겨 둔 것을 최종 기준으로 삼지 않는다.

## 편집과 표시

내장 image_gen에 V7 최종 source-keys.png와 자세도를 함께 제공한다. 정확한 요청은 `fullframe-nw-v8/edit-prompt.txt`에 보관한다. 최종 source-keys.png는 채택한 영역만 합친 후속 참고본이다. 실제 재생 walk.png에서만 미리보기 PNG/GIF를 만든다.

규격은 4프레임, 6 FPS, 셀 96×96이다. 자세 확인과 별도로 상부 보존, 팔레트, 미리보기/재생 픽셀 일치, 빌드를 검사한다. 규격 검사 통과는 사용자 최종 승인을 뜻하지 않는다.
