# 홍련 인게임 SD · 앞오른쪽 걷기 V1

2026-10-17 사용자가 “응 좋아 다른 방향도 진행하자”로 SE 걷기를 확인하고 뒤쪽 제작을 지시했다. 이 폴더의 walk.png와 frame-1.png~frame-4.png를 보존한다.

- 규격: 전신 96×96 4컷, 6 FPS, 공유 24색, 투명 배경.
- 제작: 내장 image_gen으로 승인 SD 정지 자세와 보행 가이드를 참고한 전신 시트 생성. prompt.txt에 요청문 저장.
- 출력: 공통 크롭/배율로 축소·팔레트 제한·머리 정렬 후 PNG 시트 출력. Pixelorama 수작업 보정본은 아니다.
- 실제 walk.png를 잘라 네 컷 미리보기, GIF, 어니언 진단을 만들었다. walk.json에 프레임 SHA256과 정렬 정보가 있다.
- 주요 순서: 왼발 접지 → 오른발 통과 → 오른발 접지 → 왼발 통과. 팔 스윙과 작은 상하 이동을 포함한다.
- index.html은 별도 검수 화면이며 현재 게임에는 연결하지 않았다. 이후 NE와 통째 좌우 반전 SW/NW를 같은 화면에서 확인한다.

원본 생성 시트 source-keys.png와 최종 96px 도트/미리보기를 구분한다.
