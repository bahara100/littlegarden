# 공통 몸체 NE(뒤오른쪽) 걷기 V1 · 초안

사용자 지시: “그럼 오른쪽 위로 걷는거 만들어볼래?”

이 시점의 쿼터뷰에서는 오른쪽 위로 걸어가는 뒷모습의 실루엣이 앞왼쪽(SW) 앞모습과 거의 같고, SW 컷은 이미 앞으로 딛는 발이 오른쪽 위·뒤에 남는 발이 왼쪽 아래에 있다. 그래서 NE V1은 SW V1(= SE V18 좌우 반전) 네 컷에서 앞모습에만 있는 부분만 뒷모습으로 바꿨다. 다른 픽셀은 다시 그리지 않았다.
- 목: 앞의 V넥(피부와 옷깃 선, 행 50~53)을 옷으로 덮고 행 50에 곧은 등 목선을 넣었다.
- 반바지: 앞 가랑이 V주름(행 62~68)을 옷으로 덮고, 가랑이 위에 엉덩이 가운데 솔기(행 65~67)를 넣었다.

한계: 신발 앞코가 아직 왼쪽을 향한다(반전된 앞모습 신발). 신발을 자동으로 뒤집는 방법은 다리 외곽선을 깨뜨려서 쓰지 않았다. 다음 단계에서 Pixelorama로 신발 뒤꿈치/앞코를 다시 그려야 한다.
