# 홍련2 V2 · 베이스 참고 앉기4방향

## 부츠 디테일 보완

사용자가 신발 디테일이 사라졌다고 지적했다. 몸 전체를 세로로 맞추는 과정에서 앞코/밑창의 밝기가 비슷해졌고 흰색·띠·주름의 구분이 약해졌다. 정지V2의 부츠 재질을 기준으로 Pixelorama에서 **부츠 내부 색만** 직접 정리했다: 흰 앞코, 어두운 발목 띠, 접힌 주름, 밑창 위의 얇은 금색 테두리. 새 신발 실루엣이나 다리/팔을 생성하지 않았다.

- SE는 x56..74/y103..113 안의115픽셀, NE는 x65..82/y101..110 안의83픽셀을 변경했다. 그 밖의 모든 픽셀과 전체 알파는 수정 전과 같다. 기존 깊은 외곽선도 유지한다.
- 두 원본 방향의.pxo/body/full을 갱신하고 SW/NW를 다시 전체 반전했다. 모든 확대/4방향/ZIP/브라우저 자료도 같은 PNG를 사용한다.
- 수정 전은 `before-shoe-detail/`, 앞/뒤 부츠의 수정 전후는 `shoe-detail-before-after.png`(왼쪽 이전/오른쪽 수정, 위SE/아래NE)다.
- `build-scarlet2-sit-v2.gd`의 `restore_boots()`가 원래 생성 후 부츠 디테일을 복원하므로 재실행해도 수정이 사라지지 않는다. 포장 검사는 신발 영역 밖/머리/알파 보존도 확인한다.64색 팔레트는 그대로다.

사용자가 원본 색/허리 연결을 복원한 정지V2를 “응 좋아”라고 확인하고, 그 외형으로 베이스를 참고한 앉기를 요청했다. 정지V2와 이전 앉기V1을 보존한 별도 앉기V2다. 새 앉기 외형은 사용자 검수 전이며 게임에는 연결하지 않았다.

## 제작 방식

- 승인한 `scarlet2-base-v2/head-se.png` / `head-ne.png`의 실제 머리·얼굴·갓 레이어를 쓴다. SE는 제자리, NE는 앞서 확인한 앉기 목 중심에 맞춰 x−3px/y동일이다. 크기·색·원래 픽셀은 바꾸지 않았다.
- 팔레트도 정지V2의64색 파일을 그대로 공용으로 사용한다. 갈색 눈, 보라색 장비, 피부와 흰 의상 색을 유지한다.
- 새 AI생성 없이, 기존에 **베이스 앉기를 참고해 생성한** `scarlet2-sit-v1/aligned-costume-se/ne.png`의 잘리지 않은 몸을 재사용해 Pixelorama에서 정리했다. 기존 두 AI원본/프롬프트는 이전 앉기 폴더에 보존되어 있다.
- 몸통·골반·허벅지·부츠를 따로 잘라 붙이지 않는다. 목 기준76행 아래의 몸 전체에 하나의 연속 변환을 적용한다. SE 원래42행→38행, NE38행→35행이며 가로 폭은 유지하고 팔을 포함한 몸 전체를 같은 비율로 맞췄다. 기존 앉기 베이스(`garden-body-sit-friends-v1`, `garden-body-sit-ne-v1`)에 여백(16,24)을 붙였을 때의 발 높이 SE113행/NE110행에 맞췄다.
- 이전 V1의 발 픽셀 교체/허리 경계 합성을 재사용하지 않았다. 베이스는 자세·비율·발 높이 참고이며, 다리 실루엣이 베이스와 픽셀 단위로 동일하다는 주장이 아니다.
- SE/NE 각각128×128·1프레임·2레이어 `.pxo`(이어진 몸 / V2 머리). SW/NW는 완성 전신 전체 좌우 반전이다.

## 결과와 확인

검수 주소: `/scarlet2-sit-v2/index.html`. 정지V2 및 이전 앉기V1 화면에도 새 앉기로 가는 링크를 추가했다.

- `sit-se/sw/ne/nw.png`: 실제 투명128×128 PNG.
- `sit-four.png`: 위SE/SW·아래NE/NW 순서의256×256 시트. `sit-four-preview.png`는 최근접3배 확대다.
- `scarlet2-sit-se-v2.pxo` / `scarlet2-sit-ne-v2.pxo`: 별도 편집 원본.
- `body-*.png`, `head-*.png`, `reference-body-*.png`: 실제 레이어 및 색 제한 전의 연속 몸 참조.
- `scarlet2-sitting-v2.zip`: 실제 PNG·편집 원본·팔레트·검사 기록.
- `manifest.json`: 새 방식과 변환 좌표·보존·반전·발 높이 기록.
- `browser-review.png` / `browser-mobile.png`: 실제 비교 페이지 확인 자료.

재현: `tools/art/build-scarlet2-sit-v2.gd`를 새 Pixelorama128px 프로젝트에 방향별 body/head 파트로 실행하고 PNG/.pxo를 내보낸 뒤 `py tools/art/package-scarlet2-sit-v2.py`.

검사: 정지V2·앉기V1·공통 앉기 원본70파일 SHA보존, V2머리/64색 팔레트 동일, 머리 잘림 없음, 원본 변환 몸과 알파 동일, 레이어 합성/두 전체 반전/베이스 발 높이 일치. 기술 검사는 새 앉기 작화 승인과 다르다. 브라우저는1개만 실행해 네 방향과 화면 표시를 확인한다.

현재 결과는 벤치/의자형 기본 앉기다. 앞서 논의한 시소 전용 손잡이 자세와 돗자리 바닥 앉기는 별도 자세이며, 실제 기구 높이·가림·게임 연결은 이후 단계다.
