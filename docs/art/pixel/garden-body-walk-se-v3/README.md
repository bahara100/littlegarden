# 공통 몸체 SE 걷기 V3 · 3번 골반·다리 방향 수정

사용자 지적: “걷기 모션의 3번째꺼가 다리 방향이 혼자 달라.” V2 3번은 앞발이 화면 왼쪽 아래에 닿고 발끝도 왼쪽 아래를 향해, 혼자 SW(앞왼쪽)로 걸었다. 1·2·4번은 앞발이 오른쪽 아래를 향한다.

처음 수정에서는 다리만 반전해 골반(반바지의 가운데 주름과 다리 구멍)이 이전 방향으로 남았고, 사용자가 “골반은 왜 그대로야”라고 지적했다. 그래서 3번의 골반(양팔 사이 반바지, 행 63~68, 열 41~59)과 다리(행 69~95, 열 36~64)를 함께 골반 가운데 x=50을 축으로 좌우 반전했다(x → 100 − x). 이제 3번도 반바지 주름과 다리 구멍이 다리를 따라가고, 앞발이 화면 오른쪽 아래, 뒷발이 왼쪽 위에 있으며 발끝이 오른쪽을 향한다. 1번과는 팔 스윙이 반대다.

- 1·2·4번 PNG와 3번의 머리·가슴·팔은 V2와 픽셀 동일하다. 새 색은 없다.
- 머리→목→몸→발 8방향 연결, 이진 알파, 미리보기·GIF와 실제 walk.png의 픽셀 일치를 검사했다.
- 3번은 V2 때부터 다른 생성 원본을 축소한 컷이라 외곽선/명암 느낌이 다른 컷과 조금 다르다. 이번에는 골반과 다리 방향만 고쳤다.

산출물은 V2와 같은 구성이다: walk.png(384×96, 1→2→3→4, 6 FPS), frame-1~4, head/body 레이어, walk-preview-2x2.png, walk-contact-4x.png, walk-preview.gif, layers.zip, walk.json.
