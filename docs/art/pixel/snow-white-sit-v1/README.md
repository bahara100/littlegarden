# 스노우화이트 앉기 V1

2026-10-22 뒤쪽 노출 보완: 사용자가 앉은 뒷모습의 엉덩이 노출이 과하다고 지적해, 기존 뒤 골반 장갑판 아래 흰 허리 천이 엉덩이를 더 덮게 했다. Pixelorama 기존 몸통 레이어의 x52..79/y85..93 중 피부 픽셀만 천 명암으로 바꾸며 전체 알파·머리·앞쪽 자세·94행 이후 다리/부츠는 그대로다. 뒤오른쪽 NE와 반전 NW에만 반영했다. `before-rear-coverage/`에 이전 원화/.pxo를 보관하고 재현 빌더에도 적용했다.

사용자가 정지V1을 승인하고 앉기 베이스를 참고하되 다리 디테일을 유지하라고 요청했다. 앞SE/뒤NE의 의자형 앉기 한 컷씩, SW/NW는 전신 반전이다. 보행·착석 전환 애니메이션이나 게임 연결은 포함하지 않는다.

ImageGen 내장 도구에 승인 정지 앞뒤·공통 앉기 베이스 앞뒤·사용자 SD 캡처를 입력했다. 원본/실제 프롬프트를 함께 보관했다. Pixelorama에서 새 어깨~골반~허벅지~부츠를 하나의 이어진 몸으로 맞췄고, 승인 정지의0~67행(얼굴·고글·상단 머리)을 실제 동일 픽셀로 재사용했다. 아래로 이어지는 긴 머리 끝은 새 앉기 원화 영역이다. 베이스는 자세와 비율의 참고이며 실루엣이 정확히 같다고 주장하지 않는다.

붕대는 앞SE의 화면 왼쪽 허벅지, 뒤NE의 화면 오른쪽 허벅지다. 앞 은색 무릎 보호대·부츠 앞코와 밑창을 유지하며 정지와 동일한48색으로 어두운 정강이/발목 경계와 뒤꿈치 판 명암을 보완했다. 명암 보완은 기존 불투명 부츠 내부만 변경한다. 실제 사용 색/편집기 출력/레이어 합성/반전/머리 동일/정지·베이스62파일 SHA를 포장 과정에서 확인한다. 기술 검사는 사용자 작화 승인과 다르다.

원화 `source-ai.png`, 프롬프트 `prompt.txt`, 결과 `sit-{se,sw,ne,nw}.png`, 편집 `snow-white-sit-{se,ne}-v1.pxo`(128px·1컷·2레이어), 팔레트 `palette.json`. 재현 `tools/art/build-snow-white-sit-v1.gd`를 Pixelorama에서 dir=se/ne 및 part=body/head로 실행하고 .pxo/PNG를 내보낸 뒤 `py tools/art/package-snow-white-sit-v1.py`를 실행한다.
