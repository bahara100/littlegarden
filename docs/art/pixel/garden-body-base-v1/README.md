# 모모·루루 기반 공통 몸체 시안 V1

2026-10-17 사용자 요청: 잘 나온 모모·루루의 비율을 활용해 “베이스 몸체 하나에 머리·옷만 덧그리기” 방식을 추가로 시도한다. 승인된 홍련 걷기와 현재 게임의 모모·루루를 교체하지 않는다.

이번 범위는 **앞쪽 대각선 정지 한 자세**다. 공통 걷기/뒤쪽 몸체/앉기는 아직 없다. 사용자 승인 전의 실험이며 최종 제작 방식이 확정됐다고 취급하지 않는다.

- `reference-momo.png`, `reference-lulu.png`: 기존 garden-friends-v1.png의 대기 칸을 게임과 같은96×96/90px 안쪽 배치로 축소한 참고. 알파180 미만의 부드러운 테두리를 정리했다.
- `source-base-ai.png`: 내장 image_gen으로 만든 새 몸체 초안. 원본 두 캐릭터의 큰 머리·짧은 몸·가까이 모은 발·가슴 앞의 작은 손·전면 대각선 시점을 참고했다. 요청문은 prompt.txt다.
- `base-idle-se.png`: 새 초안을96×96으로 정렬하고 고정32색 팔레트에 매핑한 시안. 실제19색, 알파0/255, 바닥 최하단90행/발 기준점(48,91). 기준 캐릭터의 발 위치에 맞췄으며 홍련의(48,88)과 혼용하지 않는다.
- `base-head.png`, `base-body.png`: 동일 베이스의 머리/몸 분리. 기본 머리는53행까지, 몸은54행부터다. 다른 머리를 쓸 때 기본 머리 레이어를 끄므로 두개골 윤곽이 머리카락 밖에 남지 않는다.
- `momo-head.png`, `lulu-head.png`: 원본 대기 그림의 얼굴·머리 레이어(54행까지). 머리카락 모양·표정·색은 원본을 보존했다.
- `momo-outfit.png`, `lulu-outfit.png`: 원본55~78행에서 떼어낸 **임시 의상 덧그림**. 소매·손·리본도 함께 들어 있다. 따라서 모든 손 픽셀이 공통 몸체에서 나온 완성된 옷 시스템이라고 말하지 않는다. 걷기 전에 손/옷 앞뒤 관계와 캐릭터별 겹침 마스크를 다시 정리해야 한다. 치마로 덮인 몸통을 원본에서 복원했다고 주장하지 않는다. 가려진 몸통과 다리는 새 초안이다.
- `momo-base-composite.png`, `lulu-base-composite.png`: **동일 base-body.png** 위에 각자의 옷, 머리를 그린 결과. 발/다리 크기는 동일하다. 기존 갈색 부츠를 재사용한 결과가 아니라 공통 회색 신발을 쓴 비교다.
- 몸체는19색이다. 외형 덧그림은 사용자가 좋아한 원본 색을 유지하므로 합성본 전체가32색 이하인 최종 게임용 캐릭터라고 안내하지 않는다. 실제 캐릭터 확정 시 외형에 맞는 팔레트를 별도로 정리한다.

`comparison-preview-4x.png`: [기존 모모, 기존 루루, 공통 몸체, 몸체+모모, 몸체+루루]. `tryon-preview-4x.png`: 마지막 세 장만4배 확대했다. 실제 출력 PNG로 만들었으며 생성 원본을 완성 도트 미리보기로 제시하지 않는다.

확인 페이지: `apps/client/public/body-base-v1/index.html`, 로컬 주소 `http://127.0.0.1:4185/body-base-v1/index.html`. 머리/옷을 각각 바꾸고 기준선을 켜서 비교한다. 모든 조합은 같은 몸 레이어를 읽으며 정지 그림만 표시한다. 현재 게임에는 새 모드/캐릭터를 연결하지 않았다.

Pixelorama MCP 연결은 현재 사용할 수 없어 Pixelorama 수작업 완성본이나 .pxo 프로젝트로 보고하지 않는다. 편집용 개별 투명 PNG, manifest.json, layers.zip을 제공한다. 재현 도구는 `tools/art/build-garden-body-base-v1.ps1`이다.

후속 순서: 베이스 비율 확인 → 공통 걷기4자세(접지·통과·반대 접지·반대 통과,6 FPS) → 각 전신 프레임에 머리/옷을 덧그리며 보정 → 합성 시트 출력 → 잘라서 재생. 별도 뒤쪽 원본을 만들고 왼쪽은 반전한다. 런타임 관절 회전이나 움직이지 않는 머리를 몸체 위에 붙이는 것만으로 완성 보행이라고 하지 않는다.


검증: 브라우저에서 모모/루루 조합, 머리와 의상 독립 교체(루루 머리+모모 옷), 기본 머리/작업복, 기준선 표시를 확인했다. 콘솔 오류 없음, 프로덕션 빌드 통과. 승인된 홍련 SE/NE 런타임 시트의 SHA256도 보존됐다. browser-proof.png는 실제 비교 화면 캡처다.
