# 홍련2 · 공통 베이스 정지 시안 V1

사용자가 기존 홍련을 유지한 채 공통 베이스에 맞춘 새 홍련을 `홍련2`로 만들라고 했다. 앞쪽 시안을 “좋아”라고 확인하고 정지 자세들을 먼저 모두 작업하라고 해서 **앞오른쪽·앞왼쪽·뒤오른쪽·뒤왼쪽 정지 4방향**을 만들었다. 앞쪽 원본은 SHA256 그대로 보존했고, 뒤쪽은 새로운 사용자 검수 대상이다. 기존 홍련·모모·루루·공통 몸체 원본이나 게임의 캐릭터 선택은 바꾸지 않았다.

## 제작

- 내장 ImageGen으로 공통 정지 V2의 편한 팔 자세와 인게임 SD 캡처를 참고해 머리·갓·상체 의상을 생성했다. 상세 일러스트 대신 사용자가 준 SD 캡처가 외형 기준이다. 정확한 입력은 `prompt.txt`, 원본은 `source-ai-se.png`다.
- 몸체 공간은 96×96 원본 그대로이며 `(16,24)` 여백을 붙인 128×128 캔버스를 쓴다. 넓은 갓·금색 장식과 칼집을 담기 위한 여백이다. 생성된 상체는 원본 몸 중심과 발 높이에 맞춰 균일 축소/이동했다(`aligned-ai-se.png`).
- 하단은 AI가 만든 발을 버리고 **실제 정지 베이스의 다리·발 실루엣을 그대로** 가져와 Pixelorama에서 흰 의상/부츠와 주름을 입혔다. 그레이스케일 신발을 단순히 머리 아래에 붙인 결과와는 다르며 상체 의상은 별도로 생성·정리한 것이다. 상체 전체의 픽셀이 베이스와 같다는 의미는 아니다.
- Pixelorama에서 48색과 알파0/255로 정리했다. `scarlet2-base-idle-se-v1.pxo`는 베이스 다리 / 의상·장비 / 상단 머리·갓의 3레이어 한 프레임이다. 상단 레이어와 의상 레이어의 구분선은 행77이며 일부 긴 옆머리 끝은 의상 레이어에 포함된다.
- `idle-se.png`가 실제 128×128 결과, `idle-sw.png`는 정확한 전체 반전이다. `preview-se.png`는 실제 PNG의 최근접6배 미리보기다. 생성 원본을 최종 픽셀 결과라고 표시하지 않는다.
- 뒤쪽은 같은 내장 ImageGen에 확인한 앞쪽·뒤 정지 베이스·실제 인게임 SD 후면·기존 후면 방향 자료를 입력해 생성했다. 원본과 프롬프트는 `rear/source-ai-ne.png` / `rear/prompt-ne.txt`. 정렬은 생성 원본을122×122로 전체 축소하고128×128 안에(-1,-1)로 놓았다. 새 뒷머리와 등 의상, 흰 허리 리본, 화면 왼쪽으로 이어지는 칼집이 있다.
- 뒤 베이스는 `garden-friends-base-walk-v2/base-idle-ne.png`를(16,26)에 놓아 발 높이114행을 맞췄다. 행99 이후 실제 베이스 다리 실루엣에 의상을 입혔고, 위쪽 허리 리본이 일부 겹치며 행103 이후 최종 보이는 발 실루엣은 베이스와 같다. 앞쪽과 같은48색 팔레트를 사용했다.
- 뒤 편집 원본은 `rear/scarlet2-base-idle-ne-v1.pxo`(다리/의상·칼집/상단 머리·갓 3레이어·1컷). `idle-ne.png`는 실제 결과, `idle-nw.png`는 정확한 전체 반전이다. `idle-four.png`는 원본128px 컷을2×2로 모은 시트이며 `idle-four-preview.png`는 이를 최근접3배 확대한 것. 순서는 위 SE/SW, 아래 NE/NW다.

## 검토

검수 주소: `/scarlet2-base-v1/index.html`. 네 방향 버튼과 전체 모아보기를 제공하며 공통 베이스·기존 홍련·홍련2를 같은 픽셀 배율과 발 높이로 표시한다. `comparison.png`와 `browser-review.png`는 앞쪽 제작 단계의 이력이며, 최신 화면은 `rear/browser-four-directions.png`다.

포장 검증은 아래를 확인한다.

- 기존 홍련 런타임·설정과 공통 정지/걷기 원본14개 SHA256 보존.
- 다리 레이어 행99 이후 알파가 공통 베이스와 정확히 일치하고, 최종 발 부분도 같은 실루엣.
- 3레이어 합성과 실제 내보낸 PNG가 동일, 불투명48색 이하, 알파0/255.
- 승인한 앞쪽 PNG·팔레트·편집 원본7개 SHA 보존, 뒤쪽 공통 팔레트/레이어 합성, 두 방향의 정확한 전체 반전, 네 컷 모두 최하단114행.
- 브라우저 한 개에서 이미지7개 로딩, 네 방향 비교 선택/배경 확인 버튼, 모바일 가로 넘침 없음, 페이지 오류 없음.

기술 검사를 외형 승인으로 취급하지 않는다. 앞쪽은 사용자 확인본이고 뒤쪽은 새 검수 시안이다. SE V20/수동 NE V8 기반 걷기·앉기·게임 연결은 이후 단계다. 기존 홍련을 교체하거나 새 홍련2의 걷기를 완성했다고 보고하지 않는다.

재현: 앞쪽은 `tools/art/build-scarlet2-base-v1.gd`, 뒤쪽은 `tools/art/build-scarlet2-rear-idle-v1.gd`를 Pixelorama의 새 프로젝트에서 각 레이어 파트로 실행한다. PNG/.pxo를 내보낸 뒤 **`py tools/art/package-scarlet2-idle-four-v1.py`**로 네 방향을 포장한다. 예전 앞쪽 전용 포장 도구는 뒤쪽 결과가 생기면 실행을 차단한다. `scarlet2-authoring.zip`에 네 방향 PNG·레이어·팔레트·두 프롬프트·두 편집 원본을 보존한다.
