# NW V12: 3번 뒤쪽 발 접지

사용자 지시: “3번 발이 땅에 닿도록 먼저 고쳐 줘. 다른 컷과 다리 디자인은 유지해.”

V11 3번은 가장 아래 픽셀이 y81로, 다른 컷(y86~88)과 기준 접지선 y88보다 5~7px 떠 있었다. 앞쪽(화면 좌상) 흰 오른다리는 원근상 위에 놓이는 앞발이므로 그대로 두고, 뒤쪽(화면 우하) 검은 리본 왼다리만 접지선까지 내렸다.

tools/art/export-scarlet-nw-ground-v12.ps1이 96×96 셀을 직접 보정한다. 생성형 편집은 쓰지 않았다. 뒤쪽 다리 띠(x44..58)에서 금색 발목 끈 바로 위의 민무늬 스타킹 행 y71을 5번 반복하고, 발목 끈과 신발(y72..81)은 모양 그대로 y77..86으로 옮겼다. 처음 시도한 균등 늘이기는 금색 끈이 덩어리로 번져서 채택하지 않았다.

- 3번 변경 픽셀 115개, y0..71은 V11과 픽셀 동일, 최하단 y86.
- 1·2·4번은 V11과 PNG 바이트 동일.
- 32색 팔레트, 4프레임·6 FPS 유지. GIF와 재생 시트의 픽셀 불일치 0.
