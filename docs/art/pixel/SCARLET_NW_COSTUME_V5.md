# NW V5: 1~3번 의상을 4번 기준으로 수정

사용자 지시: 오른다리가 흰색이며, 4번만 고칠 것이 아니라 1~3번도 수정한다. 최신 검수본은 `apps/client/public/sprites/scarlet/fullframe-nw-v5/walk.png`다. 4프레임·6 FPS는 유지한다. 사용자 승인 전이다.

오른다리는 흰 스타킹, 왼다리는 검은 교차 끈이다. 4번의 골반과 의상 연결을 기준으로 1~3번의 허리 아래를 수정했다. 1번은 짧게 앞으로 나온 검은 왼다리/길게 뒤로 나온 흰 오른다리, 2번은 검은 왼다리 지지/흰 오른다리 통과, 3번은 길게 뒤를 받치는 검은 왼다리/짧게 앞으로 나온 흰 오른다리다. 3번의 엇갈려 보이던 골반→무릎→발을 다시 그려 소유권을 분명하게 했다. 화면의 좌우만 보고 무늬를 교체하는 것을 제작 원칙으로 삼지 않는다.

4번 PNG는 V4와 바이트 동일하다. 1~3번의 y0..49는 V4와 픽셀 동일하며, 공통 축소율과 샘플링 좌표를 유지하고 허리 아래만 교체했다. 1·2번에서 각각 167/151픽셀, 3번에서 754픽셀을 변경했다. 최종 표시 이미지는 실제 재생 시트에서 만든 `walk-preview-2x2.png`이며 픽셀 대조 불일치 0이다. 각 컷은 96×96, 팔레트 최대 32색이다. 자동 검사는 사용자 작화/보행 최종 승인을 뜻하지 않는다.

내장 image_gen 편집 사용. 최종 요청은 두 단계였다.

1. V4의 source-keys.png를 참고하여 4번은 잠그고 1~3번을 같은 골반별 의상으로 맞추기. 오른다리의 모든 스타킹은 분홍 지그재그 윗단의 흰색, 왼다리는 검은 교차 끈이다. 상체·시점·크기·다른 의상은 유지하고 4개 보행 단계는 구분한다. 결과는 source-costume-edit.png에 보존했다.
2. 첫 수정 결과의 3번만 다시 요청했다. 4번과 같은 골반 연결에서 검은 왼다리는 길게 아래로 뒤를 받치고 흰 오른다리는 짧게 앞으로 나가는 작은 반대 접지로 그리며, 두 다리의 경로를 분리하고 다른 세 컷은 유지한다. 결과는 source-pose3-edit.png다. 이 두 번째 결과에서는 3번만 채택했다.

`tools/art/export-scarlet-nw-costume-v5.ps1`로 합성·팔레트 변환·시트 패킹·4번 해시 검증을 재현한다. 이후 제작 참고는 합성한 `source-keys.png`다. 생성 도구가 표시한 중간 시트를 최종본으로 제시하지 않는다.
