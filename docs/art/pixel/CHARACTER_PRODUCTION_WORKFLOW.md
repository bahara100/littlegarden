# 전신 프레임 기반 도트 캐릭터 제작

## 최신 변경 (2026-10-17)

**2026-10-18 현재 기준**: 공통 SE 걷기는 사용자 승인 V20(`garden-body-walk-se-v20/`), SW V1은 V20 반전으로 동기화했다. 편하게 팔을 내린 정지는 `garden-body-base-v2/`다. 첫 독립 앉기 `garden-body-sit-se-v1/`는 별도 보관했고, 실제 게임 모모·루루의 앉기를 참고한 새 후보는 `garden-body-sit-friends-v1/`다. 두 앉기 시안은 서로 다른 자세이며 새 후보는 사용자 검수 전이다. 기존 손/소매가 포함된 의상을 새 몸체에 그대로 덧씌우지 않는다. 아래 V1/V2 걷기 실험 설명은 제작 이력이다.

**공통 몸체 V1 거부/V2 복원**: 사용자가 V1의 품질·머리 분리·다리 문제를 지적했다. 도형 팔/다리와 별도 머리 접합 방식은 기준에서 제외한다. garden-body-walk-se-v2/의 README.md를 따라 잘 나온 전신 원본을 통째로 축소/정리하고 전신 픽셀을 보존한다. 레이어 분리는 원형을 훼손하지 않는 보조 수단이다. V2는 사용자 검수 전이다.

**공통 몸체 방식 추가 실험**: 사용자는 모모·루루를 바탕으로 몸체 하나에 머리·옷을 덧그리는 방식도 시도하기로 했다. garden-body-base-v1/의 README.md를 따른다. 정지/외형 교체 시안에 이어 garden-body-walk-se-v1/의 공통 SE 걷기4컷도 추가했다(사용자 검수 전). 생성 후보의 중복 걸음은 채택하지 않고 머리/작업복/신발을 재사용하며 팔다리를 도트 위치표로 다시 그려 전신 PNG에 합성했다. 승인된 홍련 보행과 게임 자산은 보존한다. 향후에는 자세별로 공통 몸체를 만들고 각 프레임에 머리·옷을 덧그려 보정한 후 전신 시트로 합성/재생한다.

**걷기 모션 제작 완료·사용자 승인**: SE는 scarlet-ingame-walk-se-v1/walk.png, NE는 scarlet-ingame-walk-ne-v9/walk.png로 확정했다. SW/NW는 각각 프레임별 좌우 반전이다.96×96 전신4컷·6 FPS를 유지한다. [최종 승인 기록](SCARLET_INGAME_WALK_APPROVED.md)과 scarlet-ingame-walk-approved.json의 자산 경로/SHA256이 후속 작업 기준이다. 모션은 새 요청 없이 다시 만들지 않는다. 후속 사용자 요청으로 메인 Phaser/Canvas 게임에도 연결했다. [게임 연결 기록](SCARLET_INGAME_RUNTIME_V1.md)을 따른다. 새 SD 앉기 전용 모션은 아직 없다.

가장 최신 비율/단순화 기준은 이후 사용자가 제공한 실제 인게임 SD 캡처 4장이다. 세밀한 앞선 AI 초안 대신 SD 캡처의 큰 머리·작은 몸·짧은 다리를 따르고, 우선 docs/art/pixel/scarlet-ingame-sd-v1/의 앞쪽 대각선 한 컷(96×96·24색 시안)부터 외형을 확인한다. 생성 밑그림의 축소/팔레트 변환과 Pixelorama 수작업 보정은 구분해서 기록한다.

외형의 최신 기준은 사용자가 직접 첨부한 인게임 이미지 3장과 피규어 뒷모습 1장이다. docs/art/pixel/scarlet-reference-redesign-v1/에서 원본의 머리 실루엣·흰 갓/밧줄/솜·흰색/검정 긴 무기·흰/보라/검정 팔레트만 남겨 단순화한다. 이전 창작 SD의 긴 끝묶음, 큰 빨간 띠, 검은 X자 스타킹을 새 원본에 강제하지 않는다.

사용자 지시로 홍련을 AI 정지 초안부터 다시 시작한다. 원본 두 방향(SE ↘, NE ↗)만 제작하고 SW/NW는 각각 전체 좌우 반전으로 만든다. 반전으로 다리 의상과 칼 위치가 바뀌는 것을 허용한다. 아래 2026-10-16 기록의 7번(단순 반전 금지)은 이전 네 방향 제작에 대한 이력이며 새 제작에는 적용하지 않는다.

새 순서: 두 방향 AI 정지 초안 → 외형 기준 확인 → 공통 베이스/레이어 정리와 도트 보정 → 원본 방향당 전신 걷기 4컷(6 FPS) → 반전 방향 확인 → 시트 출력과 게임 연결. 96×96·32색 이하 규격은 변경 요청이 있기 전까지 유지한다. AI 초안은 축소/팔레트 제한만으로 완성됐다고 취급하지 않는다.

새 초안 폴더: docs/art/pixel/scarlet-restart-two-directions-v1/. 이전 NW V15 등 게임 적용 자산은 새 초안과 구분한다.

2026-10-16 사용자와 공식 도구 문서를 확인한 뒤 결정한 최신 방식이다. 이전 고정 부품/관절 시험보다 이 지침을 우선한다.

## 제작과 게임 재생
1. 앞오른쪽(SE)의 96×96 기본 도트 한 컷을 기준으로 고정한다.
2. 주요 걷기 자세 4개를 전신 이미지로 만든다. 골반/몸통/팔/머리를 함께 조정한다.
3. 이전/다음 컷을 겹치는 어니언 스킨, 정지 컷 비교, 반복 재생으로 검수한다.
4. 방향마다 4프레임을 최종 재생 규격으로 사용한다(기본 6 FPS). 제작 시간을 고려한 최신 사용자 결정이며, 별도 요청 없이 8프레임으로 확장하지 않는다.
5. 동일한 캔버스/스케일/팔레트/발 기준점으로 PNG 시트를 만든다. 각 컷의 내용 경계에 따라 크기를 따로 맞추지 않는다.
6. 게임은 완성 시트의 사각 영역을 잘라 순서대로 재생한다. 엔진 슬라이싱이 그림의 자세 오류를 고쳐 주지는 않는다.
7. 한 방향의 품질이 확정된 뒤 나머지 방향을 만든다. 비대칭 의상/칼집 때문에 단순 좌우 반전하지 않는다.

## 외형 기준
- LEFT는 캐릭터 자신의 왼다리: 검은 교차 끈. RIGHT는 오른다리: 분홍 지그재그 흰 스타킹.
- 앞오른쪽에서 왼쪽 골반은 화면 오른쪽, 오른쪽 골반은 화면 왼쪽이다. 앞으로 나온 발에 따라 디자인을 교환하지 않는다.
- 머리/모자/몸 비율, 얼굴, 허리 장식과 칼집을 컷 사이에 유지한다.
- 왼쪽 허리에 칼 한 자루, 자루–코등이–칼집이 한 축으로 이어진다.
- 뒷머리는 풀어진 한 덩어리이며 아래 끝만 등 뒤 중앙 한곳에서 묶는다.
- 96×96 / 고정 팔레트 32색 이하 / 발 기준 (48,88) / 투명 배경.

## 제작 보조와 검수
이미지 생성은 원형/자세 초안의 보조 수단이다. 레이어/부품은 수정과 디자인 관리에 활용하되, 회전한 부품을 도트 보정 없이 최종 자세로 취급하지 않는다. 최종 재생 원본은 전신 프레임이다.

- 검은 끈이 네 컷 모두 같은 다리를 따라가는가?
- 후면에서는 각 컷의 골반 → 허벅지 → 무릎 → 종아리 → 발 연결을 추적해 의상 소유권을 확인한다. 접지 컷의 순서를 재정렬하는 것만으로 좌우 디자인 교체 오류가 해결되었다고 판단하지 않는다.
- 2번 오른발 이동과 4번 왼발 이동이 구분되는가?
- 골반/몸통/반대 팔이 함께 움직이고 무릎/발끝이 진행 방향을 유지하는가?
- 컷 사이에 몸/모자 크기, 좌우 의상, 발 기준점이 갑자기 바뀌지 않는가?
- 1→2→3→4→1 전체 순환에 도약/발 뒤집힘이 없는가?
- 자동 규격 검사를 작화와 자연스러운 보행의 검증으로 오해하지 않는가?
