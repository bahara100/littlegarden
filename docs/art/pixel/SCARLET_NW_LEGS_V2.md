# NW V2: 보폭과 다리 의상 수정

사용자 지적: V1 3번의 보폭이 과도하고 네 컷에서 좌우 다리 의상이 맞지 않는다. V1은 사용자 미승인 비교 자료이며 최신 기준으로 쓰지 않는다.

최신본: `apps/client/public/sprites/scarlet/fullframe-nw-v2/walk.png` (4컷, 96×96, 6 FPS). 최종 표시 이미지는 같은 폴더 `walk-preview-2x2.png`다.

- 왼쪽 골반의 검은 교차 끈 다리와 오른쪽 골반의 흰 스타킹 다리를 분리해 네 컷에서 이어지도록 보정했다. NW에서는 검은 다리가 화면 왼쪽 골반에서 출발하고 흰 다리는 화면 오른쪽 골반에서 출발한다. 화면 끝 발만 보고 무늬를 교환하지 않는다.
- 1: 짧게 앞으로 나간 검은 왼다리, 뒤로 길어진 흰 오른다리.
- 2: 검은 왼다리로 지지, 흰 오른다리를 굽혀 통과.
- 3: 과도한 좌우 벌림을 줄여 몸 아래로 모았다. 검은 왼다리가 아래로 길게 뒤를 받치고 흰 오른다리는 짧게 앞으로 나간 반대 접지 자세다.
- 4: 흰 오른다리로 지지, 검은 왼다리를 굽혀 통과.

내장 image_gen으로 V1 최종 순서의 source-keys.png를 편집했다. 첫 요청은 네 컷의 골반별 의상 소유권을 고정하고 3번 보폭을 줄이는 것이었다. 그 결과 3번이 1번과 비슷해져, 두 번째 요청으로 3번만 검은 다리를 화면 왼쪽 아래로 길게/흰 다리를 화면 오른쪽 위로 짧게 만드는 작은 반대 보폭으로 바꾸고 왼쪽 허리 칼집을 복원했다. 최종 생성 편집 원본은 `source-leg-edit.png`다.

`tools/art/export-scarlet-nw-legs-v2.ps1`은 V1의 공통 샘플링 크기·좌표를 유지하고, y0..49는 기존 재생 프레임에서 그대로 복사한다. 허리 아래 y50..95만 새 이미지에서 채택한다. 컷별 자동 크기 조정이나 포즈 재정렬은 없다. 최종 고해상도 기준은 합성한 source-keys.png이며, 생성 원본을 최종 표시용으로 사용하지 않는다.

네 컷의 모자·상반신 상부 y0..49 픽셀 변경 0, 고정 팔레트 최대 32색, 투명 배경 및 실제 재생/미리보기 픽셀 대조를 확인했다. 보행 자연스러움과 의상의 최종 판정은 사용자 검수로 남는다.
