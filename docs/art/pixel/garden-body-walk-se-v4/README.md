# 공통 몸체 SE 걷기 V4 · 1번 왼발 앞, 오른발 뒤

사용자 지시: “1번 컷이 다리가 서로 반대로 되어야 해. 그래야 4-1로 이어지는 자연스러운 걸음 모션이 돼.” 이어서 다리를 새로 칠한 시안을 거부하고 “기존꺼로 다시 돌려. 기존꺼에서 왼발을 앞으로 뻗고 오른발을 뒤로 뻗으면 되는건데”라고 했다. 그 시안은 지웠다.

V4는 V3 1번 자신의 골반(양팔 사이 반바지, 행 63~68, 열 41~59)과 다리(행 69~95, 열 36~64)를 골반 가운데 x=50을 축으로 좌우 반전했다(V3가 3번에 쓴 것과 같은 범위). 새로 그린 픽셀은 없다. 이제 1번은 화면 왼쪽 발이 앞(아래)에 딛고 화면 오른쪽 발이 뒤(위)로 뻗는다. 4번(왼발이 받치고 오른발이 뒤로 들림)에서 1번으로 왼발 앞·오른발 뒤가 이어진다.

1번의 머리·가슴·팔과 2·3·4번 PNG는 V3와 픽셀 동일하다. 검사: 8방향 연결, 이진 알파, 미리보기·GIF와 walk.png 일치.

도구: tools/art/build-garden-body-walk-se-v4.py. 확인 페이지: apps/client/public/body-walk-se-v4/index.html. 사용자 검수 전이다.
