# 홍련 인게임 SD · 뒤오른쪽 걷기 V1

2026-10-17. 승인한 SE 걷기를 보존하고 승인한 NE 정지 외형으로 만든 후면 걷기 시안이다. NE 보행과 반전 방향은 사용자 검수 전이다.

- 실제 재생: walk.png, 384×96, 전신 96×96 네 컷, 6 FPS.
- 방향: NE 원본 ↗. NW ↖는 검수 화면에서 각 컷을 통째 좌우 반전한다. SE/SW도 같은 구조다. 프레임 순서를 반대로 하지 않는다.
- 외형: 회보라 단발, 흰 갓·밧줄·솜, 금색 두 갈래 장식, 흰 허리 리본, 보라 허리 장비, 왼쪽 허리의 흰색/검정 칼집.
- 원본 NE 왼다리는 먼 쪽 주름 부츠, 오른다리는 가까운 쪽 매끈한 흰 장비다. 반전 방향은 의상과 무기 위치도 함께 반전한다는 사용자 결정을 따른다.
- 1 왼발 접지 → 2 오른발 통과 → 3 오른발 접지 → 4 왼발 통과. 작은 반대 팔 움직임과 몸통 높낮이가 포함된다. 정지 컷과 반복 재생으로 보폭/순환/접지를 검수한다.

## 제작과 출력

내장 image_gen으로 NE 정지 도트/고해상도 밑그림과 승인 SE 걷기를 참고해 2×2 전신 시트를 생성했다. 요청문은 prompt.txt, 원본은 source-keys.png다. Pixelorama 수작업 보정본은 아니다.

tools/art/export-scarlet-ingame-walk-se-v1.ps1 -Direction ne로 공통 크롭과 배율을 사용해 축소·공유24색에 양자화하고 머리를 정렬했다. 각 컷 사용색은22~23색이다. 접지 컷의 모자 최상단은10행, 통과 컷은9행으로 정렬했고 발바닥 위치를 개별 정규화하지 않았다. 크롭/배율/정렬/프레임 SHA256은 walk.json에 기록했다.

walk-preview-2x2.png와 walk-preview.gif는 실제 walk.png에서 만들었다. 두 미리보기 모두 시트와 픽셀 불일치0을 확인했다. onion-diagnostic.png는 이전 컷을 반투명으로 겹친 검수 보조 이미지다. 생성 원본을 최종96px 도트 미리보기로 안내하지 않는다.

## 브라우저 확인

http://127.0.0.1:4184/ 의 네 방향 선택, 컷별 정지, 이전 컷 겹치기, 4→1 연결 및6 FPS 재생을 확인했다. 소스는 ../scarlet-ingame-walk-se-v1/index.html이다. 그 폴더의 ne/에는 이 폴더의 시트·2×2·GIF 복사본만 있어 동일 URL에서 검수할 수 있다. 복사본 SHA256 일치를 확인했다.

기존 SE walk.png의 SHA256은 87D805F852F689FCBBC25553CF415304C8A110691C506351DCAA8A33D4F8B077 그대로다. 기존 메인 게임에는 아직 새 걷기를 연결하지 않았다. 자동 픽셀 검사는 동작의 자연스러움에 대한 사용자 승인을 대신하지 않는다.
