# NW V6: 흰 오른다리가 보이는 낮은 통과 자세

사용자는 반복된 좌우 의상 오류를 지적했고 이 방향의 걷기를 우선 마무리하도록 요청했다. 최신 런타임은 `fullframe-nw-v6/walk.png`, 4프레임·6 FPS다. 사용자 최종 승인 전이다.

V5를 다시 살펴보고 2번에서 흰 오른다리가 깊이 굽혀져 검은 신발 밑창만 크게 보이는 부분을 낮은 통과 자세로 수정했다. 흰 종아리와 발목이 보이고 신발은 옆면으로 보이도록 바꿨다. 1번도 같은 오른다리 흰색/왼다리 검은 교차 끈 디자인으로 정리했다. 3번은 검은 왼다리가 길게 뒤를 받치고 흰 오른다리가 짧게 앞으로 나온 V5를 유지하며, 4번도 V5와 PNG 바이트 동일하다.

내장 image_gen으로 V5 최종 source-keys.png와 V4 4번의 고해상도 편집본을 참고했다. 최종 요청: 4번을 고정하고 1~3번의 허리 아래만 같은 골반별 의상으로 맞추기, 오른다리는 흰색이며 검은 끈이 없어야 하고 왼다리는 검은 교차 끈이 있어야 함, 특히 2번 오른발의 과도한 접힘과 커다란 밑창을 줄여 흰 종아리를 보이는 낮은 통과 자세로 바꾸기, 1·3번은 서로 반대 접지로 유지하기, 비율·카메라·모자·머리·상체·투명 배경은 유지하기.

생성본 source-edit.png의 3번은 의상 배치가 다시 틀려 채택하지 않았다. 1·2번의 y50..95만 채택하고, 그 위 및 3·4번은 V5에서 그대로 복사했다. 이후 참고는 최종 합성 source-keys.png이며, 생성본 전체를 완성본으로 제시하지 않는다. 재현 도구: tools/art/export-scarlet-nw-pass-v6.ps1.

walk-preview-2x2.png와 walk-preview.gif는 실제 walk.png만 잘라 만든 표시물이다. 정지 미리보기 픽셀 대조, GIF 디코딩 후 모든 프레임 픽셀 대조, 3·4번 PNG 해시 동일, 상부 픽셀 변경 0, 최대 32색을 검사한다. 이러한 규격 검증으로 보행 자연스러움이나 해부학적 판정의 사용자 승인을 대신하지 않는다.
