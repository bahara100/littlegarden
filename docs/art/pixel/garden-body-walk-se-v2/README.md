# 공통 몸체 SE 걷기 V2 · 전신 원본 보존

사용자는 V1의 품질 저하, 머리/몸 연결, 이상한 다리를 지적했다. V1은 거부된 시안이다. 원인은 전신 생성 초안을 머리/작은 몸통/도형 팔다리로 다시 조립하며 원본의 목 연결·곡선·명암을 잃은 데 있었다.

V2는 **전신 원본 전체를 통째로 축소**했다. 머리와 다리를 다른 그림으로 교체하거나 도형으로 다시 그리지 않는다. 각 이미지의 출력 크기를 머리 폭 기준으로 맞추고, 한 번의 전신 샘플링과 공통32색 매핑만 한다. 몸통만 따로 찌그러뜨리거나 팔다리 길이를 조정하지 않았다.

-1·2번: V1 폴더의 source-cycle-candidate.png 상단 두 전신. 두 컷에 동일 배율을 쓴다.
-3번: source-pose1.png를 참고해 내장 image_gen으로 반대 걸음 전신을 수정한 source-pose3.png. 화면 왼쪽의 낮은 앞발/오른쪽의 높은 뒷발과 반대 팔 스윙을 확인했다. 요청문은 prompt-pose3.txt다.
-4번: V1 source-opposite-candidate.png 오른쪽 전신. 화면 왼쪽 다리는 지지하고 오른쪽 무릎이 접힌 원본이다.

새3번과4번의 생성 원본 해상도가 달라 출처별로 머리 폭48px을 기준으로 배율을 보정했다. 모든 부위는 전신과 함께 같은 비율로 줄인다. 통과 컷의1px 위 이동도 전신 전체에 적용했다. 새 정지 베이스 머리를 별도로 붙이지 않는다. 프레임별 배율과 경계는 walk.json에 기록했다.

산출물:

- walk.png: 실제 재생384×96 시트,1→2→3→4,6 FPS.
- frame-1~4.png: 동일한96×96 전신.
- walk-preview-2x2.png,walk-contact-4x.png: 실제 재생 컷의 최근접4배 확대.
- walk-preview.gif: 같은 시트를4컷·6 FPS로 패키징한 미리보기.
- body-walk.png/head-walk.png: 완성 전신의 픽셀을 단순 분할한 편집용 레이어. 기본 재생은 원본 전신 시트를 직접 그리며 레이어를 다시 맞붙이지 않는다. 두 레이어를 제자리에 겹치면 전신 픽셀 그대로다.
- palette.json: 네 컷 전체에서 만든 공유32색 팔레트. 원본의 피부/옷/윤곽 명암을 위한 색이다.

검사: 네 전신 모두 이진 알파,32색 이내,96×96 경계와 머리→목→몸통→발의8방향 픽셀 연결을 통과했다. 확대2×2와 재생 시트 원본 픽셀 차이는0이다. 이 검사는 연결/패키징 확인이며 보행 자연스러움에 대한 사용자 승인은 아니다.

도구: 내장 image_gen으로3번 수정, tools/art/build-garden-body-walk-se-v2.ps1로 전신 크기/팔레트/시트 정리, pack-garden-body-walk-gif-v2.ps1로 GIF 패키징. Pixelorama 수작업본으로 안내하지 않는다.
