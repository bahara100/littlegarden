# NW V9: 흰 오른다리가 검은 왼다리 뒤로 가려지는 겹침

사용자가 V8 제작 중 명확히 지시했다: 뒤오른쪽을 참고하고, 1·2번의 흰 오른다리가 왼다리에 가려지게 표현한다. 흰 오른다리가 검은 왼다리를 덮으면 잘못된 깊이 관계다.

내장 image_gen에 NW V8 최종 합성본과 NE V5 source-keys.png를 참고로 제공하고, 1·2번의 다리 겹침만 수정했다. 검은 왼다리의 허벅지→무릎→종아리가 앞쪽에서 이어지고, 흰 오른다리는 뒤에 가려진 후 아래쪽만 드러난다. 정확한 요청은 fullframe-nw-v9/edit-prompt.txt다.

V8은 3번을 좁은 교차 보폭으로 다시 그린 중간 버전이며, 2·3·4번은 전신 생성 컷을 채택했다. 행 경계로 상체를 합치면 팔에 이음매가 생겨 해당 합성을 폐기했다. V9는 V8 위에 1·2번의 다리 영역만 마스크로 합친다. 3·4번 PNG는 V8과 바이트 동일하다. 후속 기준은 V9 source-keys.png, 최종 표시물은 실제 walk.png에서 만든 walk-preview-2x2.png와 walk-preview.gif다.

재현: tools/art/export-scarlet-nw-depth-v9.ps1. 마스크는 이전 다리의 윤곽까지 포함해 이전 흰 다리나 신발의 잔상이 남지 않도록 구성했다. 정지 미리보기/재생 시트 및 GIF/재생 시트의 픽셀 차이는 0으로 검사했다.

사용자 반응: “이제 좀 낫네.” 이후 허리춤의 칼을 제대로 그려 넣도록 요청했다. 다음 수정은 다리 겹침과 보행 자세를 유지하고 칼에 집중한다.
