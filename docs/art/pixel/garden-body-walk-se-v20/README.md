# 공통 몸체 SE V20 · 사용자 승인 기준본

2026-10-18 사용자가 **“좋아좋아. 이 버전으로 정할께.”**라고 확정했다. 현재 SE 기준은 이 V20이며 SW V1도 컷별 반전으로 동기화했다. 별도 요청 없이 자세를 다시 변경하지 않는다.

사용자가 V19를 좋다고 평가하고 “여기서 보폭 살짝만 줄여줘”라고 요청했다.

V19 Pixelorama 원본에서 1번의 행77 아래 기존 다리 픽셀만 수정했다. 앞 왼발은 왼쪽으로 1px, 뒤 오른발은 오른쪽으로 1px 이동해 두 발의 가로 간격을 2px 줄였다. 발 높이·신발 디자인·색·명암은 유지했다. 행0..76과 2·3·4번은 V19 그대로다.

V18/V19 및 게임은 보존했다. 네 컷 96×96, 6 FPS다. 확인 페이지에서는 V19(왼쪽)와 승인 V20(오른쪽)을 같은 시점에 재생한다. 공통 몸체는 실제 게임에는 아직 연결하지 않았다.

- 편집 원본: `garden-body-se-frame1-v20.pxo`
- 재출력: `python tools/art/build-garden-body-walk-se-v20.py` (먼저 Pixelorama에서 `frame1-pixelorama.png` 내보내기)
- 확인 페이지: `apps/client/public/body-walk-se-v20/index.html`
