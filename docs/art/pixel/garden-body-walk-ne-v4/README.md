# 공통 뒤 걷기 V4 · 팔 순환 보정

사용자가 네 컷 모두 팔이 고정임을 지적해 NE V3의 팔만 수정했다. SE V20은 유지한다.

- 1번: 기존 NE V2 3번의 반대 팔 작화를 채택해 왼팔 앞/오른팔 뒤.
- 2번: 편한 뒤 대기의 팔을 걷기 높이에 맞춰 재배치한 중간 통과 자세.
- 3번: NE V3 원본 그대로, 오른팔 앞/왼팔 뒤.
- 4번: 중간 통과 팔을 2번과 반대 방향으로 조금 벌린 자세.
- 기존 머리 행0..44, 골반 아래 행68..95는 컷마다 그대로다. 3번 전체는 원본과 같다. 몸통 경계와 팔 연결은 도트로 맞췄다. 새 AI 걷기를 생성하지 않았다.
- 96×96·4컷·6 FPS·32색. NW는 최종 전신 컷별 반전이다. 관절을 런타임에서 돌리지 않는다.
