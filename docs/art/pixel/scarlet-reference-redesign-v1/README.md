# 사용자 제공 원본으로 만든 홍련 AI 초안

2026-10-17. 기존 SD 창작 이미지를 다시 참고하지 않고, 사용자가 제공한 인게임 이미지 3장과 피규어 뒷모습 1장을 외형의 우선 기준으로 삼는다. 내장 image_gen으로 도트 작업 전 정지 초안을 만든다.

## 남길 특징

- 회갈색이 섞인 연한 회보라색 머리. 뒷머리 길이와 흐름은 피규어 사진 기준. 기존 SD의 허리까지 길게 내려온 끝묶음이나 양갈래를 덧붙이지 않는다.
- 넓고 납작한 흰색/은회색 갓, 얇고 긴 황동색 두 갈래 장식, 굵은 흰 밧줄과 양끝의 흰 솜 장식, 보라색 끝술과 황동색 긴 패찰.
- 흰 몸통 의상과 검정 어깨띠, 보라색 허리 장비/옆판, 흰 허리끈과 뒤쪽 천. 빨강은 원본의 작은 어두운 앞 천 정도로만 쓴다.
- 흰색/은회색의 긴 칼과 칼집, 검정 기하학 슬롯. 무기는 허리 뒤를 가로지르는 원본 실루엣을 단순화한다.
- 좌우가 다른 다리 형태는 원본을 참고하되, 작은 문양·주름·끈은 도트에서 읽히는 몇 개의 큰 형태로 줄인다. 예전 검은 교차 스타킹을 강제하지 않는다.

## 결과물과 범위

원본 두 방향은 SE(앞오른쪽)와 NE(뒤오른쪽). SW/NW는 전체 좌우 반전을 허용한다. AI 정지 초안 단계이며 보행 프레임이나 도트 완성본이 아니다. 기존 게임 자산은 유지한다.

정확한 생성 요청은 prompt-se.txt / prompt-ne.txt에 저장한다. source reference 파일명은 reference-files.json에 기록한다. 두 초안은 draft-se.png / draft-ne.png이며, draft-pair.png는 두 원본을 축소하거나 그리지 않고 나란히 묶은 표시물이다.

NE 최초 초안은 갓의 두 갈래 장식이 뒤쪽에 붙어 있어, 피규어 후면 사진을 참고해 이마 쪽(화면 오른쪽 앞)으로 옮기는 보정을 했다. 요청은 prompt-ne-hat.txt다. draft-ne-hat-before.png는 보정 전 이력이며 최종 표시본이 아니다.
