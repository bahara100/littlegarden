# 홍련 재시작: 두 원본 방향 + 좌우 반전

2026-10-17 사용자 지시: “2방향만 그리고 좌우 반전할래. 홍련을 다시 AI초안부터 새로 해볼래?”

## 현재 단계

새 홍련의 정지 AI 초안. 기존 SD 디자인과 기본 복장을 참고해 더 간결한 형태로 다시 그린다. 내장 image_gen을 사용한다. 정밀 도트 보정과 걷기 프레임 제작 전이며 현재 게임에 연결된 자산과 구분한다.

| 실제 원본 | 파생 방향 |
|---|---|
| SE 앞오른쪽 ↘ · draft-se.png | SW 앞왼쪽 ↙ · SE 전체 좌우 반전 |
| NE 뒤오른쪽 ↗ · draft-ne.png | NW 뒤왼쪽 ↖ · NE 전체 좌우 반전 |

두 원본에서는 오른다리 흰 스타킹·왼다리 검은 리본, 왼쪽 허리의 칼이라는 홍련의 특징을 유지한다. 파생 방향은 다리 무늬와 칼 위치까지 함께 반전한다. 사용자 결정에 따라 이 반전 결과를 허용하며 네 방향을 따로 그려 비대칭을 다시 고치지 않는다.

## 제작 기준

- 약 2등신, 고정한 비율과 약간 내려다보는 대각선 카메라, 전신과 발을 모두 보이는 중립 서기.
- 모자·눈·머리·붉은 허리띠·옷의 큰 색 덩어리로 식별되도록 단순화한다.
- 뒷머리는 한 덩어리로 풀어 내리고 끝을 등 뒤 중앙 한곳에서 묶는다.
- AI 정지 초안을 외형 기준으로 확인한 다음 Pixelorama에서 공통 몸체와 레이어를 정리한다.
- 후속 도트 규격: 96×96, 32색 이하. 걷기는 원본 방향당 전신 4프레임, 기본 6 FPS.
- 시트 출력과 실제 재생 검수는 도트 작업 단계에서 한다. 정지 초안을 애니메이션 완성본으로 보고하지 않는다.

## 생성 기록

원본 SE는 기존 캐릭터 디자인을 참고해 새로 생성하고, NE는 새 SE를 외형 기준으로 사용해 비율과 색을 맞춘다. 정확한 프롬프트는 prompt-se.txt / prompt-ne.txt에 기록한다. 두 생성 PNG는 투명 배경 원본 그대로 보관한다.
