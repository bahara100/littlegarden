# 생선구이 아이콘 V1

16×16 투명 PNG,9색. 노릇한 통생선과 구운 자국·접시·작은 김을 그렸다. 기존 말풍선 아이콘과 같은 정수 배율로 표시한다.

`tools/art/make-emote-icons.py`의 `grilled_fish()`와 팔레트가 재생성 원본이다. `grilled-fish.pxo`는 실제 Pixelorama 편집 원본, `preview-16x.png`는 정수16배 확대다. 실제 게임용 PNG는 `apps/client/public/sprites/ui/emotes/grilled-fish.png`다. 네이티브 내보내기와 코드 격자의 픽셀 일치·알파·색 수·기존12아이콘 SHA 보존을 확인했다.

말풍선 키 `생선구이`를 새 아이콘으로 매핑했다. 기존 호수 물고기/낚시 아이콘과 행동은 유지했으며 자동 먹기 행동은 추가하지 않았다. 작화는 사용자 검수 전이다.
