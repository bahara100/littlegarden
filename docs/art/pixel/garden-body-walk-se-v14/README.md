# 공통 몸체 SE 걷기 V14 후보 · 왼 허벅지 기울기, 작은 종아리·신발, 오른 신발 외곽선

사용자 지시: 왼 허벅지가 골반부터 무릎까지 “\” 느낌으로 기울게. A(곧은 다리)/B(무릎 앞) 중 **B**를 고르고, “왼발의 무릎 아래의 종아리부터 발 크기를 조금 작게 해. 그리고 오른쪽 다리의 신발 테두리 부분 마저 채워.”

V14 1번(Pixelorama MCP, garden-body-se-frame1-v14.pxo):
- 왼다리(앞): 행 69~70은 반바지에 붙여 두고, 허벅지가 무릎(행 77)까지 오른쪽 아래로 +4px 기운다(\). 종아리는 발 쪽으로 돌아오고(+4, +3, +3, +2) 신발은 +2px.
- 무릎 아래: 종아리 바깥쪽 1px 가늘게, 신발은 가운데 열 하나와 가운데 행 하나를 빼 1px씩 작게 했다. 바닥은 행 89 그대로이고 종아리가 한 줄 더 내려와 신발에 닿는다. 종아리 바깥 외곽선 계단을 정리했다.
- 오른다리(뒤, 위): 그대로이고, 들린 뒤 신발의 회색이 빈 곳과 맞닿던 오른쪽·위쪽에 외곽선을 채웠다.
