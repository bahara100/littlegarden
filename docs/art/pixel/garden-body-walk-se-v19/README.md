# 공통 몸체 SE 걷기 V19 · 1번 보폭 수정 후보

사용자가 V18 1번의 자세에 대한 평가를 확인한 뒤 수정을 요청했다. **V18은 승인 기준으로 보존하며 V19는 사용자 검수 전 후보**다.

기존 V18 `.pxo`의 다리 레이어를 Pixelorama에서 직접 수정했다. 새 다리나 신발을 생성하지 않았다.

- 왼다리(앞, 화면 오른쪽 골반): 허벅지 아래를 단계적으로 오른쪽으로, 앞발을 (+2,+1)px로 옮겨 앞으로 내딛는 기울기를 늘렸다. 종아리 연결에 기존 한 줄을 반복했다.
- 오른다리(뒤, 화면 왼쪽 골반): 아래로 갈수록 왼쪽으로 이동해 뒷발은 (-3,0)px. 발을 몸 아래에 모으는 느낌을 줄였다.
- 1번 행 0..70(머리·몸·팔·골반 연결부)은 그대로이며, 2·3·4번 PNG는 V18과 바이트 동일하다. 기존 팔레트·다리 명암·신발 그림을 유지했다.

전신 96×96 네 컷, 6 FPS. 재생 시트에서 정지 미리보기와 GIF를 만들었다. 기술적 보존 검사와 자연스러운 보행 평가는 구분한다. SW나 실제 게임은 아직 변경하지 않았다.

- 편집 원본: `garden-body-se-frame1-v19.pxo`
- 재출력: `python tools/art/build-garden-body-walk-se-v19.py` (Pixelorama에서 `frame1-pixelorama.png`를 먼저 내보낼 것)
- 비교: `frame1-before-after-6x.png` (왼쪽 V18 / 오른쪽 V19)
- 확인 페이지: `apps/client/public/body-walk-se-v19/index.html`
