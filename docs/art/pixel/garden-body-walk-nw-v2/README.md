# 공통 몸체 NW 걷기 V2 · NE V2 컷별 반전

`garden-body-walk-ne-v2/`의 실제 전신 네 컷을 x→95−x로 각각 반전했다. 새로 그린 픽셀은 없으며 원본의 팔·다리·모든 명암이 함께 반전된다. 96×96·방향당4컷·6 FPS. 사용자 검수 전이다.

편집 원본은 NE의 `garden-body-walk-ne-v2.pxo`이며 출력은 `tools/art/build-garden-body-walk-ne-v2.py`로 함께 만든다. 확인 페이지 `apps/client/public/body-walk-nw-v2/index.html`은 NE/NW 공통 검수 화면의 NW 선택으로 이동한다. 실제 게임은 변경하지 않았다.
