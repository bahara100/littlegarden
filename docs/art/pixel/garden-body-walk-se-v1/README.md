이 시안은 제작 기준에서 제외됐다. 아래 기록은 실패 이력이다. 전신 원본을 살리는 V2로 수정한다.

# 공통 몸체 앞오른쪽 걷기 V1 · 사용자 검수 전

사용자가 모모·루루 기반 베이스에 이어 공통 걷기 제작을 요청했다. 이번 범위는 **SE 원본 한 방향,96×96 전신4컷,기본6 FPS**다. 다른 방향,캐릭터별 걷기 의상,앉기,메인 게임 교체는 이번 작업에 포함하지 않았다.

`walk.png`가 실제 재생 시트(384×96)다. frame-1~4.png는 같은 네 컷, walk-preview-2x2.png와 walk-contact-4x.png는 그 결과의 최근접 확대다. 최종 표시본은 이 파일들만 사용한다. 시트와2×2 원본 픽셀 차이0을 검사했다.

## 제작 방식

- 최초 image_gen 시트는1·3번/2·4번이 같은 다리 배치로 나왔다. 반대 걸음 생성 후보도3번이 제대로 바뀌지 않았다. 두 생성 원본은 source-*-candidate.png와 prompt-cycle.txt/prompt-opposite.txt에 보존하되 **후보 다리는 채택하지 않았다**.
- 머리는 garden-body-base-v1/base-head.png를 그대로 재사용한다. 컷별 이동값은 [0,0],[0,-1],[1,0],[1,-1]이다. 머리 크기·윤곽을 프레임마다 다시 생성하지 않았다.
- 몸통의 회색 작업복은 첫 후보의 중앙부에서 같은 크기로 추출하고, 잘린 외곽선·반바지 두 입구를 도트로 정리했다. 팔과 다리는 고정한 위치표를 바탕으로 피부3색/윤곽선을 래스터로 그렸다. 신발은 정지 베이스의 같은 도트를 재사용한다. 별도의 완성4컷 PNG에 합성했으며 런타임 관절 회전으로 표시하지 않는다.
- 작업 도구는 내장 image_gen + PowerShell/C# 도트 조립·보정이다. Pixelorama 수작업 완성본이라고 안내하지 않는다.
- 모모·루루 정지 시안의 임시 의상(손/소매 포함)을 그대로 움직이는 몸체 위에 붙이지 않는다. 몸체 검수 후 **각 자세에 맞춰** 소매·손 가림·옷자락을 덧그릴 예정이다.

## 네 자세와 기준

| 컷 | 동작 | 오른발 바닥점 | 왼발 바닥점 | 앞쪽 팔 |
|---|---|---|---|---|
|1|왼발 앞 접지/오른발 뒤|49,86|60,90|오른팔|
|2|오른발 낮은 통과/왼발 지지|53,82|56,88|통과 자세|
|3|오른발 앞 접지/왼발 뒤|57,90|52,86|왼팔|
|4|왼발 낮은 통과/오른발 지지|53,88|56,82|반대 통과 자세|

원본의 오른쪽 골반은 화면 왼쪽, 왼쪽 골반은 화면 오른쪽이다. right-leg/left-leg 레이어를 별도로 저장하며 화면 위치가 바뀌어도 같은 골반부터 이어진다. 발점의 y차이는 아이소메트릭 지면에서 앞뒤 위치 차이다. 앵커(48,91)는 그림의 공통 배치점이며 모든 신발 밑면이 같은 수평선에 놓인다는 뜻은 아니다.

딛은 발은 다음 컷에서(-4,-2)px로 움직이는 관계다. 왼발은1→2→3에서(60,90)→(56,88)→(52,86), 오른발은3→4→다음1에서(57,90)→(53,88)→(49,86)이다. 제자리 재생의 신발 위치표이며, 실제 게임 속도와 완전한 발 고정은 게임 연결 단계에서 별도로 맞춘다. 통과 컷은 골반·몸통·머리가1px 높고, 반대 접지는 체중을1px 옆으로 이동한다.

- 재현 도구: tools/art/build-garden-body-walk-se-v1.ps1.
- 확인 화면: apps/client/public/body-walk-se-v1/index.html. 로컬 주소 http://127.0.0.1:4185/body-walk-se-v1/index.html.

기본6 FPS/천천히3 FPS, 컷별 정지, 이전 컷 겹치기,발 기준선,머리 숨기기,1·3번 몸통/다리 비교를 제공한다. 현재 놀이터와 승인된 홍련 SE/NE 걷기 파일은 유지한다. 공통 몸체 보행은 사용자 검수 전이다.
