# 홍련 실제 GLB 제작본 1

## 상태

확정된 v3 디자인을 목표로 별도 메시/UV/얼굴 텍스처/스켈레톤/애니메이션을 작성했다. 기존 런타임 도형 모델을 GLB로 직렬화한 파일이 아니다. 다만 **현재 결과는 리깅과 게임 연결을 확인하는 초기 제작본이며, 확정 디자인 시트의 외형 완성도에 도달하지 못했다.** 얼굴·앞머리의 실루엣, 머리카락 곡선과 층, 의상 재단과 디테일은 계속 제작해야 한다. 5단계 아트 완료로 처리하지 않는다.

코드 기반 오프라인 메시 저작 방식이다. 이 환경의 Blender 설치 폴더에는 실행 파일이 없어 Blender에서 직접 편집/렌더링하지 않았다. Blender 원본 파일을 만들었다고 주장하지 않는다. 생성한 GLB는 Blender 등 표준 glTF 도구에서 열어 메시/본/애니메이션을 편집할 수 있다.

## 파일

- 실제 에셋: `apps/client/public/models/scarlet/scarlet-v3.glb`
- 메타데이터: 같은 폴더의 `manifest.json`
- 메시/UV/뼈대/애니메이션 저작 소스: `tools/art/build-scarlet.ts`
- 얼굴 텍스처 저작 소스: `tools/art/paint-scarlet-face.py`
- 편집 가능한 PNG 텍스처: `tools/art/scarlet-face.png`
- 게임 로더/모션 어댑터: `apps/client/src/scarletAsset.ts`
- 단독 검수 화면: `/character.html`

11개 본, 5개 클립(Idle/Walk/Wave/Sit/Swing), 정점 약 3.6만 개, 파일 약 2.5MB. 재질별 메시가 하나의 스켈레톤을 공유한다. 부위별 단일 본 가중치가 중심이며, 다관절 변형과 손가락/표정/옷감 물리 구현은 남아 있다.

## 재생성

프로젝트 루트에서:

```powershell
npm.cmd run art:scarlet
```

얼굴 페인팅 변경 시 Pillow가 설치된 Python으로 먼저 `tools/art/paint-scarlet-face.py`를 실행한다. 생성된 PNG는 GLB 안에 포함되므로 게임 실행 시 Python/Blender는 필요하지 않다.

## 게임 연결

- 같은 character ID를 사용해 저장된 배치와 호환된다.
- 모델을 비동기로 로드하고 준비되면 기존 표시 모델을 교체한다.
- 로드 실패 시 기존 임시 외형을 유지하고 안내한다.
- 행동 상태와 모션 클립을 연결하고, 좌석 전환 시 다리와 뒤쪽 머리/옷자락 자세를 보정한다.
- 이동 위치/좌석 예약은 기존 생활 시뮬레이션이 관리한다.
- 편집 중 로드가 끝나도 모델 숨김 상태를 유지한다.
- 검수 화면에서 정면/측면/후면/회전과 각 모션을 확인하고 GLB를 다운로드할 수 있다.
