# 작은 쉼표 · Little Garden 3D

마름모 시점의 실제 3D 놀이터를 만드는 싱글플레이 웹 프로젝트입니다. 현재는 수정 계획의 **1단계: 3D 표현 검증** 버전입니다.

## 실행

Node.js 24 LTS와 npm을 준비하고 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

게임: http://127.0.0.1:5173/

닉네임·로그인·게임 서버·환경 변수 없이 바로 열립니다. 외부 모델·이미지 없이 코드로 만든 임시 3D 모델을 사용하며 웹 폰트를 불러오지 못해도 기본 폰트로 실행됩니다.

## 이번 버전에서 확인할 것

- 16×16 지면이 마름모처럼 보이는 고정 직교 시점.
- 실제 입체로 만든 치비 캐릭터 1명, 나무 벤치, 그네, 나무/화단/울타리와 소품.
- 파스텔 재질, 부드러운 그림자, 대기 자세와 손 흔들기, 그네의 가벼운 흔들림.
- 캐릭터와 기구 클릭 시 정보 및 선택 표시.
- 줌, 화면 이동, 시점 초기화, 그리드 및 그림자 켜기/끄기.

캐릭터의 자율 산책, 클릭 이동, 기구 탑승, 배치 편집, 저장, 모바일 생활 조작은 **다음 단계**입니다. 화면 크기는 반응형으로 조정되며 모바일 생활 조작을 완성했다는 의미는 아닙니다. 니케 캐릭터 리소스는 아직 포함하지 않습니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| 캐릭터·벤치·그네 클릭 | 대상 정보 보기 |
| 우클릭 드래그 | 화면 이동 |
| ↔ 버튼 후 왼쪽 드래그 | 화면 이동 모드 |
| 휠 / + − 버튼 | 확대·축소 (65~210%) |
| ⌖ 버튼 | 처음 시점으로 복귀 |
| 작은 인사 건네기 | 캐릭터 손 흔들기 |
| 배치 그리드 / 그림자 스위치 | 장면 표현 비교 |

화면 이동 모드에서는 왼쪽 클릭 선택을 잠시 비활성화합니다. 대상을 선택하려면 ↔ 버튼을 다시 눌러 이동 모드를 끕니다. 카메라 회전은 고정됩니다. WebGL을 지원하는 최신 브라우저가 필요하며 초기화 실패/컨텍스트 손실 시 안내와 재시도 버튼을 표시합니다.

## 검사와 빌드

```sh
npm run check
npm run build
```

배포 결과는 `apps/client/dist`입니다. Vite base는 상대 경로여서 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다.

## GitHub Pages

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Settings → Pages → Source를 GitHub Actions로 설정합니다.
3. main 브랜치 push 또는 Publish game to Pages 워크플로 수동 실행으로 배포합니다.

이전의 `VITE_SERVER_URL` 변수는 현재 버전에 필요하지 않습니다. 현재 화면은 정적 파일만으로 실행되므로 별도 Node.js 서버 호스팅이 필요 없습니다. 원격 저장소 연결과 실제 공개 배포는 아직 수행하지 않았습니다.

## 구조

- `apps/client/src/scene.ts`: Three.js 장면, 임시 모델, 카메라, 선택, 모션.
- `apps/client/src/main.ts`: UI와 장면 연결.
- `apps/client/src/style.css`: 반응형 화면과 패널.
- `apps/server`, `packages/shared`, `tests`: 보존된 기존 멀티플레이 구현.
- `docs/archive/multiplayer-client`: 보존된 기존 2D 클라이언트 소스.
- `Dockerfile`: 기존 멀티 서버용으로 남긴 파일. 현재 3D 화면 배포에는 사용하지 않습니다.

이전 멀티 회귀 검사가 필요할 때만 아래를 실행합니다. 이는 현재 3D 화면 검사가 아닙니다.

```sh
npm run check:legacy
npm run build -w apps/server
npm run test:legacy
```

기존 서버만 실행하려면 `npm run dev:server`를 사용합니다. 현재 `npm run dev`는 클라이언트만 시작합니다.
