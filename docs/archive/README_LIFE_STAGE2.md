# 작은 쉼표 · Little Garden 3D

마름모 시점의 3D 놀이터를 만드는 싱글플레이 웹 프로젝트입니다. 현재 **2단계: 친구들의 생활 시뮬레이션**까지 구현했습니다.

## 실행

Node.js 24 LTS와 npm을 준비한 뒤 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

게임: http://127.0.0.1:5173/

로그인·게임 서버·환경 변수 없이 열립니다. 직접 만든 임시 3D 캐릭터 토리·모모·루루가 함께 생활합니다. 외부 모델·이미지 없이 실행되며 웹 폰트 로드 실패 시 기본 폰트를 사용합니다.

## 구현한 기능

- 고정 직교 시점의 16×16 놀이터, 줌과 화면 이동.
- 서로 다른 옷 색상의 치비 3명, 대기·걷기·앉기·인사·그네 모션.
- 장애물과 맵 경계를 피하는 A* 경로 탐색. 캐릭터끼리는 부드럽게 간격을 조정하며 통과합니다.
- 자율 산책과 빈 기구 선택, 접근 중 좌석 예약, 벤치 2석·그네 1석 이용, 하차 후 자율 생활 복귀.
- 친구를 선택한 뒤 바닥 클릭으로 이동, 기구 클릭 또는 이용 버튼으로 이용 지시.
- 예약·이용 중인 좌석의 상태와 이름, 각 친구의 현재 행동 표시.
- 이동/인사/자유 행동 지시로 기존 접근 예약을 취소하고, 하차 완료 시 좌석 반환.
- 그네 좌석과 캐릭터가 함께 흔들리며, 탑승·하차 전환 시 자세를 보간합니다.

아직 미구현: 배치 편집, 기구 이동/회전, 저장·복원, 실제 니케 모델, 멀티플레이. 모바일 화면 크기는 조정되지만 실기기 성능과 완전한 터치 UX는 후속 검증 대상입니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| 친구 목록 / 캐릭터 클릭 | 지시할 친구 선택 |
| 빈 바닥 클릭 | 선택한 친구 이동 |
| 벤치·그네 클릭 | 선택한 친구에게 이용 지시하고 좌석 정보 표시 |
| 벤치/그네 이용 버튼 | 남은 자리 수 확인, 직접 이용 지시 |
| 내려오기 | 이용을 마치고 접근 지점으로 내려오기 |
| 자유롭게 놀기 | 현재 지시를 중단하고 자율 생활 재개 |
| 작은 인사 건네기 | 접근/산책을 취소하고 인사 |
| 우클릭 드래그 / ↔ 후 왼쪽 드래그 | 화면 이동 |
| 휠 / + − | 확대·축소 (65~210%) |
| ⌖ | 처음 시점으로 복귀 |
| 그리드 / 그림자 스위치 | 장면 표현 변경 |

기구 이용 중에는 먼저 내려온 뒤 이동·인사를 지시할 수 있습니다. 기구 위 캐릭터를 누르면 그 캐릭터가 선택되므로, 기구가 가려지면 패널의 이용 버튼을 사용하세요. 지시가 끝나면 잠시 쉬었다가 자동 생활로 돌아갑니다. 화면 이동 모드에서는 왼쪽 클릭 지시를 비활성화합니다.

처음 입장하면 토리와 모모는 벤치, 루루는 그네를 먼저 이용합니다. 이후에는 기구와 산책을 번갈아 선택합니다. 실제로 나갔다 들어오면 초기 배치에서 새로 시작하며 저장/오프라인 진행은 없습니다. 브라우저 탭이 숨겨지면 시뮬레이션을 일시 정지합니다.

## 검사와 빌드

```sh
npm run check
npm test
npm run build
```

현재 생활 테스트는 6개입니다. 경로 우회와 원형 장애물 사이 구간, 좌석 경쟁, 탑승 도중 취소, 수동 이동 후 자율 복귀, 10분 분량의 자율 생활, 캐릭터 교차 이동과 예약 반환을 확인합니다. 10분은 빠르게 계산한 시뮬레이션 시간이며 실제 기기에서 10분간 성능을 측정했다는 뜻은 아닙니다.

배포 결과는 `apps/client/dist`입니다. GitHub Pages의 저장소 하위 경로를 위해 상대 base를 사용합니다.

## GitHub Pages

1. 소스를 GitHub 저장소에 올립니다.
2. Settings → Pages → Source를 GitHub Actions로 설정합니다.
3. main 브랜치 push 또는 Publish game to Pages 워크플로로 배포합니다.

서버 주소 변수는 필요하지 않습니다. 현재는 원격 저장소와 공개 배포를 연결하지 않았습니다. CI와 Pages 워크플로에는 생활 테스트를 포함했습니다.

## 구조

- `apps/client/src/simulation.ts`: 렌더링과 분리된 생활 상태, 좌석, 경로 탐색, 지시 처리.
- `apps/client/src/scene.ts`: 3D 모델, 카메라, 선택, 생활 상태에 따른 자세와 그네 연결.
- `apps/client/src/main.ts`: 친구 선택, 상태 패널, 이용 명령, UI.
- `apps/client/src/style.css`: 반응형 화면과 패널.
- `tests/life`: 현재 생활 테스트.
- `apps/server`, `packages/shared`, `tests/*.test.ts`: 보존된 기존 멀티 구현과 테스트.
- `docs/archive/multiplayer-client`: 보존된 2D 클라이언트.
- `Dockerfile`: 기존 멀티 서버용이며 현재 클라이언트 배포에 사용하지 않습니다.

이전 멀티 코드의 회귀 검사는 필요할 때만 별도로 실행합니다.

```sh
npm run check:legacy
npm run build -w apps/server
npm run test:legacy
```
